BioImage WB 自动流程修复测试版 T072

桌面入口：BioImage WB（自动流程修复测试版）。独立安装目录、设置和卸载入口，保留既有测试版。

顶部新建 Fig，填写 Fig 名、一次 N 和每行一个的蛋白名。跨 Fig 连续分配仪器采集组；参考结果不占序号。组内手选用于裁剪的原图后，点开始自动处理。

可靠完整定位会自动保存裁图并继续。小角度显示纠偏自动接入预览与拼图；可在原图页调整角度或恢复不旋转，再保存修正。无法定位、N冲突或歧义才暂停，在原图调整范围后继续。

整批全部裁剪→全部拼图→全部原图定量→统一结果。灰度页可看当前 Fig、蛋白与测量区域；结果页可查看固定泳道表、导出 Excel/CSV 或新结果目录。缺失、失败和质量待复核分别显示。原值 TIFF 和定量仍使用原图像素，显示纠偏不进入积分。

本版为工程测试候选，干净 Win10、物理 DPI/按钮和独立科学真值留出尚需另验。环境自检会在独立合成目录运行四种工程流程并保留报告，不使用用户原图。报告 PASS 不能代替科学准确率验收。
