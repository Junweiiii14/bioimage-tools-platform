BioImage WB Fig 顺序自动化测试版（T071）

离线候选测试版，尚非正式发布。独立 AppId、程序目录、FigSequenceTest 设置和快捷方式，
保留既有正式版及 T069 采集组测试版。安装目录内自带 Python、Qt、计算依赖和 OCR 模型。

从仪器文件夹导入后，在上方新增 Fig，填写 Fig 名称、一次填写本 Fig 的泳道数 N，
每行一个蛋白名。程序从第一个采集组开始跨 Fig 连续分配；在每组内手选用于裁剪的原图。
确认本次范围和输出位置后，点击“开始自动处理”。

整批按全部裁剪→全部拼图→全部原像素定量→结果输出推进，并跟随真实阶段自动切页。
需要复核时整批暂停，在对应原图调整范围后点击“保存范围并继续自动处理”。
可以暂停自动切页；重开项目不会自动续跑。旧项目保留原对应，显式修订才重排。

原图、历史修订和已发布结果保留；每次输出使用独立新目录。
显示变换不进入定量，缺失/失败不记为有效零值。

“测试版环境自检.cmd”执行灰度/OCR、旧采集组兼容及新两 Fig 实际页面自动化诊断。
自检报告记录真实退出、worker PID、页面阶段与输出检查。
干净 Windows 10、物理 DPI 和独立科学准确率验收仍须另做。
