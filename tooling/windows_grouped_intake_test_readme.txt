BioImage WB 采集组测试版（T069）

候选测试版，尚非正式发布。独立 AppId、程序目录、GroupedIntakeTest 设置和快捷方式，
可与原版及旧测试版共存；不要求删除旧安装、原图、项目或历史结果。无需管理员权限。
支持 Intel/AMD x64 Windows 10 1809（17763）或更新版本，不支持32位或ARM。
包含私有 Python、Qt/WebEngine、数值库、VC运行库和本地OCR模型，无需联网下载或
另装 Python/uv/Office/WebView2/Visual Studio。默认装到当前用户程序目录。

导入原图目录后，采集组网格将同次采集的图平等并排。可批量归Fig、填写正式蛋白名，
每组明确单选或取消裁剪原图，在Fig级填写泳道槽位N。可先保存未知N/未选源的草稿。
识别候选需核对来源、目标区域和原坐标，不能按编号后缀判断信号图。辅助图不进入定量。
确认清单后继续固定N裁剪；复核待确认范围，再继续完整Fig拼图、原像素测量、填表和新目录输出。
已执行清单可明确返回修改分组/对应关系，或保存裁剪修正：受影响当前结果会失效，
旧修订、原图、运行及历史输出保留。保存重开后须重新确认继续执行，不自动宣告旧结果仍有效。
文件菜单的快捷键设置支持自定义、冲突提示、禁用和恢复默认；文字输入、中文IME组合、
弹窗、失焦和忙态下保护编辑。默认 Ctrl+S 保存、Ctrl+Shift+K 打开快捷键设置。
独立灰度与OCR入口继续保留；显示缩放/旋转/拼图像素不作为原图定量输入。
失败、未检出与待复核不会填成有效零值；不同蛋白的样本配对需明确指定。

开始菜单“环境自检”使用临时合成图分别运行独立灰度/OCR与采集组主链/快捷键，
报告写入 %LOCALAPPDATA%\BioImage-WB-GroupedIntake-Test\Diagnostics。失败请保留报告和日志。
自检不改用户项目。卸载只移除本候选程序与入口，保留用户数据和设置。
交付目录的 SHA256SUMS.txt 与 build-manifest.json 用于核对安装包和源码提交。

验收边界：本机Win11工程检查不能替代干净Win10、物理按钮/多DPI和独立科学真值/留出验收。
已见实际图仅为开发回归，不报告自动准确率，不因自检通过宣称科学验收或正式发布完成。
