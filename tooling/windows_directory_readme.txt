BioImage 三工具本机候选 — 直接启动说明

双击本目录的 BioImageWB-Acceptance.exe。无需安装 Python、uv 或开发工具；请保留 runtime 与启动器在同一目录。
本目录不包含安装器，不创建快捷方式或文件关联，不替换在用安装。请勿将它覆盖到旧安装目录。
窗口标题显示应用版本、独立验收通道及源码 SHA 前12位，完整来源和依赖摘要见 build-manifest.json。

首页包含 WB 图像处理、单图核分割、BCA 蛋白定量；“工作流编排”提供现有 WB 流程和固定核/BCA研究模板。
WB 可使用原图导入或编排中的合成样例；BCA 需要固定方法的逐孔 CSV 和匹配板记录。
核分割需维护者在“运行设置”中选择已经准备好的固定 worker Python 和 2D_versatile_fluo 模型目录。
重型核环境和模型不在此目录内，也不会自动下载；路径缺失时明确提示准备。配置一次后按本候选独立通道保存。
核分割与 BCA 界面的准备指南说明各自输入限制和研究边界。

“工具启用设置”更改在退出并重新启动后生效。此候选的设置与原实验室安装隔离。
输入与已完成结果保留；工具默认在文档/BioImage/Projects 下创建唯一项目，编排另选本地可写保存位置。
关闭后可从对应工具的“打开已保存项目”或编排的“打开工作流项目”读取成果，不需要重新运行。
导出模板后可以用新的合规输入创建新项目，不能把预览图或显示变换当作原值定量输入。

附带的环境自检只覆盖历史 WB 合成诊断，不证明核/BCA或整个平台验收。
本机工程候选不代表干净 Windows、真实学生、物理 DPI/GPU 或科学/化学准确性已通过。
本目录没有商业签名，不进行公开发布或自动更新。不要关闭系统防护或绕过单位策略。
