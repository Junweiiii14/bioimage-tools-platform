BioImage WB E7 验收版（T060）

本包是候选测试版，不是正式发布。独立 AppId、程序目录、E7Test 设置和快捷方式；
不替换原版、T047 候选版或 T048 测试版。无需管理员权限。
系统要求：Intel/AMD x64 Windows 10 1809（17763）或更新版本；不支持32位或ARM。
本包包含私有 Python、Qt/WebEngine、数值库、VC运行库和完整OCR模型，无需联网下载、
Python/uv/Office/WebView2/Visual Studio。默认安装到当前用户程序目录的中文路径。

主流程：导入仪器图片目录，填写 Fig、蛋白行和固定 N，明确各行来源并确认清单；
执行后复核不确定裁剪，再继续拼图、原像素测量、自动填表与导出。不会猜测不同蛋白
之间的样本对应。独立灰度和OCR入口继续保留，显示调整不改变定量输入。
失败、未检出和待复核不作为零值；每次导出使用新目录，原图和历史结果保持。
旧项目按原schema读取，新执行链使用显式版本，迁移/恢复请在副本验证。

开始菜单的“环境自检”运行两条真实工程流程：独立灰度/OCR/取消与恢复，以及
清单批量/固定槽/真实worker/表格/导出/重开。只使用临时合成数据，不改用户项目。
报告保存在 %LOCALAPPDATA%\BioImage-WB-E7-Test\Diagnostics；失败请保留报告和日志。

验收边界：本机Win11自动化工程通过不等于干净Win10、物理按钮/多DPI或科学准确率
通过。独立仪器真值与目标机仍待验；不得据自检结果宣称正式版已完成科学验收。
卸载只移除本候选程序及入口，保留用户项目、原图、结果和个人设置。
请保留已有安装；使用交付目录SHA256SUMS.txt核对安装包。
