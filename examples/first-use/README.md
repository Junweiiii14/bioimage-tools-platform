# 三工具首次练习

普通使用者从这里开始：这些材料无需 Python 或生成代码。保留仓库目录结构，或使用准备人员提供的完整练习资料 ZIP，先解压再选文件。软件候选单独提供；本页不要求替换已有安装。

| 首页入口 | 选择的材料 | 必要信息与练习目标 |
|---|---|---|
| WB → 选择仪器文件夹 | 本目录 `wb/inputs`，选择文件夹而非单张图 | 新建 Fig，5 泳道，两行蛋白名 Target / Reference，A 对 Target、B 对 Reference；两组各勾选原图再开始自动处理。需要相对表达量时按[已有五步练习](../wb-first-use/README.md)填写样本配对和对照。两个图均为程序生成的矩形，**不是实验图** |
| 单图核分割 → 选择原图 | `nuclei/Ganglioneuroblastoma_10.tif` | 先由准备人员配置环境；[操作五步](../../docs/runbooks/nuclei-single-image.md)覆盖运行、轮廓、导出、重开。固定方法输出46核仅是工程复现值，**不是人工真值**，这张低信噪图已有误检和漏检 |
| BCA → 选择 CSV | [synthetic.csv](../../tools/bca/examples/synthetic.csv)，再“加载板记录”选择同目录 `record.json` | 原样使用配套文件，不用 Excel 重存再套旧记录；[操作五步](../../docs/runbooks/unified-workbench.md)覆盖结果、导出、项目位置和重开。全部为合成吸光度，**不是化学实验** |

首次走查可在 WB 得到原始积分后点“导出原始积分”，关闭软件，从首页最近项目打开同一 Fig。核分割和 BCA 等结果保存后再导出，在“保存位置与来源”记下项目目录和运行 ID，重开时选择该项目目录。WB 两张图对应条带相同，按练习配对后比值/相对值为1；五条泳道不等于五个生物重复。BCA S1的预稀释倍数为10，原样均值约5008.681 µg/mL，四组 partial 汇总留空：不是0，也不是全部样本合格。技术重复只描述同一样本的重复孔。

## 换成自己的输入之前

- WB 保留原始灰度 TIFF 位深；必须自己确认泳道数、蛋白、样本配对、对照和重复身份。不要从文件名猜分组，也不要将显示 PNG 当定量原图。
- 核分割只接受单页单通道 uint8、BlackIsZero、TopLeft TIFF；16位/RGB/多页不支持，不能先转8位来冒充原始数据。标签ID不是强度。本例的46不能套用到其他图。
- BCA CSV 保持原列顺序；一板、唯一孔号、逐孔原始A562、标准浓度、技术重复和**分析前的样本预稀释倍数**必须有记录。仅适用界面显示的固定Pierce25研究方法；不是任意酶标仪导出都能直接导入。自己的CSV用“新建空白板记录”填写真实仪器/日期/稀释液/基质依据和实验确认；不要复制合成记录的确认。缺SOP事实就先补记录，不勾选猜测值。CSV改动会使旧记录摘要不匹配。
