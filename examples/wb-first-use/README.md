# WB 首次使用练习

这些图是程序画出的矩形，不是真实实验；用于熟悉操作，不用于判断检测准确率、科学适用性或统计显著性。生成器复用已有回归的五泳道几何，不含私有原图。

普通使用者可直接选择[已生成练习图](../first-use/wb/inputs)，从下方五步开始；三工具材料总入口见[首次练习](../first-use/README.md)。

准备人员重新生成时，在仓库根目录运行（需要已安装的项目开发环境）：

```powershell
uv run --locked --no-sync python examples/wb-first-use/generate.py ../wb-practice-new
```

目标目录必须尚不存在，避免覆盖以前的素材或结果。普通学生无需运行代码：准备人员把生成的 `inputs` 文件夹和本页一起交给学生，并在本次检出目录运行 `uv run --locked --no-sync python -m bioimage_app`，准备好工作台。练习依据包含 P011/P012 的源码界面；实验室旧安装未被本次工作替换，不把旧版缺少入口计为学生操作失败。本任务不要求发布或替换安装包。

## 约 15 分钟的试用任务

1. 从 WB 首页选择 `inputs` 仪器文件夹。添加一个 Fig，泳道数填写 **5**，蛋白名按两行输入 **Target**、**Reference**。A 图用于 Target，B 图用于 Reference。开始自动处理，找到原始积分和完整拼图。
2. 在“样本对应与归一化”建立 Target / Reference，参照类型选择“目标蛋白 / 内参”。五条目标泳道分别填写 S1–S5，参照泳道分别填写 1–5。这里的配对是练习规则，不是软件从文件名猜测的实验关系。
3. 为 S1 填写实验 ID `Synthetic-P012`、处理组 `Practice-control`、生物重复 ID `DemoBio1`、技术重复 ID `DemoTech1`。这些都是演示标识；S2–S5 的这四项先留空，观察身份未填全提示。未知身份不能按泳道数凑成独立样本数。
4. 选择“相对单个对照”。先不选对照，核对、保存并刷新，找到缺少对照的原因；再把 S1 勾为对照，重新核对、保存、刷新。五个比值及相对值应为 1：两张合成图的对应条带信号相同。只选“仅比值”时，相对值留空是正常的。
5. 导出逐样本表、原始积分表和完整拼图到新的文件。修改身份后如完整输出提示需更新，使用“继续自动处理”更新快照。关闭项目，再从最近项目继续工作，核对样本、对应关系、身份、数值及原图仍在。归一化面板需要时点击“刷新结果”。

## 观察记录（由旁观者填写）

先让学生独立操作，卡住时再帮助。记录入口是否找到、在哪一步停顿或点错、提示是否能解释、恢复需要几次帮助、能否区分原始积分/比值/相对值，以及能否找到导出文件和重开结果。记录实际完成时间及未完成项，不要求得到“通过”。

重点问学生解释：为什么相对值可能为空？“身份未填全”是否等于数值为零？五条泳道是否必然代表五个独立生物重复？只记录实际回答，不代填满意度或成功率。

当前只有开发者走查证据，尚无真实学生独立试用、真实实验科学验收或干净目标 Windows 验收。不要把本练习当作上述验收。
