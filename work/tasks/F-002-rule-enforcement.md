# F-002：公开仓库与自动规则检查

- 状态：implementing
- 授权：用户要求公开仓库、将规则放 GitHub、补非编码能力并直接执行无需持续人工监督的防漏读方案。
- 范围：仓库可见性、规则发布、规则上下文加载/检查、非编码能力规范、服务器分支保护及实测。
- 不启动业务功能；不绕过宿主信任控制或更改全局模型。

## 验收

1. 仓库公开，规则在 main 可见。
2. 缺失/过期/超范围的规则回执不能通过 CI；有效回执通过。
3. main 强制 PR/状态检查，禁止强推和删除，无 bypass。
4. 文档解释自动发现边界与认知不可证明性，调研能力复用现有工具。
5. 实测失败路径及成功路径，记录链接，不把配置文件当作服务器已经生效的证据。
