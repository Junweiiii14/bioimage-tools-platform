# T-013：膜/Marker/固定N泳道与候选行的自动建议

- 状态：ready
- base commit：开始实施时核对最新T-012提交。
- 依赖：T-012多原图行计划与项目复核；原始导出类型仍待用户说明，继续显式选源。

## 目标
把人工框行之前的自动候选接入同一项目：用户给定泳道N/极性和裁剪高度，建议膜范围、左Marker排除/泳道网格、候选条带行，并提示弱/空或多候选。原图坐标和全部N位置必须保留，蛋白身份以元信息为准。处理结果是可拒绝/调整/恢复的建议，不能自动变成已审核或有效定量。

## 开始前
读取适用规则并context记录tools/wb、apps、测试、文档/任务/交接范围；按研究协议先冻结候选算法、阈值/版本、合成反例与真实样本验证计划。用原图和显示分离的数值数据，只在明确极性和来源下分析。不得把任务单预期趋势变成检测目标。

## 验收
后台/取消/过期结果保护，建议快照可保存重开与恢复；固定N空位、边缘膜/Marker、噪声/饱和/平坦图、多行与弱带均有明确状态。真实用户源类型未知时只做明确选定图的建议探针，不声称自动选源或蛋白身份准确。UI能切候选、调整区域并复核；提供与原像素核对的证据。自动候选阈值不从用户预期趋势拟合。

并行产品待办（不遗漏）：项目级OCR/单图结果关联与归一化、Excel/文件名元信息、批参数/缩略图、ZIP导入/直接TIFF拼图、独立审查与产品打包。具体先后按下一轮证据细化，不把T-013完成视为整体目标完成。
