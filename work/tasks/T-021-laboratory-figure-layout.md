# T-021：实验室版式、明确横向分段与模板复用

- 状态：review（本轮模板保存/导入、重复解码修复与兼容验证完成，490全量及绑定产品提交独审通过；远程CI、真实工作流和最终产品验收另计，前序独审仍待办）
- 依据：用户方案10.1–10.5与组合图的可见版式，材料仅作需求证据。2026-10-14只读查看00060263(1).tif及02360643(1).tif的既有预览：同Fig多段并排、段间边框/留白、同名蛋白重复行、不同高度行、列内独立纵向排列、Fig字号与蛋白标签有区别。

## 目标

让用户按明确选择的原图行组成实验室常用版式，并把设置保存成可复用模板。显示排列可变，原图row/lane/band身份、原像素定量、OCR明确关联和历史结果不得随显示顺序被重编号或推断匹配。

## 开始与范围

1. 建立独立分支并加载context；读FigureTemplate/FigureRow/布局、原图定量、OCR、归一化、ZIP恢复及渲染验证契约。核对现有字体导入/模板复用接口与旧项目样例。
2. 冻结兼容方案后再编码。旧v1–v6项目仍按原版式渲染，使旧ZIP重建校验保持；新字段/渲染操作必须版本化，不能把新增默认值静默写入旧来源清单。
3. 先建立明确版式计划：以已有row_id选择显示行与横向段、显示顺序与可见分界；不按同名蛋白猜配、不同原图不得无痕拼接。处理缺图、空泳道、不同段宽、标签侧/对齐、Fig独立字号、列换行。按真实样例确认哪些参数属于模板、哪些属于项目。
4. 支持逐行高度时保留明确原ROI和审核失效规则；统一高度仍可批量设置。不得通过插值拉伸把宽/高不一致掩盖为对齐。不同样本数/段数由用户显式给定；同一原图行分段的lane映射必须连续/可回溯，不能自动丢槽或重排科学意义。
5. 可视化选择/排序/预览与保存新模板；复用时不带入旧实验绑定、结果或图像。字体作为资产显式保留。模板库范围先依据实际消费者与有界导入导出确定，不创建任意脚本插件或平台实验特判。
6. 同一版式接通完整预览、直接TIFF/PNG、ZIP/恢复及生成图OCR。来源清单逐段记录原row/SHA/ROI/输出位置与分界；完整迁移不丢原值裁剪和历史证据。

## 验收

- 合成已知像素的独立预期验证横向/纵向布局、缺图/空位、不同宽高、边框不覆盖裁剪、同名重复行；零缩放、原图摘要保持。
- 旧项目与既有ZIP像素/清单兼容；新项目保存重开、模板复用、参数修改失效、实际定量/OCR/归一化身份和值保持。
- 后台、取消/关闭/过期结果、输出预算/错误可见与无覆盖沿用现有契约；Qt截图检查常用窗口大小，不以截图替代数值测试。
- 真实组合图用于版式对照，未经人工冻结的实验对应不得自动确认。完整门禁与独立wheel、研究/验证/回执/交接记录齐全，作者自验与独审分开。

后续仍有交互缩放/拖动句柄、旧灰度工具实际连接、真实标注与效率评价、大项目性能、独立审查/CI及最终Windows产品交付。整体Goal保持active。
