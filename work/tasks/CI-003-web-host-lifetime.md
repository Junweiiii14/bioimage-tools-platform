# CI-003：工作台隐藏宿主的Qt生命周期

- 状态：in_progress；T043全量挂起调查发现的确定资源生命周期问题，不先宣称其为挂起根因。
- 最小离屏实验：WebWorkbenchWindow关闭后台并deleteLater后，owner的C++对象已失效，host的C++对象仍有效；host.parent()为None。证据.local/t043/web-host-ownership-before.log。
- 修复：隐藏宿主设为工作台的Qt子对象，同时保留Window标志，使现有高级工具仍是独立编辑窗口。保持后台完成后才接受关闭，不改网页设计/数据/公式/schema。
- 验证：先写拥有者销毁必须释放隐藏宿主的失败用例，修复后检查实际C++对象释放、显式高级窗口属性、正常入口和关闭拒绝回归；绑定提交独审，完整门禁重跑。
- CI诊断继续保留，不改超时/skip/预期；只有匹配挂起栈和复现证据后才可宣告根因已修复。
