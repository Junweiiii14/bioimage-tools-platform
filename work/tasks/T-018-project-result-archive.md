# T-018：项目结果CSV与统一归档导出

- 状态：review（实现与作者自验完成，独立审查待执行）
- 依赖：T-012原图/原值裁剪/模板归档，T-014项目/OCR已验证结果，T-015归一化，T-017批量元信息；前序独审仍待办。

## 目标

补上用户总体方案11节的结果CSV和“原图、裁剪、拼图、结果、处理记录”统一交付。已有ZIP目前包含项目计划、PNG、原值裁剪、原图和字体，却没有完整定量/OCR/归一化结果与运行证据，单独XLSX与项目归档不能组成一次可核对的输出。

## 实施准备

先读AGENTS/handoff/module-map及figure_export、project_export、project_ocr_export、normalization_export和存储结果校验契约。核对用户项目材料对表结构/目录结构的要求，资料仅作证据。不执行便携旧程序，不按预期趋势修正数值。按实际范围记录context后实施。

## 范围

- 项目原图表、OCR标签表、归一化表的CSV导出，明确列、编码、状态、真实零/空值、源SHA/row/lane/band/run身份。文字字段不被表格软件当公式执行，原标签可追溯；不要以转字符串代替有效数值语义。单图CSV若确有共用契约再复用，不预建公共平台抽象。
- 在精确保存的项目修订上后台冻结统一归档：现有原像素/来源内容，加当前已校验结果表、原始结果资产、OCR证据/模型身份、归一化配置与来源清单。每成员摘要/字节数/角色、归档格式版本和缺失/无效结果原因明确；失败与未运行不包装成成功。
- 无覆盖发布、取消/关闭/源损坏/过期草稿保护，文件与数据预算，已完成结果保持不可变。所有额外读取与压缩在后台；不把显示图送入定量。
- 本任务先明确可检查的导出格式；跨工作区ZIP导入需要单独说明历史run的来源与验证，不伪造本机PID/退出/提交记录。不要通过静默丢弃历史结果宣布导入完成。

## 验收

原图/裁剪像素和SHA保持，三种结果视图在CSV/Excel/统一ZIP的一致性；4000、真实0、缺失/排除/过期不混淆；重名蛋白、带逗号/引号/换行/等号的标签；坏结果、取消发布、目标已存在、后到生成、真实Qt保存导出和独立安装。现有科学预期/容差不削弱。运行全门禁并绑定实现提交，作者自验不是独审。
