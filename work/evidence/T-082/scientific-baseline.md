## 冻结口径

以下均引用现有契约/实现，不新增或“校正”科学语义。

| 内容 | 现有方法与来源 |
| --- | --- |
| 输入 | 单页uint8/uint16；灰度或显式RGB/不透明RGBA；整数BT.601转换，MINISWHITE原值不反相。`adapters/tiff_input.py` / `docs/contracts/wb-reference-v1.md` |
| ROI/坐标 | 原图左上x/y半开矩形，数组row/column；显示缩放/纠偏/检测副本不进入量值。泳道沿宽求每行均值，暗条带为原位深上限减均值 |
| 积分 | `profile_integral@1`：闭区间L/R，至少两点；减线性基线、负差取零、纵向单位间距梯形积分。单位intensity*pixel，不乘泳道宽；ROI面积独立 |
| 背景 | 默认连接L/R剖面值，可显式人工端点；整段smear仍保留端点封底，不能从ROI外重建信号，不能当自动背景科学正确 |
| 识别 | 检峰/裁图/OCR为版本化机器建议；历史策略不静默重算。当前明显条带与固定N契约保持，N不证明上样/蛋白/跨图配对 |
| 归一化 | `lane_reference_ratio@1`：显式目标/参照及一对一样本映射；参照须有限正值，目标有限非负；显式单对照/算术均值。无效对照不能跳过，分母不加epsilon。`domain/normalization.py`、`wb-project-normalization-v1.md` |
| 饱和与无效 | 位深上下限触发复核；待复核原始积分与有效信号分列。缺失/失败/排除/未检测不填零，平坦合法区域可为真实零 |
| 人工确认 | 生物学对应、内参稳定性、曝光线性、跨图同名标签与真实N由实验负责人确认；工程回归不代替这些选择 |

## 已冻结合成样本

既有 `wb-reference-v1` 在实现前定义六组解析几何预期：[10,20,10]→10；[10,20,20,10]→20；线性[10,15,20]→0；非正残差[10,0,20]→0；[4,8,4]零基线→12；[8,8]零基线→8。整数精确比较，浮点性质容差abs1e-10/rel1e-12只适用于受控双精度运算，不是实验容差。

`test_input_profiles.py` 将同一三角形以uint8/uint16和宽1/2/5构造成真实TIFF：原值/SHA/位深不变且积分均为10。`test_manual_lanes.py`、`test_peak_envelope.py`覆盖完整泳道/截断峰与人工范围；`test_project_analysis.py::test_normalization_explicit_pairs_controls_roundtrip_and_export`固定比值[0.5,None,0]及归一化[1,None,0]，并验证导出历史不覆盖。既有测试/方法源码摘要保存于 `scientific-frozen-files.json`；若未来修改，必须说明科学语义及版本策略。
