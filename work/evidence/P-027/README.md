## 缺陷与定向复验

顺序草稿的 reference_group_ids 为空时可以省略。识别按钮在发送后重排草稿，旧页面给未编辑的草稿补上空数组，造成界面把它判为已修改；识别结果更新摘要后报冲突。删除该多余赋值，保留真实冲突保护。实际旧候选、修复源码页面的可见状态与保存摘要见 [记录](observations.json)。旧候选探针遇到冲突后仍尝试填写已禁用的 Fig，JS 找不到输入框；该探针退出时亦记录 QThread 警告，没有据此判定关闭验收。离屏运行出现字体/GLES 回退日志。

用已有导出识别用例改从真实页面按钮发起，检查点击当下没有本地修改，以及回包后可编辑；保留已有识别、保存重开断言。Windows 锁定环境，pytest -q tests/test_instrument_intake_desktop.py -k export_discovery_real_worker_save_and_reopen：旧逻辑 exit 1（脏标记 True），修复 exit 0（1 passed）。首次只检查回包后的按钮，在合成测试中旧逻辑也能通过，因此加入点击当下的回归断言。修复未写回冻结候选、未改变文件格式、算法、默认值或科学准入。
