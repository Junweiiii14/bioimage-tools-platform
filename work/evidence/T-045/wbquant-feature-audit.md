# WBQuant功能迁移取舍

核对来源：本机旧wbquant-improvements/wb_quant/web/index.html、app.js、desktop_app.py、core.py与worksheet.py；只读，不覆盖旧软件。新入口沿用绿色三栏与现有后台/存储。

| 旧能力 | 当前安排 | 理由 |
| --- | --- | --- |
| 第一条完整泳道、同尺寸复制、删除/清空/重新框选 | 独立泳道控件恢复 | 手动量化的基本操作；不把不连续泳道强制平铺 |
| 手形/空格平移、滚轮缩放 | 同一原图画布恢复，中键也可平移 | 大图边缘定位；显示变换不改源像素 |
| 多峰、全部/单泳道曲线、边界与封底 | 冻结WBQuant数值核，现有同源曲线监督 | 保持旧数值定义，不再开第二个定量窗口 |
| 添加/排除峰、撤销/重做 | 显式补峰范围/排除，32步会话历史 | 稳定身份；缺失不填零，不恢复旧运行当新结果 |
| 细框自动排除、手动有效范围 | 冻结框线检测，原图泳道/范围可调整 | 以源坐标统一表达，无另建显示数组量化路径 |
| 分组工作表、保留前组、组/条带名称 | 复用项目分组、共享原图新组、名称/拆并调整 | 已完成run不可变；不另存一份旧前端临时表作为权威 |
| 内参/实验配对归一化 | 复用已有明确配对与归一化能力 | 不按蛋白名称猜内参，不新增重复公式 |
| CSV及Excel | 复用分组Signal导出和审计表 | 缺失留空、版本/来源证据可追溯 |
| ROI/审计JSON与标注图独立副本 | 复用现有项目/归档/来源与图片导出能力 | 不复制旧软件另一套存储；不宣称支持旧ROI JSON直接导入 |
| UB拖尾 | 新增整段模式，端点封底及积分范围可调 | 用户明确要求；不选最强局部峰，保留背景模型限制 |
| 整张标注拼图自动Fig/行/泳道 | schema9记录OCR/原坐标建议并直接运行 | 自动后按需修正，仍支持手动；不要求先逐组确认 |

迁移指必要操作与现有能力整合，不是旧HTML逐个控件原样复制。人工补峰为填写原图纵向范围；旧弱候选可用同一入口纳入。旧工作表任意单元格编辑、删除已提交历史与旧ROI JSON格式不是新项目的第二套权威数据路径。标签错误需改名称或分组，不用改导出数值替代重新测量。

真实指定拼图33组/106行成功运行是开发样本的工程闭环，不等于所有自动框/标签正确。OCR I/L、缺蛋白标签、端点封底和背景不足等原因保留。独立科学留出、最终干净Windows/DPI及历史原生退出问题按原任务继续，不由本次软件回归销账。
