# 工具平台与 WB 自动流程

从工具平台进入 **WB 自动化**，新建一个空的项目目录，或在最近项目中继续已有工作区。当前真实可用工具是WB；其他实验工具尚未添加。

1. 在左侧选择 **导入原图文件夹**，指向含TIFF源图的目录。程序会递归导入，自动定位泳道/裁剪/积分边界，计算并输出一套新的结果。
2. 中央图像显示自动裁剪和泳道。拖框内部移动，拖角或边缩放；滚轮放大，中键拖动平移。全过程不需要填写精准坐标。修改后点击 **自动识别与分析** 重新生成当前几何的结果。
3. 左侧切换原图，右侧查看机器建议/待处理状态；在定量页查看原图、曲线和测量表。摘要采用4位有效数字，完整表保留完整精度。
4. 顶部 **打开结果文件夹** 查看刚发布输出，或用自动导出按钮选择新的保存位置。每次产生新目录，不覆盖原图和历史结果。

结果包括展示拼图PNG/TIFF、测量XLSX/CSV、状态JSON、完整项目ZIP及校验摘要。没有候选或结果过期的图不进入展示拼图，但仍保留在项目/归档中；全部未检出时只输出表和状态，原始输入仍保留在工作区。

“自动结果·待复核”不等于人工审核。原始积分是待复核测量；质量警告时有效信号为空，空值不代表0。当前不会猜测蛋白名、样本分组、内参或归一化配对。这些需要明确实验信息，不能由图像外观冒充。

本次真实输入10张，5张检出21条泳道，5张没有可靠候选。21条积分存在位深上下限质量提示，已明确保留警告。当前完成的是可运行的自动处理与输出闭环，科学准确率、完整实验标签/配对和最终产品验收仍需后续完成。
