# 全组审核候选版试用

入口：`C:/Users/70236/.codex/worktrees/t045-wbquant/bioimage-tools-platform/Start-BioImage.ps1`。
本轮继续使用T045候选目录；旧桌面快捷方式和已打开的窗口不会自动更新。

1. 新建独立灰度项目并导入完整TIFF，选择按Fig分组定量；也可打开已有候选项目继续。
2. 已有项目保留原计算和手调参数。要验证这次新算法，选择一个Fig后点“重新自动封底（本组）”。它沿用当前泳道框，重置本组积分边界/封底并重新计算，旧运行留在历史。
3. 在全组页查看全部泳道框，右侧按蛋白纵向检查曲线。点击框或曲线，展开起止点、封底高度；拖动橙色端点或输入数值，再点“应用并重算”。
4. 本组核对完成后点“本组已审核，下一组”。审核在保存后继续下一未审核组；再次改参数/重算会使对应审核失效。
5. 原框选、复制泳道、重选、多峰/排除、撤销重做都在“手动泳道工具”；完成后可返回全组审核。UB仍按整条泳道拖尾积分，范围与封底可手调。
6. 结果页按组合并组序/组名，蛋白逐行、泳道逐列。点击数值返回曲线；CSV/Excel沿用原导出。空值不是0，星号的质量原因可以展开查看。

进度显示真实阶段和完成计数；计算中可以浏览其他组或取消。取消保留已经提交的运行，未完成项不产生假结果。
到ROI边缘的峰可能没有足够背景，仍需人工检查；本次修复不自动扩大用户泳道，也不修改原图。
