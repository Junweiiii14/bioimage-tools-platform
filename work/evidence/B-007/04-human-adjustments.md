## 实验人员微调：从“工具参数”升级为完整编辑能力

### 微调的产品定义与默认体验

实验人员说“这个结果需要调整”，可能是在修正实验身份、纠正自动识别、选择合适的科学方法、处理异常、改变汇总口径或准备论文图。旋转只是几何调整中的一项。软件必须能表达他们想改的对象和范围，说明会影响哪些结果，并把修改真正送入计算和成果链。

正常流程继续默认自动。实验室模板已具备必要样本关系和方法设置时，导入即运行；人员可以在任何页面浏览已完成步骤，并在需要时主动编辑。不能把每个参数都变成必填表单，也不能每步要求批准。新实验首次创建模板时，只收集图像无法推断的信息，例如样本身份、实验组、内参、板位和预期成果。

所有工具使用同一编辑节奏：**选中对象 → 在原位工具区或抽屉修改 → 查看预览与影响范围 → 应用并重算 → 对比新旧结果**。显示偏好可即时生效；影响实验结果的修改先成为草稿。批量应用多一个“应用范围”选择，但不额外复制一套编辑器。运行中仍可浏览、筛选、复制已提交数值、修改非冲突显示设置；科学修改可以先形成草稿，应用时等待声明的节点边界。当前版本的忙态禁用不是未来全部能力已经存在。

### 统一微调目录：每一项都要进入需求和验收

下表是全部计划场景共用的编辑能力目录。不是每个工具都显示所有动作；ModuleSpec的编辑声明只展示该方法支持的能力。作用域为“当前对象／选中对象／同一图或孔／选中样本／兼容批次／保存模板”，不能把一个勾选框默认理解为整个实验。

| 类别与真实问题 | 人员动作与控件 | 保存什么／影响什么 | 自动处理、例外与验收 |
|---|---|---|---|
| 导入漏图、重复或错误文件 | 追加文件、移除当前批次引用、重新绑定来源；原文件名可查看 | 来源映射新版本；新增/替换输入使对应分支失效 | 相同路径/摘要提示重复，不合并内容相同但实验身份不同的文件；移除不删除原文件 |
| 样本名、蛋白名、时间或孔位识别错误 | 表格原位改名、OCR原文对照、拖到正确组 | 注释改名只改展示；改变身份映射要重算关联/汇总 | 名称相同不等于同一样本；后台回执不得抹掉正在输入的中文 |
| 图像上下颠倒、镜像、倾斜 | 自动方向结果；主动使用方向按钮或数值覆盖 | 几何约束→新分析图→ROI/测量/图表 | 仅支持的方法可用；镜像/翻转会改变泳道顺序，显式重映射身份；原图不覆盖 |
| 裁剪漏掉条带或框入无关区域 | 拖动框边、数字输入、重置自动建议、锁定框比例 | ROI/采样范围版本；对应测量和下游失效 | 预览含无效补边时标出；WB全有效ROI检查失败不能默默换分母 |
| 泳道过宽、错位、间距不均 | 逐泳道或选中泳道调整宽度/位置，统一宽度，调整边界 | 固定槽位身份与几何分开；测量、配对汇总及素材重算 | 不能靠删空泳道让后续样本左移；跨图复制像素宽度要检查倍率/坐标 |
| 自动条带漏检、相邻条带混在一起 | 添加/删除候选、指定有效条带、分开测量区 | 新ROI和排除理由；改变峰到目标的关联 | 同泳道多个条带不能默认取最亮当目标；未知蛋白角色保留待处理 |
| 背景不均、局部背景区不合适 | 拖背景区/环带、改已支持半径、选择已准入背景方法 | 背景mask/方法/参数版本；受影响强度和归一化 | 背景不足明确失败；不能把WB端点基线与IF局部背景当同一公式 |
| 曲线基线、积分区间不合适 | 拖端点、范围句柄、数字输入、复位自动区间 | 曲线编辑草稿→冻结边界/支持的基线参数 | 显示缩放不改采样；改基线应同时更新阴影积分区、数值和版本 |
| 暗/亮信号或采集量程识别不明 | 极性/已声明量程来源选项，查看原始元信息 | 方法输入/预处理版本；该图所有强度相关节点重算 | 显示反色与分析极性控件名称分开；缺采集证据不由图像最大值猜量程 |
| 过曝、欠曝、离焦、坏图 | 查看质量叠图、选替代采集、标为待复采/排除 | 质量决定与替代来源，传播到下游覆盖摘要 | “接受查看”不清除不可定量状态；饱和不能通过亮度滑块修复 |
| 多通道对应错误、串色或漂移 | 选结构/测量通道，使用已验证配准，查看叠加 | 通道映射或配准资产；ROI转移、强度重算 | 不同通道同shape不等于已对齐；串色校正须有方法及对照，不能任意减一个比例 |
| 三维堆栈只想看某层 | Z/时间选择器；模板选择受支持的投影方式 | 单层仅查看时不改结果；改变分析层/投影需新分析方法 | v1二维工具拒绝静默压平Z；不把最大投影强度与单层强度混为同一指标 |
| 细胞/核阈值导致漏检或碎裂 | 修改受支持阈值、最小面积、marker间距；叠图预览 | 分割参数→mask/object set→计数/对象强度/汇总 | 模板规定参数适用域；变更后列出新增、删除及数量变化，不只显示“已更新” |
| 粘连对象要拆开 | 画分割线/加marker，在局部预览中拆分 | 新子对象ID，记录多个对象的来源关系 | 分割线不能只画在屏幕上；对象表、数量、mask和导出必须同步 |
| 一个对象被误拆为多个 | 多选对象→合并，查看合并边界 | 新对象及parent_object_ids[]，重新计算属性 | 合并后的面积等于合法区域并集，不能重复累计重叠像素 |
| 漏掉对象或有碎屑被计入 | 补标、移除候选、改计入/排除，理由快捷选项 | 几何纠正与纳入判定分别保存 | 不直接编辑总数；每个计数变化都能定位对象。排除不删原始记录 |
| 边缘对象要不要计数 | 方法允许时切换边缘规则或单对象复核 | 纳入规则版本及有效观察区 | 用同一规则批量执行，保留总检出/计入/排除数；不能只在某实验组排边缘 |
| 一个细胞有多个核 | 查看核→细胞对应，合并/修正关联 | 对象关系表，不改核原始mask | 核数和细胞数独立显示；超出单核算法适用域时不能直接强报细胞数 |
| 克隆孔位偏移或孔边反光 | 对齐板网格、内缩孔区、标明边缘伪影 | 孔几何/有效区→分割、分母、面积/强度 | 改有效孔区必须重算覆盖率分母；克隆面积不自动变成克隆数 |
| 划痕边界缺口或细胞岛 | 局部刷mask、移除误入区域、选择已支持修补规则 | 时点mask、理由和共同观察窗关系 | 手动边界不能换掉原始时点；共同窗改变时整条时间曲线重算 |
| 时间顺序、起点或视野配对错 | 时间表改映射、选基准帧、检查配准 | 序列身份/时间单位→配准/共同窗/面积/闭合率 | 缺帧不自动插值成实验值；负闭合率保留。增加末帧可能改变共同窗 |
| qPCR目标/内参/校准组错 | 孔表选assay角色、样本/重复/参照映射 | 设计表→QC、技术重复汇总、表达比值 | 不由Cq大小推测内参；生物重复和技术重复分开，n变化可见 |
| qPCR异常孔、未检出 | 查看原始仪器flag，排除/恢复单孔并记录原因 | 纳入表→均值Cq、有效孔数、结果状态 | 不能把未检出填0或最大循环数；首版不提供重设原始曲线阈值后重算Cq的假能力 |
| qPCR效率不符或标准曲线更换 | 引用效率来源/有效范围；切换已验证方法 | 效率/公式版本→相对表达及报告 | E=2需适用证据，不能在缺效率时静默回退ΔΔCq |
| ELISA板角色/标准浓度/单位错 | 板图与表格双向选择，设置blank/standard/QC/unknown | 板设计→预处理/标曲/所有依赖浓度 | 只改一个标准即可使整板依赖浓度失效；不只更新该孔 |
| 空白或双波长是否已扣除 | 查看仪器导入标记，选择模板允许的处理 | 预处理步骤版本→全部OD_used及拟合 | 重复扣除被阻止；原始OD始终可追溯 |
| 标曲模型、权重、异常标准 | 方法下拉、显示残差/回算，排除理由 | 新方法/纳入表→全标曲和整板浓度 | 模型切换进入新方法适用校验；不以R²最好自动选结论最理想的模型 |
| 稀释倍数或浓度单位错 | 样本/孔级倍数、单位转换，批量范围预览 | 原样浓度换算和汇总；不重拟合标曲 | 同一个标准不变时只改倍数，拟合摘要应保持相同；非正倍数拒绝 |
| IHC组织、坏区、阳性区域 | 组织/坏区/阳性图层分别编辑，标注层级和尺度 | 专用mask/分类→面积或细胞评分 | 修改分母组织区域需重算比例；染色向量变化会影响整片，不是显示滤镜 |
| 流式父门/子门或边界错 | 在散点/直方图拖门、复制模板、查看父门路径 | gate树新版本→该门及全部子门事件集合/比例 | 通道/补偿/变换先兼容校验；改显示坐标不可偷偷改原始事件上的门含义 |
| 流式补偿/变换设置错 | 引用有效补偿矩阵与变换，显示来源 | 新预处理→门控适用域检查与全部相关群体 | 不重复补偿；上游更改后旧门不能被当新有效门。模板回放v1不等于自动补偿 |
| WB目标/内参/对照对应错 | 配对表拖选关联、指向唯一measurement ID | 归一化和依赖统计重算；原始积分可复用 | 跨图身份配对还要校验膜/曝光/方法适用条件，缺内参输出null与原因 |
| 分组、排除、重复层级需更正 | 实验设计表、排除复核抽屉、按样本展开来源 | analysis design→汇总/统计/图表 | 删除展示行不等于排除数据；恢复排除会重新计算有效n；不得改完只更新柱形高度 |
| 统计分析单位或比较计划变化 | 选择已批准的汇总模板，列出比较与重复关系 | 新统计计划版本→估计/区间/图表 | 图像内多个细胞不自动当生物n；不让软件穷举检验直到显著 |
| 图中字体、组名、颜色不合适 | 沿用成图工具，编辑图例/字号/线宽/顺序/标尺 | FigureSpec版本；仅渲染/导出 | 排序只改展示不改样本对应；改组名若仅别名不重新定义实验分组 |
| 亮度、色阶、伪彩不利于展示 | 显示窗口/LUT、查看共享设置 | DisplaySpec，保留对比图处理记录 | 只显示调整不进入强度计算；一个比较组是否统一窗口由成图模板声明 |
| 误操作想撤销 | Ctrl+Z/重做、放弃当前修改、恢复自动建议、恢复旧版为新版本 | 本地草稿栈或补偿编辑命令，历史不删除 | 四个动作语义不同；已保存撤销生成新修订，不将数据库回滚覆盖历史 |

目录中的分析操作必须由对应模块实现并验证；能力尚未实现时不展示一个可点击却只改界面的控件。某工具只交付面积时，不能把“计数”留成看似可用的空按钮。

### 同样的微调，三种时机的处理逻辑

运行前：调整模板生成批次草稿。输入改动会让预检重新计算支持范围、缺参和预计成果；“开始处理”绑定冻结草稿。被选择的模板版本不可被后台更新悄悄替换。

运行中：人员可以查看任何已完成对象，不随当前进度自动跳页。修改先留在本地草稿；点击“应用并重算”时显示影响摘要，停止派发，在当前节点终态和真实进程退出后保存新revision并生成新的执行计划。首版采用此清晰的节点边界，减少并发重算错误；界面继续可浏览。耗时不可中断算子可选择取消当前步骤重来，按钮必须说明这一后果，不能把请求已发出显示成已暂停。

运行后：通过“修改并生成新版”进入相同编辑器，读取旧参数和原始来源。只把不受影响且方法仍准入的资产作为缓存；新结果使用新run ID和方法/参数来源。用户可并排查看旧版与新版，差异表显示变化对象、数值、有效n及新增/解除的质控问题。

### 编辑契约：不能只有一个含义不明的params字典

在现有ScientificAsset、WorkflowSpec和ExecutionRequest之外，拟增加版本化 `EditIntent`、`EditPreview`、`EditReceipt`。内部放 `tool_contracts/edits.py`，公开入口仍为api。宿主负责身份、版本、操作幂等和CAS；工具application负责科学含义与失效声明；domain只执行数值/几何；UI和未来Agent调用相同编辑服务。

```json
{
  "schema_version": 1,
  "operation_id": "edit_041",
  "document_id": "project_01",
  "expected_revision": 12,
  "target_kind": "roi",
  "target_ids": ["roi_lane_03"],
  "analysis_asset_id": "analysis_A01_v2",
  "action_id": "wb.roi.set_geometry",
  "scope": {"mode": "explicit_selection", "apply_policy": "all_or_nothing"},
  "payload": {
    "frame_id": "frame_A01_v2",
    "geometry_type": "rectangle_edges",
    "edges": {"left": 49.5, "top": 19.5, "right": 69.5, "bottom": 59.5},
    "unit": "pixel"
  },
  "reason_code": "automatic_roi_missed_signal",
  "origin_surface": "ui",
  "preview_generation": 7
}
```

以上是设计样例，坐标沿用像素中心在整数、边界在半整数的约定。矩形覆盖x=50…69/y=20…59，宽20高40；不能把这些边界直接当整数切片端点。节点仅接收校验后、绑定analysis ID的几何资产。mask刷选和大量对象修改通过草稿资产引用传递，不把整张数组塞进消息。

`action_id`来自工具的固定动作目录，不允许执行任意Python、SQL或通用JSON Patch路径。每个动作声明支持的target kind、payload schema、作用域、是否影响科学数值、可预览性、支持的撤销行为、失效输出端口及适用方法。UI控件声明仅允许固定组件类型（枚举、数值、区域、表格、对象选择等），不执行工具返回的任意脚本。上例target_ids是唯一目标集合；跨图批量请求使用每目标绑定表（target_id、analysis_asset_id、frame_id、base_revision），不能用一个全局analysis ID代表所有图。

operation_id绑定规范化请求摘要；同ID同请求返回同一真实回执，同ID不同payload拒绝。宿主先持久记录编辑意图，再在同一次CAS中保存新revision及applied_operation_id、规范化request_digest和父revision，然后记录结果关联；若CAS成功但回执丢失，按操作ID和revision对账补回执，不重复应用。origin_surface只描述入口，真实操作者及授权范围由宿主当前会话/操作者设置确定，不信任客户端自称user或approved；本机姓名标记不冒充机构强身份。应用时重新核验方法准入、implementation_digest和操作权限。

`EditPreview` 返回：base_revision、preview_generation、候选资产、受影响节点/成果、不能应用的对象及原因、预计重算范围、原/新值差异。`EditReceipt` 返回：operation_id、applied_revision、已应用对象、保留/重算/阻断节点以及新计划引用。预览和应用都由工具使用同一个冻结参数解释器，禁止预览A公式、正式执行B公式。

保存时重新校验base revision与目标资产；冲突时保留草稿，让人员在同一面板看到“数据已更新，重新预览后应用”。首版不自动合并两个相交ROI修订或两个不同配对表。已提交A后又编辑B，A的保存回执只能清除A，不能清空新B；这是从现有裁剪修正保护推广的通用要求。基线/积分端点编辑不改raw_profile的原始样本或曲线形状，只改变端点、基线、填色及候选积分；正式旧曲线与候选计算分层标注。

### 自动结果、人工纠正与模板之间如何组合

默认策略生成可追溯的自动候选；人工编辑保存为对该输入版本的约束，优先于同一输入上的自动建议；“恢复自动建议”明确移除所选约束并重新运行相应自动模块。顺序是模板默认 → 当前批次设置 → 当前对象覆盖，覆盖字段逐项可查看，不靠“最后一份字典更新”隐式决定。

人工修正ROI只绑定当前图像资产与坐标；换原图、重做几何或重定位通道时，旧覆盖要经显式迁移/校验，否则标“需要复核”。不能把旧图x=100的框原封不动应用到不同尺寸或倍率的新图。跨图复用使用归一化几何、物理单位或已验证的配准变换之一，并记录模式；变换不是自动可比性的证明。

把修正“保存为模板”需说明哪些是可推广规则，哪些是当前样本的事实。阈值/方法和版式可形成实验室模板；样本名称、具体对象mask、单孔排除和一张图的坐标默认不入模板。Agent可建议把反复出现的纠正做成模板候选，但不能因为一张图修正过就全实验室生效。

### 批量应用与复用的准确规则

批量操作先生成兼容性报告：选中数量、可应用数量、不可应用原因与受影响成果。支持“仅应用到兼容对象”时，将明确的兼容ID集合与apply_policy冻结到请求，receipt逐对象记录；不支持部分应用的方法采用全批拒绝。同一文档以一次CAS原子应用选定集合；跨文档是多个独立子操作，各有状态和回执，不能声称跨项目原子事务。相同operation ID重试不得重复叠加变换、重复扣背景或再次拆对象。

作用域按稳定ID冻结，不按当前页面第3行之类位置描述。排除/恢复、标准浓度等科学修改不能在排序后落到别的孔或样本。物理单位的参数在有校准的不同倍率图上可以换算；像素参数只能用于模板声明的相同像素语义。没有尺度时不能猜一个换算倍数。

### 把失效重算做成可验证的依赖关系

| 修改事件 | 必须重算 | 应保留/复用 | 验收用例 |
|---|---|---|---|
| IF背景环带 | 该ROI背景、校正强度、样本汇总与图表 | 原图、结构分割、其他不相交对象 | ROI原均值不变；背景变动只影响声明的量值 |
| 计数对象拆为两个 | 局部mask/object set、数量、对象强度与样本统计 | 原图、其他对象原始几何 | 原对象变历史，两子对象来源可追溯；表和图同时多1个对象 |
| WB内参配对 | 对应比值、控制组汇总、相关图注/输出 | 原始剖面和积分 | 改配对后原始积分摘要一致，归一化数值变化符合新配对 |
| qPCR排除一个技术孔 | 该样本/assay技术汇总、配对表达、组统计 | 各孔原始Cq和其他样本预处理 | 有效孔数变化可见；生物n不因少一技术孔自动减1 |
| ELISA标准浓度 | 标曲拟合、回算/QC、所有依赖未知孔浓度和报告 | 原始OD及未变空白处理 | 同板每个未知孔标为待重算，不能留混合新旧标曲结果 |
| ELISA样本稀释倍数 | 该样本原样浓度与汇总 | OD、标曲、孔内浓度 | 原样值按倍数变化；拟合与孔内值摘要一致 |
| 划痕共同观察窗 | 所有时点有效mask/面积/闭合率与曲线 | 原始帧、兼容的平移估计 | 新起始面积和所有分母同步，不只刷新一个时点 |
| 流式父门 | 父门/全部子门事件、分母和统计 | 原始事件、未变补偿/变换及独立门分支 | 父门变小后子门百分比按新父门，不能保留旧分母 |
| 论文图字体/颜色 | figure/report render与导出 | 所有数值和分析资产 | 数值文件哈希不变、图版本变化，来源报告记录展示设置 |

失效声明是模块正式契约的一部分，需用反例测试“遗漏下游”和“过度全量重算”。如果一个编辑同时改变多个语义，拆成一个有明确子动作的事务，预览一次性显示完整影响，不能只靠前端按钮选择哪个缓存清空。

### 最小实现文件与分阶段交付

V0保留已有曲线/泳道/裁剪编辑，不重写成熟编辑器。V1先让新分析资产的ROI与几何能够接收同样的人为纠正，并完成同源预览和失效。V2新增 `apps/desktop/.../edit_controller.py`、`edit_projection.py`、`web_ui/edit_session.js`，统一草稿状态、影响预览、提交回执和快捷键；`platform_runtime`仅保存通用编辑记录/修订，工具在 `application/edit_actions.py` 实现具体动作、校验与输出依赖。

第二工具接入时，提取真正共用的 `GeometryEditPort`、`ObjectSelectionPort`、`TableEditPort` 和 `EditSession`；WB基线算法、IF背景算法、ELISA拟合规则分别留在工具包。共享表格可以编辑孔角色和样本名，但不能把它们都解释为WB内参。共享画布可以画多边形，但门控空间和图像像素空间必须由各自坐标适配器定义。

V4/V5交付对象/mask编辑、环带背景和通道映射；qPCR/ELISA切片交付孔板设计、QC/纳入、标曲影响预览；IHC/流式在各自阶段补对应编辑面板。每个场景验收既包括自动正常流程，也包括至少一种识别失败、一种错误身份、一种运行中修改和一次撤销重开，不能只录正常路径。

### 人员真正用得上的统一验收脚本

交付时准备一包已声明用途的公开/合成样例。人员不写代码，按以下动作验收：导入并自动完成；找到一个故意错误的对象/配对/孔；在图或表中定位它；修改并查看影响范围；应用后核对表图；撤销为新版本；关闭重开；与未改的样本并排比较。对每个动作都提供预期变化和必须不变的内容。

额外验证：计算中输入中文标签、连续拖两个ROI、保存A期间继续编辑B、改变排序后批量排除、取消在最终提交前后各发生一次、断开Agent服务后继续通过UI修改。任何一种出现“图改了值没改”“值变了来源没变”“修一个对象全批旧结果混入”“后台抢焦点”都不能作为完整微调交付。
