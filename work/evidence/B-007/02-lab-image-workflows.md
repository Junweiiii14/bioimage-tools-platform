## 从实验人员熟悉的操作，设计自动工作流与可选接管

本章是WB、二维IF强度、核/细胞计数三条产品工作流的研发设计。下文“参考操作”来自已访问的官方软件文档，是可复查的常见操作路线，不声称是所有实验室共同遵守的唯一SOP；“本项目设计”是候选实现，尚未交付或通过科学验证。采用软件菜单是为了说明实验人员实际做什么，不是要求本项目把这些菜单逐个弹给用户。

正常使用只有“导入已支持批次及样本表—选择已保存模板—运行—得到完整成果”。后台自动识别、质控、计算、汇总和制图。用户随时可以查看当前图像/曲线、主动暂停并接管；只有缺身份、数据不适用、方法未准入或自动判断不可靠时，相应依赖进入待处理。独立样本继续，异常数和未完成成果明确列出。把每个手动步骤搬成一个必须点“下一步”的向导，不符合本项目的自动化目标。

### 数据在进入算法前就要组织完整

导入结果包括不可变原文件引用、文件摘要、格式/轴序/通道/dtype、实际采集位深及其来源、曝光/增益/设备及校准信息、像素尺度及来源、样本身份。仪器没有提供的信息写unknown，不从文件名、16位容器或漂亮的预览反推真实采集条件。批次表必须能区分“文件”“物理膜/孔”“生物样本”“技术重复”“视野”“通道”“本次测量”；同一样本跨通道、重拍曝光、同一视野的裁剪不增加生物n。

WB另保存膜ID、目标蛋白、泳道ID与角色、上样顺序、目标/内参测量ID、对照组和排除理由；IF和计数另保存板/孔/视野、结构与目标通道、细胞类型、采集平面、对象类型和统计单位。默认从已批准模板、仪器元信息和明确样本CSV解析；OCR只生成带源位置和置信信息的标签候选。通过模板约束、唯一性和已有样本表一致性校验的候选可以自动采用，冲突项才待处理，不让每个正常标签都等人工确认。文件排序不能替代样本配对。

CellProfiler的`Images → Metadata → NamesAndTypes → Groups`为这种组织提供了实际软件参考：先建文件清单，再关联元信息和通道，最后定义处理组；其Groups是处理组织概念，不能直接等同于本项目的生物学分组或生物重复。[F05：CellProfiler 4.2.8 Input](https://cellprofiler-manual.s3.amazonaws.com/CellProfiler-4.2.8/modules/input.html)，访问2026-10-31。

以下模块ID均为拟执行模块，版本记`@1.0.0`；方法另有独立`method_id@version`。共用契约沿用B-006：`ScientificAsset`组合旧`AssetRef`，首版WB分析载荷与累计均float64；预览、定量、表图引用同一分析资产，`DisplayAsset`不能进入测量。ROI绑定分析资产ID/revision和坐标frame；全部非零插值贡献源像素均有效，目标像素才有效；首版WB ROI须全在有效区内。IF若采用相同几何运算也遵守此规则。原图、旧成果、旧整数方法都保留，改方法必须新版本及独立科学准入。

## WB：从膜图、泳道与背景，到配对表和拼图

### 实验人员的参考操作路线

ImageJ Gel Analyzer的一条基础路线是：打开膜图，矩形框选首泳道，执行`Analyze > Gels > Select First Lane`；移动同尺寸矩形，以`Select Next Lane`记录其他泳道；`Plot Lanes`生成剖面，直线工具封闭目标峰，用Wand测峰面积，`Label Peaks`显示结果。这里的峰百分比是相对所测峰总和，不是目标蛋白/内参归一化。[F01：ImageJ 1.46r Analyze/Gels](https://imagej.net/ij/docs/guide/146-30.html)，访问2026-10-31。

几何处理在ImageJ可用`Image > Transform > Rotate…`，选择插值和扩展画布。查看时可调`Image > Adjust > Brightness/Contrast`；显示范围调整、把范围应用到像素和转8位是不同操作。项目不会把8位显示副本当成精度保留的原图。[F02：ImageJ 1.46r Image](https://imagej.net/ij/docs/guide/146-28.html)，访问2026-10-31。

仪器软件的完整路线还包含身份和重复：Empiria Studio 3.1的HKP流程先设置图像/蛋白，定义泳道，再关联重复、指定Sample/MW Marker/Not Used、寻找与补充条带，随后查看定量与导出。它提供自动和手动泳道模式。这说明“微调”不仅是旋转，也涉及实际样本和测量对象；本项目采用自己的算法和数据契约，不复制其专有ALF/背景算法。[F04：Empiria Studio 3.1 HKP工作流](https://www.licorbio.com/help/empiria_studio/archive/v3.1/contents/software/empiria-studio/quantitative-western-blot/analysis-with-housekeeping-protein.html)，访问2026-10-31。

### 每一步如何进入本项目

| 实验人员的步骤及输入→输出 | 拟模块、独立算法和前后关系 | 复用范围、自动分支与失败处理 |
| --- | --- | --- |
| 1. 打开原膜/多曝光文件，填膜与泳道表→有身份的原图 | `wb.import_batch`接文件与样本表；`wb.source_qc`检查解码、轴序、采集范围、质量来源和显示图嫌疑 | 复用受限文件读取/摘要/表schema；膜和泳道关联为WB专用。重复文件不静默重复计入；不支持格式隔离，其他图继续 |
| 2. 查看直方图和背景，区分暗带/亮带→极性与质量结论 | `wb.source_qc`先于估角；检测极性使用模板/仪器信息；可信度不足给unknown。曝光选择按已验证线性范围与质量规则 | 直方图技术运算可复用，WB放行规则专用。dtype端点仅是风险线索，不自动等同真实饱和。不得调暗预览后消除饱和警示 |
| 3. 转正与限定分析范围→校正资产 | `wb.estimate_geometry`绑定投影集中度角搜索方法；`wb.apply_geometry`绑定一次反向双线性采样、扩展画布、float64/mask | 矩阵/采样内核候选可复用，WB估角策略专用。不可靠角度不填0；区域倾斜不一致、弯曲或超范围留待处理 |
| 4. 定义泳道、排除Marker，定位蛋白条带→带身份ROI | `wb.locate_bands`在校正坐标自动确定泳道和目标区；数量/预期目标范围来自模板与样本表 | 矩形/多边形编辑器复用；泳道顺序、蛋白角色专用。疑似双峰/漏检保留候选，不按最大亮度猜目标蛋白 |
| 5. 画积分区间、调整背景线→剖面、基线、单带量值 | `wb.measure_float`绑定`wb.measure.profile_integral_analysis@1`：泳道行均值、端点线性基线、非负超额梯形积分 | 曲线控件可复用，方法专用。区间包含邻带须提示；无效mask、非有限值或无可解释基线拒绝。区域背景/滚动球另立候选方法，不能混入此ID |
| 6. 把目标与内参对应，设对照与排除→相对量 | `wb.collect_measurements → wb.normalize`；按唯一测量ID关联并校验膜/批次/曝光/校准兼容；参照方法必须明确 | 表连接技术可复用，配对与归一化规则专用。缺内参、内参0、源QC失败或方法撤销只阻断依赖的比值，保留原量值/状态 |
| 7. 汇总重复、比较分组→样本表与组图 | `wb.summarize_replicates`先按SOP汇总技术重复，再按生物单位汇总；输出实际n、中心量/离散度及排除清单 | typed_table/绘图可复用；统计定义由模板固定。默认不自动挑检验、删离群点或加显著性星号；未知重复身份不宣称生物n |
| 8. 整理条带、曲线和结果→可交付包 | `wb.compose → wb.export_bundle`生成表、带来源的拼图/剖面、参数和例外报告 | 渲染/导出技术可复用，WB布局素材专用。已提交数值可保留；必需拼图失败时“完整成果”仍未完成 |

WB三种背景操作必须在界面上说清：**图像背景校正**改变进入测量的分析数组；**剖面基线**改变积分参考；**背景区域估计**得到区域统计后参与扣除。ImageJ的`Process > Subtract Background…`有滚动球/滑动抛物面选项，是图像处理，不等同于在剖面上画直线。半径也不是跨位深、跨图尺寸可盲用的通用常数。本项目首版保留端点线性基线；接管中的“改方法”必须显示新方法和准入状态，不能只是一个看似无害的滑块。[F03：ImageJ 1.46r Subtract Background](https://imagej.net/ij/docs/guide/146-29.html)，访问2026-10-31。

条带上下边界和泳道宽度必须分别可调：前者改变积分区间，后者改变行均值的像素集合。当前方法不乘泳道宽度；同样的行值复制成双倍宽度不意味着量值翻倍。ImageJ绘图测峰、二维区域像素求和、IOCBIO沿泳道宽度积分、项目行均值后积分不应默认数值等价；对照必须固定ROI、背景、极性、尺度、预处理和单位，比较同一端点。IOCBIO官方论文明确描述其宽度方向积分及背景处理，只能作为方法差异证据，不能把其结果直接当本方法金标准。[F10：IOCBIO Gel原始论文，2023-10-20](https://link.springer.com/article/10.1186/s12915-023-01734-8)，访问2026-10-31。

WB完整成果表至少包含原量值、目标/参照ID、归一化公式、单位、有效/排除/未知状态和样本层级；不能只给一列最终比值。总蛋白归一化、多通道、分子量估计是不同扩展：前者要定义测量区及线性范围；多通道要验证配准和通道采集；分子量需要已知Marker及迁移拟合，只是估计，不能证实抗体特异性。OCR的“45 kDa”也不自动成为分子量校准点。

## 二维IF强度：分割用于找区域，原强度用于测量

### 参考操作与不同软件的边界

ImageJ路线可以是打开原通道图，`Image > Color > Split Channels`分离通道；设置空间尺度和`Analyze > Set Measurements`的面积/均值/积分量；ROI Manager保存结构区域，在对应强度图上测量，并另测背景区。RGB合成图拆出的8位RGB分量与仪器多通道原值不是同一输入；必须先辨认数据来源。[F02](https://imagej.net/ij/docs/guide/146-28.html)、[F01](https://imagej.net/ij/docs/guide/146-30.html)，访问2026-10-31。

CellProfiler批量路线使用前述输入模块，必要时`CorrectIlluminationCalculate/Apply`处理照明，再由已定义对象进入`MeasureObjectIntensity`。照明估计具有适用条件，其文档也提示实施难点；本项目的匹配dark/flat方案不是宣称复刻该模块。[F06：CellProfiler 4.2.8 Image Processing](https://cellprofiler-manual.s3.amazonaws.com/CellProfiler-4.2.8/modules/imageprocessing.html)，访问2026-10-31。其强度文档说明默认按NamesAndTypes定义的最大可能值缩放，且均值和积分要区分；本项目保留原强度域，不能直接将两软件导出数字作相等断言。[F07：CellProfiler 4.2.8 Measurement](https://cellprofiler-manual.s3.amazonaws.com/CellProfiler-4.2.8/modules/measurement.html)，访问2026-10-31。

| 参考步骤及输入→输出 | 本项目拟模块/算法与依赖 | 复用、专用语义与异常 |
| --- | --- | --- |
| 1. 核对同一视野的结构/目标通道→匹配图像集 | `if.import.channels`解析支持的TIFF轴和CSV，以样本/孔/视野/通道唯一匹配；保留原元信息 | 复用图像资产/表读取；通道角色为IF专用。缺一通道、重复匹配、未知Z/T维度待处理；首版不自动做最大投影 |
| 2. 查看对焦、曝光及质量→可分析视野 | `if.source_qc`记录离焦、源饱和、损坏、质量mask及排除原因；规则阈值随方法冻结 | 图像质量特征候选可复用，实验放行专用。离焦可能仍“看见细胞”，不自动允许强度比较；不能以改变显示窗修复采集 |
| 3. 处理照明/暗电流→保原单位的分析图 | `if.correct.dark_flat`实现`(I-dark)/F`，F为匹配flat减dark后归一化的照明场；校准无效区传播mask | 纯数组运算可复用，校准匹配为方法责任。无校准采用明确none模板；F≤0不除后填0，不从处理组平均亮度估造背景 |
| 4. 从结构通道圈区域，检查与目标图位置→ROI集 | `if.roi.structure_otsu`在结构通道有效域阈值、连通域和冻结尺寸过滤；跨通道只在已验证共享frame/配准下传ROI | 对象集/坐标工具复用；ROI定义专用。目标通道亮像素筛选不是默认ROI；错配不以相同shape掩盖 |
| 5. 选择空背景或局部环带→背景B及可用面积 | `if.background.annulus`外扩ROI，排除其他对象/无效像素，取中位数；`if.background.fixed_region`为另一个明确方法 | 几何扩张可复用，背景含义专用。环带不足时仅允许模板已准入的替代区，不能自动拿细胞内部作背景 |
| 6. 测每区域的平均及总信号→ROI长表 | `if.measure.region_intensity`读取未检测平滑的分析图，分别输出`mean-B`和`sum-N*B`，保留原均值、N和B | float64/有限数检查可复用，量值定义专用。负的合法背景校正值保留；背景未知则校正值null，原始区域量可单独交付 |
| 7. 按视野/样本汇总→生物单位结果 | `if.summarize_replicates`执行冻结的聚合：逐对象平均、像素加权或逐视野平均必须选定并命名；再按生物单位统计 | 复用表/统计容器。不能让对象多的视野自动改变样本权重；缺尺度仅给像素面积，不伪造µm² |
| 8. 导出→强度表、ROI/背景证据、分组图 | `if.report.bundle`输出区域与视野表、叠加图、完整状态和方法；图上伪彩/显示窗另存 | 复用渲染、导出、来源跳转。用于报告的通道颜色不影响量值；组图标题须明确mean/integrated、单位、n |

这种流程需要让用户看到区域是怎样来的：点强度表中的一行，画布同时显示结构ROI、目标原强度、背景区与质量异常。面积、强度和计数分开交付。比如ROI4个像素为110/130/150/170、背景100，则校正均值40、像素和160；这是解析预期，不是某数据集的实测结果。若删除一个ROI只为“变异太大”，系统保留原值和理由，不能把删除历史抹去。上游检测可以在副本上平滑；显示、检测和测量数组的来源分别可查。

背景方式从局部环带改为固定背景区，是方法/参数变更，重算受到该背景影响的所有ROI及其汇总。选择多个相交ROI时要明确输出“逐ROI表”还是“ROI并集”；并集以像素集合去重，不能把重叠像素算两次后仍叫总面积。用户画出的自由曲线在测量前成为版本化几何/标签，画笔和截图不会覆盖原图。

## 核/细胞计数：实例身份、排除和拆合必须追得回

### 可复查的参考流程

ImageJ计数路线是对检测副本设置`Image > Adjust > Threshold`，生成二值mask；需要时做`Process > Binary > Fill Holes/Watershed`；`Analyze > Analyze Particles`按尺寸、圆度和边缘规则输出对象/总数。也可用Multi-point Tool做手动点标注。官方粒子分析页面同时提示接触对象会增加难度，且该Wiki内容带“迁移后未重新审核”的声明，因此这里结合版本化手册核验，不把页面示例当真实性能证明。[F09：ImageJ Particle Analysis](https://imagej.net/imaging/particle-analysis)、[F03](https://imagej.net/ij/docs/guide/146-29.html)，访问2026-10-31。

CellProfiler把可独立识别的核作为Primary Objects；Secondary Objects可借助核及胞质/膜信息获得细胞区域。`EditObjectsManually`能增删改对象，但会逐图暂停等待Done。本项目只借鉴对象对照和可编辑性，默认自动链不插入这个逐图人工必经环节。[F08：CellProfiler 4.2.8 Object Processing](https://cellprofiler-manual.s3.amazonaws.com/CellProfiler-4.2.8/modules/objectprocessing.html)，访问2026-10-31。

| --- | --- | --- |
| 1. 选择核图及样本关系→可计数视野 | `count.import.fields`复用已验证通道适配器；`count.source_qc`检查有效区域、离焦和对象类型 | 用IF图像读取能力而不导入其内部代码；DAPI核图不会自动成为全细胞真值。没有有效像素时count=null |

| 4. 判断对象质量/边缘→计入及排除对象集 | `count.objects.qc`逐对象保存面积、边缘、形状、接触和排除原因；`count.objects.apply_edits`可选接管 | 对象变更账本复用，核/细胞放行规则专用。大小过滤和排除边缘不能隐藏从总数中消失的对象 |
| 5. 有膜/胞质条件才找细胞→核-细胞关联 | `count.cells.seeded_watershed`结合已验证核marker、胞质前景及边界梯度；首切片限定经验证的单核类型 | 不能以核外扩圆代替真实细胞。多核/无核类型另需方法；当前算法不能声称自动将两核恢复为一细胞 |
| 6. 逐对象检查、汇总视野→核数/细胞数与密度 | `count.summarize_fields`分别报告accepted/excluded/unresolved、有效面积和密度，再按样本模板汇总 | 复用表与来源跳转。未知团块可给已确认对象数，但不能把它标为完整总数；密度的分母必须与计数观察窗一致 |
| 7. 保留编号图与标签→完整计数成果 | `count.report.bundle`导出实例表、标签mask、编号叠加图、视野/生物样本汇总及修订差异 | 编号颜色只是显示，label ID为结构化身份；重编号要保存映射。独立边缘/团块结果不可被一张漂亮叠图掩盖 |

分水岭内部的前景、距离图、marker、标签都应可观察，但第一版不必拆成四个独立进程。只有需要独立参数、复算或多人组合时才拆为节点；保留中间资产已能满足实验人员查看过程。ImageJ的二值EDM分水岭、灰度Find Maxima分割和本项目显式marker分水岭的种子/边界规则不同，名称相同不意味着实例数量相同。

手动点一下计数与画一个完整对象不能混淆。点标注可用于计数复核和漏检提示，不能自动成为对象面积或IF强度ROI；若用户要把漏检对象用于强度测量，需建立有效边界。拆分一个核、合并两块碎片都生成新object_set；原ID保存为父身份，子ID新建。多个父对象合并必须记录父ID列表，不能把单个`parent_object_id`字段硬塞成假一对一关系。首版独占实例标签中，一像素被编辑为多个对象的无定义归属不能发布；这与IF允许多个独立ROI及明确并集统计不同。

## 全面的接管设计：改动在哪里，谁需要重算

所有科学编辑先进入本地draft_generation草稿，临时预览带generation；应用时才通过一次CAS形成持久revision，旧任务不能回写新草稿。拖动时更新受限预览；停止拖动可自动计算候选预览，用户一次“应用并继续”冻结此轮修改并正式执行。普通自动运行没有这个点击要求。撤销未提交编辑恢复草稿；撤销已完成运行通过恢复旧参数产生新revision，可复用合法旧缓存，但不删除新旧成果。恢复自动模式要明确删除哪些人工覆盖，不能一边保留手动参数一边声称全自动。

| 接管类别 | 修改的状态及作用域 | 重算/撤销与质量边界 |
| --- | --- | --- |
| 自动角度覆盖、裁剪范围、翻转方向 | `geometry_spec`与源资产绑定；默认本图，批量须明确模板范围；最终旋转只有一个科学操作 | 从原图和累计矩阵采样一次，重算ROI/测量/统计/表图；撤回回到旧矩阵。扩展边缘继续masked，不因视觉完整假装实测 |
| ROI位置/宽度/高度/自由边界、多选平移 | 新`geometry_set`；独立选择本ROI、同蛋白、同膜的明确对象集合 | WB改宽度重做剖面与基线，改上下界重做积分；IF重做受影响背景与区域量。批量对象集合须在提交前冻结，不能“当前可见项”漂移 |
| 漏检、误检、拆分、合并、多个对象 | 新marker、对象label或排除决定，记录父子/多父映射和操作者 | 重算该视野计数、相关对象强度和后级汇总；保留自动/编辑前后差异。点标记不替代完整边界，团块无法解释则仍待处理 |
| WB基线端点、积分区间 | `measurement_spec`中的界限；端点线性方法内参数编辑 | 重做该带量值、依赖内参/对照/组图。任意多点基线/多项式拟合是新方法候选，不偷偷扩大既有方法能力 |
| 图像背景、局部环带、固定背景区 | `background_method`、mask、半径/支持规则或校准资产ID | 改ROI可能同时改变邻近对象可用背景，因此重算共享背景依赖，不能仅改当前表单那一行。方法切换须准入；不通过调背景追求预期差异 |
| 极性、强度上界、曝光选择、饱和 | `intensity_descriptor`或`selected_acquisition_id`；不能编辑原像素来消除警示 | 极性影响检测/剖面、曝光选择产生新分析链。可信仪器量程修订要有来源；曝光时间字段不是“自动相除即可可比”的授权；源饱和不能修补 |
| 蛋白名、泳道角色/顺序、目标与内参配对 | 区分显示名称与科学身份：改显示别名仅标签；改`target_id/lane_id/reference_measurement_id`是语义修订 | 身份变化重新验证定位约束/配对/方法适用及汇总；Marker/Not Used切换可使检测范围失效。不能只更新表头而让量值偷偷换样本 |
| 生物/技术重复、分组、对照、排除/恢复 | 样本映射、aggregation_spec及排除账本，保留理由 | 通常复用图像量值，重做归一化/样本汇总/统计/报告；若改变校正批次则校正下游也失效。恢复不是删除排除记录，而是新决定 |
| 跨图模板、共享ROI和参数范围 | `template_revision`、适用条件、绑定清单、覆盖优先级 | 先检查格式/尺度/通道/设备/对象支持域；每图独立自动定位。复制参数不复制像素坐标；同frame复用也须来源证明。批量失败逐图报告 |
| OCR标签和图上文字 | `label_candidate`与样本身份有分开的来源、冲突状态；用户可一次改多个候选 | 只改排版文本不重测；采纳为蛋白/配对字段时走对应语义重算。识别结果不能执行代码、选未经批准算法或改科学容差 |
| 阈值、核尺寸、marker间距、边缘规则 | 版本化检测/质量参数，明确本视野临时覆盖或新模板 | 改本图不写回整个模板；新范围需验证；局部编辑如改变过滤规则须重跑全视野，不能仅刷新总数 |
| 表图顺序、字体、颜色、显示窗、比例尺 | `presentation_spec`；生物分组仍由analysis schema提供 | 仅compose/export失效。改轴单位/误差线定义若涉及新统计是分析变更；不允许手改结果单元格而失去原始来源。比例尺来自校准，不是装饰文字 |

跨图应用要有两种不同命令：“把本次参数作为模板应用于所选图”与“在同一已配准视野上复用ROI”。前者重新检测，后者沿明确变换映射几何并检查有效域。把模板保存成未来默认不会偷偷改历史结果；仍在运行的批次用启动时冻结的模板，下一批才使用新版本。

预览图和曲线出现时显示当前分析revision、完成/候选状态及源质量标记。暂停首版在节点边界生效，界面可立即查看此前结果；修改后继续采用新运行身份。取消要等进程退出与提交对账；取消先于最终提交生效时，不允许迟来结果把页面刷成成功；最终提交若已先完成，取消返回已完成并保留真实成果。重算清单用中文说明“3个条带和对应归一化/图表需要更新”，实验人员不需要读DAG或JSON。

## 三个完整交互故事及拒收反例

### 故事A：一批WB到表格、拼图和异常清单

实验人员导入三张膜的目标/内参原图和泳道表，选“已验证目标/内参模板”。软件自动检查来源，估角、转正、定位、出剖面和结果；过程页可以点击已完成的第一张图看基线，其他图继续。正常膜不要求任何确认。一张图估角不确定时只暂停该图依赖，明确显示不能判定原因，不默认为0°；批次仍能交付其他图和异常表。

人员发现第二膜第三泳道ROI略宽，主动接管并缩窄，再把一个OCR误识别的显示别名修正。界面告诉他ROI会更新该带及对应相对量/组图，别名仅改图表标签。应用后只重算依赖，旧版仍能打开；最终导出原量值、配对比值、组统计、拼图、剖面和异常说明。若源饱和，选另一张经过模板可比性检查的低曝光采集；不存在合格采集则报告未定量，不能用“自动修复饱和”解决。

拒收：调暗预览后饱和标记消失；角度失败显示“已校正0°”；跨膜只因泳道名相同就自动配内参；改目标名后旧量值直接被重标为新蛋白；取消后旧结果覆盖新ROI；缺拼图仍称整批成果完成。工程算例：目标120/参照60得2，对照90/90得1，归一后2；参照缺失必须null，不能以1兜底。它只验公式与身份，不验真实生物准确率。

### 故事B：二维IF从通道与背景到可解释组图

人员导入两个处理组的多个生物样本，每样本若干视野。模板用结构通道定ROI、目标通道测强度，自动关联采集信息，完成区域/视野表及组图。人员点击一个偏高视野，看到背景环带被邻近细胞占满；软件已经把校正量标为待处理，没有给出一个漂亮高值。人员在模板允许范围内选已定义背景区，预览即时显示新B及受影响ROI，再应用继续。

随后人员把一个ROI和邻近ROI合成并集。系统去重交集像素，并重做与该前景遮挡相关的背景，更新该视野与对应生物样本；其他样本缓存可复用。最终图明确每点代表生物样本，视野数和排除数另列。导出保留原均值、背景、N、校正均值/总和与证据图，别人能知道变化来自信号还是区域/背景定义。

拒收：把合成RGB当原通道；结构图与目标图错配却因尺寸一样通过；只保留亮像素再宣称总表达增强；两相交ROI的面积直接相加；负校正强度截0；把同一样本的十个视野写为n=10个生物重复。解析预期：均值80、合法背景100应为−20；背景未取得时不能输出−20或0，只能输出缺失状态。

### 故事C：核计数中的团块、漏检和全细胞边界

人员导入核标记图，软件自动提供核总数、编号图、排除和未解团块数。人员在密集视野打开接管，在确有两核的团块放两个marker，看到分割边界和前后数量差；补一个漏核时可先点定位，只有补齐边界后才加入对象强度测量。新对象表记录原父ID和新增来源，撤销会恢复此前分割但保留修订历史。

若批次有已支持膜/胞质通道，独立细胞模板才输出cell_count；仅核图则成果写nucleus_count。明确多核细胞的场景不强行走单核模板，可以保留核成果并指出细胞计数未支持。用户不需要了解分水岭数学，但能从总数追到每个计入/排除对象。

拒收：原视野没有有效像素却输出0；两个marker示例成功就宣布所有接触核准确；无膜通道仍输出“细胞数=核数”；未标注对象一律当自动误检；人工合并后旧标签ID无映射而对象强度串行；同一对象的多张裁剪被分进开发和留出集。解析预期：独立已确认标签中一个细胞含两个核，统计必须分别为1 cell和2 nuclei；这不证明当前自动算法能识别多核细胞。

这三个故事是依据真实实验工作形态设计的验收脚本，不是已观察客户案例或实测成绩。正常/异常数据包、性能环境、错误放行阈值和方法容差须提前登记；用户操作验收与科学负责人/独立评测承担的量值验收分开。
