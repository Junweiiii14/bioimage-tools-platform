# 开发日志｜2026-10-17｜T-042 原图自动裁图与灰度边界修复

记录范围：本次社区调研、算法修复、现有工作台接入、真实原图验证、独立审查与仓库管理现状。产品仍在开发中，本日志不表示发布或验收完成。

## 目标与实施顺序

用户要求先处理短膜误判、倾斜、Marker 误删和泳道数识别，再处理灰度积分边界；所有能力接入现有工作台。8 张真实原图作为识别输入，参考图仅在预测冻结后用于评分；原图和旧结果保留。

1. 固定输入清单与摘要，建立旧自动结果基线，区分原图、参考与历史结果。
2. 对照 ImageJ/Fiji GelAnalyzer、GelJ、GelGenie 及 SciPy/scikit-image 官方资料。没有证据支持直接引入某个社区工具就能解决本组全部问题；沿用锁定依赖，实现可复核的几何与信号处理。
3. 实现 `source_geometry@2`：膜定位与显示裁图高度解耦；从完整轮廓估计倾角；Marker 排除要求多行证据；自动确定泳道数，保存各泳道在原图上的 ROI。
4. 实现 `background_support@1`：以连续背景支持判断积分边界，识别截断、背景不足与内部双峰；缺少支持时输出待复核状态。原始像素用于积分，拉正插值仅用于检测和显示，积分公式保持版本化兼容。
5. 接入现有网页工作台的正常后台服务、结果持久化和导出流程，补齐 worker 协议及 3 份公开 JSON Schema。没有把本地脚本生成的结果注入项目来代替正常处理。
6. 完成绑定提交的只读独立审查，按发现修复显式排除误删样本、裁剪框残留、分段显示框、重分析破坏版式、内部双峰及协议质量标记遗漏。
