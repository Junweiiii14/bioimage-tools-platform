# 新版 WB 界面：按四个步骤完成项目

这是现有 Qt 桌面程序的工作流程重写。原始数据、定量规则和项目文件格式保持兼容。当前为本机开发版。外观借鉴旧WBQuant的参数区与图像工作区布局，操作仍使用新版功能；四个步骤可自由切换，定量后可直接导出，无需先做拼图。

## 开始

打开程序后，在欢迎页新建工作区，或打开已有工作区。工作区是保存输入副本、项目草稿和运行结果的目录。恢复别人交给你的完整项目时，使用“从完整项目 ZIP 恢复”。

顶部保留常用导入、保存、取消和项目切换。较少使用的项目操作放在“项目”菜单内。

## 1. 原图与裁剪

点击“批量导入 TIFF”。在原图表填写 Fig、蛋白、泳道数 N，并在原图画布选择裁剪范围。检测候选是辅助建议，应用后仍需审核。空泳道保留原位置，不删除来改变泳道顺序。

需要直接输入 ROI 数值时勾选“精确坐标”；极性、Marker 等参数在“高级检测设置”中展开。折叠不改变参数值。ROI 坐标以原图像素为准，起点包含、终点不包含。泳道编号从 1 开始。批量名称及样本信息操作在本步骤的批量信息页内。“更多操作”中可以添加缺图位或删除所选行。确认所选行后再进行定量或正式导出。

## 2. 定量与复核

使用“当前原图”选择器选中需要处理的行，配置定量，再计算曲线。填写条带边界后重新计算；边界是裁剪内的行号，从 0 起算且包含两端。基线两端同时留空表示使用边界端点值。

切换阶段不丢当前选择。若边界只填了一端，切换原图会被阻止，并提示补全；修正后再切换。计算完成后复核曲线、有效值和失败原因。缺失或未检测不等于数值零。

需要归一化时，在样本对应页明确选择目标、参照和对照，不按同名蛋白自动配对。输入更改后需要重新计算和复核。

“OCR / 结果表”位于定量与复核内。OCR用于识别拼图标签并明确关联原图行，识别结果要人工复核，重新识别会重建候选关联。无需先排版即可导入已有标签图；当前生成拼图也可直接用于识别。

## 3. 拼图排版

在版式设置中配置 Fig 顺序、分段、间距和标签。旁边显示生成的拼图预览；修改后点击生成预览更新。默认“适应窗口”显示完整拼图，选择“100%”查看输出像素细节；两者都只改变屏幕显示，不影响导出或定量。分段仍对应原泳道，不能以显示排列替代科学样本对应。

模板保存公共排版设置和字体，不保存本次原图、样本关联或结果。导入模板会先保存当前项目，再建立空项目。

## 4. 导出

| 输出 | 用途 |
|---|---|
| TIFF / PNG 拼图 | 论文展示、排版；是显示图，不能作为本项目的原值定量输入 |
| 完整项目 ZIP | 携带原图、当前项目和可用结果证据，供恢复与追溯 |
| 原图定量 XLSX / CSV | 原始积分和逐槽状态、来源 |
| OCR 关联表 | 已明确关联和复核的标签结果 |
| 归一化表 | 显式样本对应后的派生值及状态 |

需要继续编辑时点击“保存项目”；需要迁移到别处时导出完整 ZIP。导出不会覆盖已有文件。
