# P017 最小实验预声明

2026-11-06。在运行拟合前固定本计划。输入采用plateReadeR v1.3.0提交cfb05bd403747b3192999debe9889fa5d1fefb78的真实BCA示例：96孔仪器表，42个已定义孔（3空白、21标准、18样本孔/6个样本）。上游说明是Tenebrio molitor whole_body；具体生物独立性未知，不做组间显著性。

先验参考为该提交已发布levels.csv六个浓度及analytical_performance.csv；它是软件参考输出，非独立化学真值。冻结原文件SHA256后运行。数字容差atol=1e-10、rtol=1e-10用于双精度同一线性模型复现（不是科学容差），不调整标准点或删除失败。

源码核验发现plateReadeR使用反向OLS（浓度~信号）、缺空白时跳过扣除、元数据eval(parse)、组平均后才判断外推，以及std/sample体积比自动修正。这些使整套脚本不适合直接作为不受信任学生输入的产品默认。FPCountR有论文与公开get_conc_bca，但专为荧光蛋白校准，要求蛋白序列/基线/稀释系列，不能把它宣称为普通组织BCA即插即用。Python plater未见许可证。上述缺口形成选择受支持通用回归API加最小数据胶水的依据，不以R下载慢作为淘汰理由。

本轮实际直接调用SciPy linregress与statsmodels OLS（固定独立环境），各自复现上游反向拟合，并对照常规正向OLS后反算以显示方法方向差异；不会自行实现拟合求解器。空白扣除、明确稀释及身份合并为公开assay所需胶水，不声称运行了plateReadeR全脚本。检查原始孔数/布局、逐孔原值与校正、标准残差、逐样本参考误差、耗时及环境。保留范围外/缺值，不把负值或未检出裁成0。已有3与10uL体积差只复现原软件口径，不验证其化学准确性。

CCK-8保留比较候选：官方Dojindo CK04公式及显色/还原干扰；xstars固定提交a6033589a74831c9460d193bb4a97fafbc7759e4的CCK8Preset存在首列默认对照、无空白默认0、仅分母等于0拒绝等边界。本轮不做IC50。若后续取得完整CCK-8原始孔表+处理匹配空白+对照+重复身份及真实使用任务，其优先级可改变。
