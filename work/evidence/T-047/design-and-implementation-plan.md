# T-047 入口与退出交互方案（待预览审核）

日期：2026-10-19。代码基线：6b643a3957852a87827f85912544ea36da3b712f。
当前仅设计和可交互演示；不把网页进度、退出画面当作真实软件关闭、安装或定量证据。

## 已确定的需求

- 日常从 Windows 桌面/开始菜单启动安装后的软件。先提供与原版并存的候选安装版。
- 新项目默认灰度定量，可选择自动或手动；保留裁图/拼图工作流。
- 选择 TIFF 原图或原图目录后自动创建独立项目，确认输入后进入对应工作页。工作页展示加载状态，无需用户再次寻找开始按钮。
- 软件项目目录用于重开；恢复上次页面、Fig 和有效选择。两类目录明确命名，选错目录给恢复路径。
- 在同一主窗口切换项目、返回首页；旧项目需要的保存/取消先完成，错误不丢当前修改。
- ×、Alt+F4、文件菜单退出与左栏退出共用同一状态机。用户已确认两种异常现象，尚未定位唯一根因。

## 当前代码证据与缺口

- `web_ui/index.html` 的普通导入与独立灰度导入是不同入口；最近项目按钮目前进入 demo，不能作为真实最近项目恢复。
- `web_ui/app.js` 的 `bootstrap` 仅依赖 `manualQuant.pendingImport` 等当前页面变量决定导入后的页面，未建立跨重开、跨入口统一的目标页面/位置恢复。
- `web_window.py:open_project` 在已有 workspace 时明确拒绝打开其他项目；没有同窗口项目切换闭环。
- `web_window.py:closeEvent` 先 ignore，转发隐藏宿主 close，完成由 `_backend_closed` 推进。`figure_window.py` 关闭链路包含取消、保存、AsyncStorage/背景服务 shutdown 与 closed 信号。当前网页缺少退出阶段与错误展示。
- `resources_closed` 依赖两线程和选择/恢复任务清理状态；当前是否因某一具体任务、隐藏窗口或保存失败导致用户现象仍 UNKNOWN。后续在独立副本复现并记录本实例进程树，不操作用户的现有窗口。
- `tooling/p0/build.py` 仅是旧 P0 探针 standalone 构建脚本；其中排除 scipy.signal 等规则不适合直接用于现产品，不能把它当最终安装包。

## 实施顺序（预览审核后）

### 1. 项目入口与导航

桌面层增加明确的入口意图（新灰度、新裁图、打开项目）与会话代际，桥接返回相应加载/就绪/错误状态。文件选择取消不产生空项目；目录扫描、解码、项目验证继续在现有异步端口进行。新图导入确认后定位新条目；初始载入时可先呈现工作页的加载状态，但不得提前显示“导入成功”。

已有项目在项目文档与结果装载后恢复位置。界面位置用独立、带版本的本机设置存储，键包含真实项目身份；校验页面白名单、Fig、row/lane 仍存在，失效时回退到有效分组/默认工作页。不为 UI 位置改动科学项目 schema，不改计算请求、历史结果或原图。

最近项目只记录实际成功创建/打开的项目；缺失/不兼容给重新定位/重试入口。修改保存路径只影响后续新项目。当前项目切换统一经过关闭项目流程，旧回调不能把新项目覆盖。视图/桥接重新绑定必须撤销旧订阅并使用新会话身份。

### 2. 可见且可靠的退出

在可见主窗口协调：工作中 → 请求退出 → 确认未保存/未提交修改 → 取消并等待本实例任务 → 保存并核验 → 清理工作进程/线程/高级窗口/WebEngine → 真正关闭。重复点击合并成一次请求，GUI 不阻塞等待。

退出提示区分曲线/选框未提交草稿、未保存项目修改和已自动保存内容；“放弃”仅作用于可放弃的未保存/未提交内容，不撤销已提交结果。不把设置中的页面位置成功写入当作项目保存成功。

计算取消保留已提交结果，取消确认与正常失败分开。保存失败/清理失败保持主窗口可见并可恢复；显示当前阶段、错误和重试入口。进度来源为真实生命周期事件，未知耗时不伪造百分比。工作进程治理只针对本实例创建且身份仍有效的进程，不按进程名结束原版、其他窗口或其他用户程序。是否终结进程要以真实退出观察为准。

### 3. 完整 Windows 候选安装版

先对现有构建依赖和官方打包文档做版本/许可/来源核验及最小实验，再确定正式构建配方与 installer 工具。冻结源提交、依赖版本、构建命令和文件摘要。完整包必须带上 QtWebEngine、页面/脚本资源、数值与 TIFF/OCR 依赖，并验证打包后的 worker 静态路由。

候选程序使用独立 AppId、程序目录、名称、快捷方式和卸载项，不覆盖原版。桌面与开始菜单提供可选快捷方式；无需用户打开命令行或安装 Python/uv。新项目、缓存、设置、日志与安装目录分离，卸载默认保留项目与原图。先生成可审查安装包，再在用户要求的并行安装范围内验证；发布/替换原版单独处理。

## 交互和验收

预览保持既有深绿栏/矿物白/翡翠强调。主按钮进入工作流，辅助入口含义明确；只在取消、未保存修改等需要中断的场景使用对话框。加载以工作面状态表示，退出时窗口保持可见直到完成。减少动效保留文字反馈。

产品实现后，相关检查覆盖：原图/目录/已有项目/最近项目四入口；取消、选错目录、损坏或不可写；恢复页面/Fig/选择失效回退；切换项目的旧回调；关闭空项目、加载中、计算中、未提交草稿、保存失败、重复关闭、后台退出失败；实际 OS 进程终态和无本实例残留。

安装候选验收须从图标启动，打开用户 TIFF 的独立副本项目，保存、退出、重启恢复，确认真实退出码及本实例工作进程均退出。无开发目录、中文路径及干净 Windows/不同 DPI 分别记录实测状态，未运行不宣称通过。现有 T-046 761 测试仅属于旧产品基线，不是 T-047 通过证据。
