从新测试版自己的最近项目记录定位项目，以SQLite只读连接及一致备份API读取提交头，不争抢Workspace所有者、不点击或关闭用户窗口。快照为schema14/revision11，10个蛋白行、30个来源、每个采集组三图等尺寸；本次实际遇到的两行均N=2。11份历史草稿均按已提交资产大小/SHA核验后读取。私有路径、完整项目、图像和原始诊断只保留于忽略目录`.local/t073/`。

- revision5：首行`explicit_lane_count_conflicts_with_evidence`暂停；用户明确范围后，revision9已保存原值裁剪。revision10自动领取第二行，revision11因`guide_membrane_unlocated;source_signal_contour`暂停。该序列证明首次人工处理后调度能自动推进，当前重点是定位/可靠性判断，未发现这两次属于保存失败或取消。
- 第二行只读重放：旧检测得到唯一候选、完整两个泳道、信噪证据约85.59/44.55、角度−2.810997°；后置源图校验却返回膜未定位，候选从1变0。旧候选本身仍需验证目标唯一性与原像素槽位，不能因为旧分支给出一框便直接放行。
- 30来源通过公共`discover_exports`只读重放：10个被选来源全部在当前启发式中归为merge，每组同时有signal/white建议，无读取错误。这是算法角色建议而非实验真值。`propose_intake_crop`仅从两个“未亮背景”伙伴中挑白光；选中merge时，两个伙伴为signal与white，条件不成立，辅助定位被跳过且未解释。
- 代码`detect_instrument_geometry`要求至少三个独立信号组件；正常只有两个独立条带的N=2场景无法满足该方向校验。这是结构性覆盖缺口，不代表本次第二行已走到该条件（它更早失败于膜定位）。N=1另受旧源检测至少两中心的限制，不宣称只删“三条带”条件即可支持。
- 首行诊断性取消显式N仅用于分析：算法得到3槽、第三槽信噪约10.26，前两槽约150.59/145.91；额外槽在目标右侧。已查看显示副本，右侧有笔迹/非目标暗结构，是误计数的排查重点，尚未以人工真值证明该组件类别。用户实际N仍为2，未改任何保存参数。
- 调度`intake_workflow@3`在任何`needs_review`时暂停整批，因此以上误阻断会使后续所有pending看起来需要逐张确认。修复应优先纠正判定；继续保留全部裁剪→全部拼图→全部定量→统一结果的阶段屏障。

## 待审核修复清单

| 优先级 | 修复项 | 目标行为与验收 |
|---|---|---|
| P0 | 已有候选与后置验证分离 | 保留原候选和具体失败依据，在已核验膜范围/目标内独立验证信号，修正“唯一两泳道候选→膜未定位→候选清零”的误阻断；旧单候选不直接免检。第二行作为必要回归。 |
| P0 | 适配用户选中的来源角色 | 同组三图统一核验角色与对应坐标，选合并图也可利用同组白光提供膜范围；方向与槽位须从所选来源的目标信号独立验证。保留用户手选裁剪/定量来源，不按编号猜角色，不静默换成另一张图。 |
| P0 | 小N与角度可靠性拆分 | 为N=1/2建立独立结构依据，不能强制需要≥3条带。仅当原像素范围和全部N槽独立可靠时自动裁剪；角度证据不足但已证明不影响安全范围时保留未纠偏显示并记录状态，疑似倾斜会影响槽位/目标时才暂停。不得把白光角度当信号角度。 |
| P0 | 修正N冲突误报 | 排查并过滤Marker、膜边、笔迹/划痕、背景纹理产生的假槽位；以用户N约束几何检验，只有唯一完整结构满足N时通过。不得仅取最强N峰、吞掉真实弱条带、外推不可见首尾槽或把缺失当零。首行假3槽/真额外条带均须有正反例。 |
| P1 | 自动推进和暂停条件集中管理 | 范围/固定N/来源/提交均通过则自动保存原值并处理下一张；人工解决当前问题后一次继续整批。只在多目标未定、真实N冲突、范围/原坐标不可靠、读取/保存失败或用户停止时暂停；质量说明与非必要显示纠偏问题不无条件阻断整批。保存成功后才推进，保护取消、旧回调与未提交草稿。 |
| P1 | 暂停说明与回归验收 | 每次暂停用一句中文指出是哪张图、哪个条件及最小处理动作；详细检测依据折叠，不让用户重复确认已可靠项。覆盖N=1/2/4/5、水平/小倾斜、合并/信号来源、Marker/笔迹、双排/多膜/弱条带、人工后续跑、完整表/历史保护；统计逐例通过与暂停原因，不只报总体测试数。 |

涉及几何/角度/采纳语义的变更应版本化，旧项目/人工确认/历史结果不静默重算；原图、显示与定量输入继续分开。验收要同时证明可靠案例不中断和真正不确定案例会暂停，不能用提高自动率替代正确性。
