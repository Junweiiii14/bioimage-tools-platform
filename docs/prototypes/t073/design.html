进入交互原型

一条连续、清楚的工作流

配置原图 → 全部裁图 → 全部拼图 → 全部定量 → 统一结果。顶部保留当前阶段与一个主要动作，可靠定位直接继续，只有需要你处理的问题才展开说明。

  • 顶部直接填写 Fig、N 和蛋白名，采集组跨 Fig 连续分配。
  • 组内原图并排选择，参考结果不占序号；任何一张都能放大。
  • 大图居中，左侧按 Fig 组织蛋白，右侧只显示当前图像需要的信息。
  • 不确定定位给出一句具体原因，调整后“保存范围并继续”。
  • 灰度页能看见图像与曲线，结果页直接显示完整表格。

细节服务于操作

统一字体、间距、颜色和控件状态；150–200ms 的控件反馈，支持减少动效。图像、曲线和结果数值保持稳定。输入、拖拽和主动浏览期间不自动抢页，保存失败保留草稿。窄窗可展开图像详情。

参考与技术

参考 Linear 的信息层级、Figma 的画布与属性组织、Carbon 的状态反馈。沿用本地 HTML/CSS/JS 与 Qt WebEngine，不引入在线字体、CDN或额外前端框架。原型的布局和规范将用于软件实现，并用实际状态逐页核对。

预览范围

这是可操作的设计原型。图像、曲线、数值均为合成示例，N 的演示范围为 1–8；可演示自动推进、必要暂停和恢复。真实科学计算、保存失败、原图与历史保护将在软件和独立审查中验证。
