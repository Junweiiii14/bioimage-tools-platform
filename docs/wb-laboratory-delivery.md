## 使用

1. 解压完整交付包，可先运行“校验安装包.cmd”核安装器SHA256，再双击Setup.exe。
2. 从桌面/开始菜单“BioImage WB 实验室版”启动；初次部署运行开始菜单“环境自检”。
3. 将仪器文件夹拖至WB工具卡，或选择目录；核对来源、Fig、蛋白和N后执行，复核裁剪、曲线及质量提示。
4. 保存项目并导出成图、Excel/CSV或归档。未审核表也导出当前可见内容；质量星号/缺项不转换成有效零。
5. 合成练习包提供原图、可打开的示例项目文件夹及示例结果。主界面“打开已有项目”选择项目文件夹。项目ZIP作为独立归档保留，不能把ZIP当作该文件夹入口。

完整逐步说明随安装器安装到“安装与使用说明.txt”。项目保存到本地可写目录，备份完整项目或可恢复归档；卸载只移除安装载荷，不主动删除用户项目、原图、结果或设置。更新前正常保存关闭并备份。
