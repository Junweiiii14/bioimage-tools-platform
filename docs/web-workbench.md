# 同源网页工作台

用户2026-10-16明确要求先实现网页，再按网页还原桌面。本轮选择 QtWebEngine 加载同一 HTML/CSS/JS，而非两套控件分别近似，使用已锁定 PySide6 组件，无新增依赖。页面本地加载，QWebChannel只连接固定动作白名单；原图计算和持久化仍在现有WB后端。

启动：`uv run --locked --no-sync python -m bioimage_app --web-workbench`。页面资源位于 `apps/desktop/src/bioimage_app/web_ui/`，已确认包含在wheel。

选原图自动建立独立工作目录并识别/输出；已有项目添加原图为追加。中央可拖动裁剪/四角或在未定位图上拖画，无需手填坐标。键盘方向键移动，焦点位于角点时改变尺寸，Shift步进10原像素。确认后转下一张。高级模板/OCR/归一化/曲线仍打开原生编辑器。

浏览器版本通过本地demo.json展示真实历史预览，只维护交互草稿；不会冒充新的计算/导出。桌面通过bridge执行真实计算。当前仅主工作区视觉同源，不能宣称所有高级窗口已网页化。原生默认入口仍保留。

现有项目在新窗口打开；同窗口已有workspace时明确拒绝另一个项目，避免丢弃当前草稿。独立安装包体积/干净Windows及完整屏幕阅读器验收尚未覆盖。
