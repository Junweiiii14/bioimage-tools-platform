# T076：平台首页与整 Fig 浏览

本说明记录 T076 在 T075 `7fcb8192ada7acf5695e74f23cbe010ffd862966` 上的普通界面扩展。源码核对点为 `d3aff15d53bf04c822976af0dd6b261f2b4dd6a1`；当前实施、检查与交付状态只见 [T-076 任务](../../work/tasks/T-076-platform-home-scroll.md)。模式为 Operate：先找到工具或项目，再继续处理实验图像。

## 产品层级

BioImage 是工具平台，当前已安装工具只有 WB。平台首页以“已安装工具”为主区，最近项目为右侧辅助区；没有未实现工具的占位入口。WB 卡片进入 WB 首页，最近项目使用已有项目打开流程。

| 层级 | 实际内容与入口 | 会话影响 |
|---|---|---|
| 工具平台 | 已安装 WB、最近项目、打开项目、当前项目的“继续工作” | 浏览保留已打开项目与草稿 |
| WB 首页 | 仪器文件夹导入、独立灰度与裁图、已有项目、保存位置、原有成图示意 | 浏览保留已打开项目；新建或打开项目使用现有会话流程 |
| 当前项目 | 导入与分配、裁剪、拼图、定量、结果 | 操作沿用已有业务与保存契约 |

面包屑表达“工具平台 → WB → 项目”。浏览跳转只更新前端 surface，并保存对应滚动位置与可恢复焦点；它与文件菜单的“关闭项目并返回 WB 首页”分开。后者仍发送宿主会话命令，经忙碌、草稿、未保存修改保护。后台状态可以更新当前项目，但自动完成与批次跟随不会把平台/WB 首页切走。

WB 首页的“选择原图”和“选择原图文件夹”分别发送 `new_images` / `new_folder`，宿主先校验 `workflow` 为灰度定量或裁图拼图。用户选择文件后，经 `start_from_images` 进入新项目替换保护；已有项目和草稿在用户完成保护流程前保留。这两个首页入口不复用项目内追加原图的命令。

## 既有视觉体系内的扩展

[DESIGN.md](../../DESIGN.md) 与 [.impeccable/design.json](../../.impeccable/design.json) 保持原样。`design_tokens.css`、本地 Noto Sans SC、`appearance.js` 与 `motion.js` 相对 T075 基线无变更；默认仍为 forest / comfortable / expressive，四主题、紧凑密度和减少动态效果沿用原实现。

平台工作面继承 ground；WB 入口继承 rail、shell-ink、shell-muted、primary 和 primary-ink。正文继承本地 `WB Sans`，主要正文 14px，辅助信息 12px。平台标题在本页使用 32px / 600，窄窗为 26px；WB 首页标题为 28px。平台入口采用 16px 圆角。这些是此页面的具体尺寸，不替换系统的通用标题或工具入口规范。

宽屏布局以工具区和最近项目区约 1.8 : 1 排列，间隔 40px；≤1100px 收紧间距与比例，≤800px 改为上下排列。主容器纵向滚动，最近项目仍复用既有详情与打开入口。平台不添加新的主题或字体资源。

工具卡上的条带装饰与箭头响应悬停和键盘焦点；丰富模式的指针跟随只作用于装饰条带，命中区域保持稳定。系统或应用减少动态效果设置会关闭该位移。WB 首页继续使用原成图纸面与动效。此处没有新增实验结果或科学图像动画。

## 整 Fig 曲线矩阵

定量中间列作为纵向滚动容器，标题保持可见；上方 Fig 图像增加显式收起/展开按钮，并通过 `aria-expanded` 表达状态。收起只改变当前窗口中的显示，不写入实验项目，也不修改原图或结果。

整 Fig 矩阵保留“蛋白为行、泳道为列”，横向区域可聚焦并独立滚动，支持 Shift + 滚轮。蛋白名称列固定在左侧，曲线卡标出泳道号及原图 y 像素范围；各格纵轴独立，不能据显示高度比较绝对信号。

点击曲线时记录矩阵横向位置、中间列纵向位置和所选格身份，等待对应蛋白/泳道编辑区出现后再显示编辑区。显示回调在动画帧执行时重新查询当前编辑区，并重新核对身份；连续快照替换 DOM 后仍使用当前节点，不提前消耗待显示请求。“整组概览”恢复记录位置与原格焦点。异步显示与返回逻辑校验项目、会话、当前模式和选择身份，避免旧回调改变另一页面。拖动端点期间阻止滚轮移动工作区；端点、边界与积分仍沿用原有坐标和提交路径。

## 同源预览

桌面和 HTML 预览共用 `apps/desktop/src/bioimage_app/web_ui/index.html` 及其 CSS/JS。`?preview=1` 打开平台首页与合成演示适配器；预览工具栏提供准备、完成和多条带矩阵场景。`?preview=1&matrix=large` 使用每个 Fig 10 个蛋白 × 18 条泳道的合成矩阵，供滚动、编辑返回和窄窗检查。

预览不读取真实科研项目、不执行科学重算；演示保存不等于桌面事务成功。该合成规模不是最大项目性能承诺。用户已验收首页样式并追加安装授权；安装结果见 T076 任务，旧预览和安装目录保留。
