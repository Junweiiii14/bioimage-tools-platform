# 实验覆盖与需求调研路线

5.0 · 2026-11-03。目标是逐步覆盖普通学生常见的完整分析任务。以下是待调研候选，不是已经证实的市场排序或算法可用性结论。

## 1. 先验证已有基础能否解决真实任务

首条候选为WB完整学生流程：已有工程基础可复用，但仍要核对真实原始数据、样本身份、背景/归一化、重复汇总、结果表图和独立用户体验。不能把已交付的通用执行器当作完整学生产品已经完成。

从[P010](../../work/tasks/P-010-experiment-discovery.md)开始，先研究目标结果、当前处理链及缺口，再决定实现范围。若缺少必须材料，不伪造验收；保留对应阻塞，并比较有真实材料的其他候选，不为固定顺序浪费开发成本。

## 2. 候选实验：先看输入与结果

| 候选任务 | 需要取得的输入与目标结果 | 关键待决和验证 |
|---|---|---|
| WB相对表达与表图 | 原始膜图、蛋白/内参/组别/重复；原值、归一化、汇总与图 | 检测/背景/饱和与分母失效；已有方法对照和独立留出 |
| IF/荧光细胞计数与强度 | 原始通道、尺度、对象定义；数量、区域强度和样本汇总 | 分割、重叠、背景、跨视野/样本汇总；计数/强度独立参考 |
| 孔板读数处理 | 原始读数、孔位布局、空白/对照/重复；校正值与实验定义的汇总 | 布局身份、背景/标准曲线适用性、缺孔与超范围 |
| qPCR相对表达 | 仪器导出、目标/内参/组别/重复、实验采用的方法；逐样本及汇总 | 检测下限、效率假设、未检出与重复排除；不默认所有实验同公式 |
| 划痕闭合 | 对齐的时序原图、尺度/时间/视野；面积变化与样本汇总 | 同一视野身份、定位/分割及归一化，漂移/异常帧 |
| 克隆或Transwell计数 | 原始视野、计数对象/区域、样本身份；数量/面积与汇总 | 重叠、边界、染色差异与抽样，人工标注参考 |
| IHC区域/染色测量 | 原始图像、区域与实验定义的评分/测量方法；区域与样本结果 | 染色分离、区域选择、批间变化、评分定义与专业复核 |
| 流式数据处理 | 原始数据、通道/补偿/对照与门控依据；群体与样本统计 | 专业规则、质量控制、对照与门控一致性；后期再评估范围 |

这张表不意味着每项都需要自行研发算法，也不表示一个现成软件能覆盖全部步骤。每个候选都按[开发流程](workflow-development.md)验证可复用方法和授权条件。

## 3. 如何选第二实验及后续顺序

每个候选给出真实证据，不凭热门程度或功能数量排序。比较：用户任务频率与当前痛点、可获取的授权数据和独立参考、输入/结果定义是否清楚、有效算法能否复用、完整闭环开发成本、维护/部署负担、是否有人愿意持续试用或付费。

需求强但材料不足的候选保留；资料齐全但无人需要的候选不因易实现就优先。IF计数/强度可以优先纳入比较，原因是符合图像平台方向；在调查完成前不固定为必须实现的第二工具。先给出一个推荐和备选，写明为什么，以及什么新证据会改变顺序。

首轮实现只选一个场景。第二批数据用于检验模板可复用性；真实用户纠错反馈进入下一轮，而不是立即新增更多实验名称。

## 4. 后续专业需求怎样进入平台

先判断需求属于参数预设、方法替换、流程连接还是格式适配。小范围专业需求仅在使用者、材料和验收明确时拆任务；优先封装已有有效算法，确无合适实现时才自研。实现后与普通模板共用公开入口和执行语义。

不先建设插件市场或万能算法库。新公共能力须有真实复用证据，专业选项按需展开，普通用户不被迫理解节点和模型配置。

## 5. 当前验收与经营边界

P002/M1/M2已工程集成；P004正式几何仍是独立候选任务，不能借本路线自动改变旧WB数值。科学留出、用户试用、目标机和性能缺项见[Issue57](https://github.com/Junweiiii14/bioimage-tools-platform/issues/57)。

用户已有学校老师及企业联系人，可由用户协调调研和试点；本计划不自动外联。使用者、付款者和验收者分别确认；付费部署/适度定制是可测试的经营假设，尚无确定定价或收入证明。首个市场与收费模式需要实际需求、交付成本及购买条件证据再决定。
