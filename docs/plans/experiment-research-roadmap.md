# 后续实验：先调研，再开发的具体路线

2026-11-02 · B-014 · 仅规划树保存，未派发给开发窗口

## 1. 怎么使用这份路线

当前开发窗口继续P-008批处理及后续P-009可视编排。下面是新增实验能力的建议顺序，不是已激活任务，也不是要求所有内容同时开发。第一项先完成[WB实际流程对照](../research/2026-11-02-wb-workflow-audit.md)，补齐模板和实验数据汇总。

推荐顺序是：**WB闭环 → 免疫荧光计数/强度 → CCK-8等孔板结果 → qPCR → 划痕 → 克隆形成/Transwell → IHC → 流式。** 这按现有能力的复用程度和数据复杂度排序，不是市场需求排名；如果某类实验已有完整真实数据和明确用户，可以调整先后。

目前只对下列软件功能做了公开资料初筛，没有把每个场景都做成完整调研。真正启动某一项时，先按[操作调研表](workflow-development.md)补齐软件版本、具体操作、参数和对照结果，再创建实现任务。

## 2. 每种实验具体研究什么、做出什么

### 第一项：免疫荧光细胞计数、阳性率和强度

**要解决的问题：** 每张图有多少细胞，多少阳性，每个细胞或选区的荧光有多强。

先调研一套二维、明确通道的实验。可对照CellProfiler的`IdentifyPrimaryObjects`识别细胞核、必要时`IdentifySecondaryObjects`识别细胞，再用`MeasureObjectIntensity`测目标通道。ImageJ的阈值和`Analyze Particles`可作为另一个实验室操作来源，不强制统一为同一种算法。[CellProfiler对象识别](https://cellprofiler-manual.s3.amazonaws.com/CellProfiler-4.2.8/modules/objectprocessing.html)、[强度测量](https://cellprofiler-manual.s3.amazonaws.com/CellProfiler-4.2.8/modules/measurement.html)

- **先拿材料：** 原始多通道图、通道含义、像素尺寸、阴性对照、人工核/细胞标注、软件测量表。
- **重点问清：** 测细胞核、全细胞还是固定ROI？怎样处理粘连和边缘细胞？阳性阈值从哪里来？是否做背景/照明校正？
- **候选模块：** 通道读取 → 核/细胞分割 → 对象筛选 → 强度测量 → 阳性判定 → 按样本汇总。
- **第一版交付：** 细胞标号叠加图、逐细胞表、每样本计数/阳性率/强度表，并能用模板跑第二批。
- **验收重点：** 人工标注的漏检和合并错误；计数和强度分别核对。多视野先归属同一样本，不能把每个细胞直接当独立实验重复。

这能复用图像输入、ROI、显示与表格交付，但需要新的二维分割和对象测量能力；不能直接用WB的泳道积分替代。

### 第二项：CCK-8/MTT结果与ELISA标准曲线

先做一套CCK-8板读数，再扩展ELISA。CCK-8先核对试剂说明和仪器导出；它反映代谢相关读数，不能未经验证就等同于直接细胞计数。ELISA可对照Prism的`Interpolate a standard curve`，但要按具体试剂和数据确定曲线模型及权重。[Dojindo CCK-8](https://www.dojindo.com/ASIA/products/CK04/)、[Prism标准曲线](https://www.graphpad.com/guides/prism/latest/curve-fitting/reg_interpolating_with_linear_or_n.htm)

- **先拿材料：** 仪器原始CSV/XLSX、孔位布局、空白/对照、标准品浓度、稀释倍数、重复孔和原结果表。
- **重点问清：** 空白怎样扣？有没有参考波长？复孔怎样合并？标准曲线用什么模型、加权和范围？
- **候选模块：** 板表读取 → 孔位绑定 → 空白校正 → 复孔汇总；CCK-8接相对对照，ELISA接拟合→反算浓度→稀释换算。
- **第一版交付：** 可追溯到孔位的结果表、板图和所需曲线。CCK-8相对值和ELISA浓度采用不同模板。
- **验收重点：** 手算样例、标准品回算和超范围样本。不能把缺孔填0，不能不说明地外推浓度。

可复用文件导入和通用表格/出图机制；孔板模型、拟合和实验公式需要新增。Excel元信息读取功能本身不等于已有孔板分析。

### 第三项：qPCR相对表达量

以一个具体仪器的导出格式起步。QuantStudio相对定量模块提供参照样本/内参设置、基线和阈值检查等操作；这些参数必须随结果记录。[QuantStudio Design and Analysis v2相对定量指南，Rev F.0](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN0018747_RelativeQuantificatAnalysisModule_QSDASWv2_UG.pdf)

- **先拿材料：** 原实验文件或导出曲线、Cq/Ct表、孔位、靶标、内参、对照、复孔、熔解曲线及效率证据。
- **重点问清：** 哪些孔未扩增？阈值是否一致？复孔异常怎样处理？采用ΔΔCt还是效率校正方法？前提是否满足？
- **候选模块：** 仪器结果读取 → 孔/基因/样本绑定 → 质量检查 → 复孔处理 → 内参与对照计算 → 表图。
- **第一版交付：** 从仪器已计算的Cq/Ct开始做可复现相对定量；重新从扩增曲线估计Cq另立方法任务。
- **验收重点：** 未检出不填0或任意最大循环数；与仪器/实验室参考表逐孔核对；保留生物重复身份。

先复用孔表与样本身份，不复用WB比值公式来冒充qPCR计算。

### 第四项：划痕愈合

研究ImageJ/Fiji的Wound Healing Size Tool及实验室已有操作。其方法文章描述了划痕区域、覆盖率、平均宽度等输出，首版只选择实验室真正使用的一个端点。[原始方法论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC7386569/)

- **先拿材料：** 同一视野的0时刻及后续图、时间信息、标尺、人工划痕区域和原结果。
- **重点问清：** 是否同视野配对？如何排除漂浮细胞、划痕岛屿和边缘？需要面积闭合率还是宽度变化？
- **候选模块：** 时间/视野配对 → 必要的配准 → 无细胞区域分割 → 面积测量 → 相对0时刻计算。
- **第一版交付：** 各时间点区域叠加图和同视野变化曲线。
- **验收重点：** 面积与人工mask对照，错误时间配对被识别；图像中的闭合不能自动解释成纯迁移效应。

此处首次真正需要时间序列配对，确认实际需求后再扩展公共数据结构。

### 第五项：克隆形成与Transwell

两者都可能涉及分割/计数，但必须分开模板。ColonyArea测的是孔内覆盖面积并考虑强度，**不是克隆个数**；不能把它直接贴上“克隆计数”标签。[ColonyArea官方说明](https://imagej.net/plugins/colonyarea)

- **克隆形成材料和问题：** 完整培养孔图、孔边界、原计数/覆盖率；确认端点是数量、面积还是强度，粘连克隆怎样处理。
- **克隆候选模块：** 孔检测/裁剪 → 背景与阈值 → 克隆分割/计数，或覆盖面积测量 → 按孔汇总。
- **Transwell材料和问题：** 染色视野、孔/膜/样本对应、人工计数；明确膜孔、碎屑、重叠细胞和取景规则。
- **Transwell候选模块：** 有效视野 → 细胞识别/筛选 → 每视野计数 → 每膜/样本汇总。
- **第一版交付：** 目标轮廓/标号与结果表，数量和面积字段分开。
- **验收重点：** 对照人工标注；同一孔/膜的多个视野不能凭数量充作多个独立重复。Transwell具体软件方法尚待单独实测。

先从前面的二维对象测量提炼复用，不预先假定一种分割算法适合所有染色图。

### 第六项：IHC阳性率/面积

可对照QuPath：标注组织区域 → `Analyze > Cell detection > Positive cell detection` → 设置检测参数、测量部位和阳性阈值 → 查看测量结果。核标志物与膜/胞质标志物的测量部位不能混用。[QuPath细胞检测教程](https://qupath.readthedocs.io/en/stable/docs/tutorials/cell_detection.html)

- **先拿材料：** 原始切片/扫描文件、染色信息、像素尺度、组织/细胞参考标注、原软件工程和结果。
- **重点问清：** 阳性面积、阳性细胞比例还是H-score？哪些组织纳入？染色分离、弱/中/强阈值如何确定？
- **候选模块：** 切片读取 → 组织ROI → 染色分离 → 细胞或像素分析 → 评分/汇总。
- **第一版交付：** 一种固定染色和端点的ROI结果；整张超大切片分块与病例汇总随后扩展。
- **验收重点：** 独立标注/评分、不同染色批次及组织排除。不能把普通图像计数结果当作病理结论。

### 第七项：流式细胞术

流式处理的是事件表，不能沿用二维图像模型。FlowJo提供Graph Window、轴变换、门和门层级、统计输出，这些是要逐项记录的实际操作。[FlowJo Graph Window](https://docs.flowjo.com/flowjo/graphs-and-gating/gw-overview/)

- **先拿材料：** FCS、通道/标记表、补偿或解混信息及对照、现有门层级、软件workspace和结果表。
- **重点问清：** 补偿/解混在哪一步完成？显示变换是什么？每个门依据什么对照？阳性率分母是哪一级父群？
- **候选模块：** 事件读取 → 已验证补偿/变换 → 质量/单细胞等门 → 目标群门 → 频率和强度统计。
- **第一版交付：** 一套明确panel、固定方法的门树和表格复现，随后再研究跨样本自动调整。
- **验收重点：** 与参考软件逐门核对事件身份和分母；不能只比较最终百分比。补偿/解混算法与workspace兼容能力还需专项调研。

## 3. 每次调研结束才能确定的开发清单

每个实验至少形成五项简明产物：**一份真实输入和输出对照、逐步操作表、方法/参数来源、现有模块差距表、可验证的第一版模板。** 不要求收集完所有实验室才开发，先覆盖一个明确场景，再用第二批和第二实验室检验复用。

把每个操作归为“已能复用、只需适配、新算法、尚需人工判断”，然后只开发缺少的部分。先保存所选方法和参数；有证据的自动估参再独立加入；没有依据的判断不得交给Agent随意补齐。

公共能力优先跟随真实需求出现：WB先需要样本/膜/重复表与统计出图；IF需要对象mask与测量表；孔板需要孔位；划痕需要时间配对；IHC需要大图组织区域；流式需要事件与门树。它们共享工作流执行和来源记录，不共用一个包办所有实验的数值模型。

每完成一个模板，证明它能保存、重开、替换新数据、自动运行、解释失败和回溯结果，再进入下一实验。具体发布、数据用途与外部服务授权仍按原任务范围，不因本路线自动扩大。
