# 公开开发数据使用入口

[机器登记JSON](../../work/evidence/B-007/public-development-data.json)覆盖WB、IF、核计数、细胞计数、克隆、划痕、qPCR、ELISA、IHC、流式，共17个具体记录。每条含版本/下载入口、格式、标签、许可、实际读取情况、可用/不足用途及留出单位。具体操作见[主方案第8章](research-platform-rd.md)。

登记包含受限、不可访问及未解码候选；不得把全部记录直接投入商业训练。已解混FCS不重复补偿，RDML缺效率不默认E=2，核标签不冒充全细胞真值。同实验派生物分在同一集合；公开测试集不自动具有独立性。

B007实际取得五份轻量文件，逐项验证见sample-download-verification.json及主文记录；文件保存在用户本地交付，不在本仓库再分发。按download_url、许可和用途获取自己的受控副本，放.local/datasets，保留原字节/摘要/署名。JSON中的local_file/历史绝对路径只描述原检查环境，不是本仓库可访问文件。

成功下载、正确解码和科学方法通过是不同状态。初始开发先取得正确配对、版本与小样，再按方法补独立标注和留出；不要整库无界下载。
