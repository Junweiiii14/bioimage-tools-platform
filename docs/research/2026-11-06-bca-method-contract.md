## 冻结候选的计算口径

1. 一块96孔板；本候选固定标准浓度0、25、125、250、500、750、1000、1500、2000 µg/mL，零标准角色为blank；每水平与每样本至少2技术孔。这是简化研究入口的选择，不是厂商强制重复数。空白不再作为独立未知背景或另一零标准重复扣除。
2. 每孔保留原始A562；减所有blank孔均值。不裁成0、不移除离群值。按浓度聚合标准的校正A562均值，零点均值为0。保留各标准孔偏离均值的残差供查看，不以插值穿点的R²充当质量验收。
3. 按浓度升序，校正标准均值必须严格递增且有限；否则整板失败，不能按吸光度重新排序、取绝对值或换模型兜底。逐点分段曲线无回归系数、无拟合权重、无强制全域截距。反算交换横纵坐标直接调用interp，仅因单调分段线性曲线可唯一求逆；不是浓度对吸光度的OLS。
4. 每个未知孔先扣空白、反算，再乘样本预稀释倍数。浓度指加入工作液前的被测样本溶液，**不乘225/25、10/3或工作液稀释倍数**。原样本浓度=被测溶液浓度×明确的预稀释倍数；µg/mL转mg/mL仅除1000。
5. 首版支持的估计范围收窄为最低非零标准25至2000 µg/mL（含端点），不把厂家20强行当已校准下限。0–25区间包括有效数值0也不得输出成有效样本定量；保留低范围原因。超出曲线吸光度区间不外推，不钳到0/2000。LoD/LoQ均UNKNOWN，不套P017软件阈值。
6. 同样本同稀释倍数的全部技术孔都在支持范围时，汇总逐孔原样本浓度均值和样本SD（ddof=1），n是技术孔数。不先平均吸光度再逆算；分段拐点附近两者不等。任一孔范围受限则样本汇总留空且标partial，不悄悄忽略坏孔；仍保留其他有效孔。没有生物n、显著性或置信区间。

## 最小输入与输出候选（尚未实现解析器）

UTF-8长CSV，一行一个实际使用孔，空孔不补零；[透明合成例](../../work/evidence/P-018/results/synthetic-input.csv)只演示格式。板级伴随记录含method_id、kit/SOP版本、25/200 µL、37℃/30分钟、562 nm、标准/样本/空白稀释液身份、同处理及基质兼容依据、仪器与读数日期、原文件摘要。实际未知的实验事实不能被候选默认值自动填成已确认。

| 列 | 含义及入口规则 |
|---|---|
| plate_id / well | 唯一板ID；A1–H12规范孔号且不重复 |
| role | blank / standard / sample；blank是加工作液的0浓度标准，不是空孔/纯工作液 |
| sample_id | 非空身份；标准/空白按水平标识，未知样本显式ID，不从孔名推测 |
| technical_replicate | 同角色/身份下唯一技术重复标识；不能用作生物重复 |
| a562 | 原始、未扣空白、无仪器自动浓度换算的有限数值；缺失/OVER/NaN/Inf拒绝 |
| standard_ug_ml | blank必须0；standard为上述非零水平；sample必须为空，不填0 |
| dilution_factor | sample有限且≥1，标准/blank固定1；表示入板前预稀释，不是加入工作液后的比例 |

整板不支持：不同试剂/SOP/体积/孵育/波长、已扣背景、混单位、多板、多空白体系/不匹配稀释液、未知必要元信息。入口拒绝：缺列/缺孔值、重复孔/重复技术身份、标准集或空白不完整、有限性/稀释不合法、标准非单调。拒绝和不支持有原因，无浓度输出；不为复杂性创建通用schema或拟合选择框架。

正式适配的逐孔输出需回带全部输入身份及原值，附blank_mean、corrected_a562、标准均值/残差（标准孔）、assayed_ug_ml、original_ug_ml、status/reason。blank/标准浓度结果标not_applicable；样本数值仅research_estimate时填充，其他CSV空单元格、JSON null。范围状态至少below_supported_range、above_supported_range/outside_calibration；不能用0表示失败。板级保存固定方法/API版本、原文件摘要与UNKNOWN质量限制。

样本输出：sample_id、dilution_factor、n_total、n_valid、mean_original_ug_ml、sd_original_ug_ml、status/reason。有效n不足或partial则均值/SD留空；已知有效单孔不因此变成零。输出必须新目录保存，原表和旧成果不可覆盖。图仅表达标准点/曲线与技术重复，无科学通过图章。
