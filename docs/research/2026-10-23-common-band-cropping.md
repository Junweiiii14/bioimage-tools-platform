## 1. 要解决的问题与用户确认的取舍

用户要求在实验室常见项目中减少人工框选：明显主条带应优先于规整阴影，细弱干扰不应频繁中断整批；修复旋转，并把来源、原值裁剪、展示图、单 Fig/完整拼图、灰度表与恢复包按 Fig 和蛋白名交付。

验收单位是**完整项目**。用户明确目标是：**至少 80% 的项目内部，所有计划裁剪均 100% 自动通过，无逐图确认、手画框或手调角度；少部分项目出现错裁可以接受，并可事后修正。** 这不等于 80% 的图通过，也不等于每个项目有 80% 的图通过。不能将每个 Fig、每个采集组或同图不同来源拆成独立项目来提高指标。

该取舍允许选择较积极的自动采纳策略，不能继续把“零错裁”隐含设成放行前提。但“自动通过”只是工作流事实，不等于实验者审核或蛋白身份正确。保留 `reviewed=false`、算法版本、采用的候选及必要诊断，保存原始证据和手动修正能力。错裁风险的接受不授权修改原始像素、按信号强弱删除实验组、把失败填成有效零值或覆盖已完成结果。

## 2. WB 常见目标与裁剪规范

WB 通常检测目标蛋白是否存在、表观大小及相对丰度，也用于比较处理组表达、敲低/敲除效果或蛋白修饰。抗体特异性和实验上下文参与目标身份判断；图像显著性只能帮助定位。[S1、S6、S7]

因此，本轮可优先覆盖“蛋白、Fig、来源和样本数已由实验清单确定，目标为一个明显主条带行”的工作流。没有证据表明任意实验室中这一类恰好占 80%；80% 是用户的产品目标，需要独立项目验证。

| 事项 | 证据支持的要求 | 本轮产品落点 |
|---|---|---|
| 裁剪范围 | 不应贴着条带过度裁剪，应留上下背景及解释所需上下文。[S3] | 检出主行后保留合理边缘，不用“刚好只剩黑条带”作为成功标准；原图与裁剪轮廓一起归档。 |
| 分子量/完整来源 | 保存完整来源，目标、样本、分子量可识别；切膜来源需保留目标上下 marker 上下文。[S2] | 有 marker 信息则保存，缺失时如实记录；本轮不自动伪造 marker 或宣称出版规范已全部满足。 |
| 多膜/泳道拼接 | 不同膜或曝光分面板；非相邻泳道重排应明确标识。[S2、S3] | 默认保留连续行及原泳道顺序；Fig 排版与来源对应，不无标识制造连续膜。 |
| 图像调整 | 调整不能隐去科学信息，且应一致作用于整图。[S3] | 显示变换独立记录；不单独提亮弱泳道、擦掉背景条带或拉伸个别条带。 |
| 内参与定量 | 目标和参照均需在适当线性范围，内参可能饱和或随处理改变。[S5] | 保留现有明确参照配对；数字截断检查不能冒充实验线性验证；不把白光或任意合并图当总蛋白归一化。 |
| 弱/阴性泳道 | 阴性对照、敲除或抑制处理可能本来就没有明显目标信号。[S7] | 主行中的全部计划泳道仍保留；不要求每条泳道都有强峰才能完成几何裁剪。 |

没有跨期刊统一的“上下留 X 像素”裁剪标准。S4 讨论上下约 5–6 个条带宽度的建议，并强调 marker 和完整原图；这是作者建议，不能直接变成唯一软件高度。当前 `5N:4` 固定框是既有版式/工程约定，也不是期刊普遍标准。工程实现须审查它与大倾角、完整支撑和上下背景是否冲突，不能用规范为现有比例背书。

用户的“很不明显的不要管”落实为：不主动追逐远离目标的细弱杂点、不因它们单独阻断明显主行；不意味着从裁图中擦除这些像素，也不意味着删除同一目标行中的弱表达或阴性样本。

## 3. 当前开发基线与结论强度

本机基线报告记录 Windows 11 `10.0.26200`、Python `3.12.14`、`tifffile 2026.9.20`。报告基线提交同上，确认原文件 SHA 未改变。本研究仅阅读既有报告及其诊断脚本，没有重跑当前算法或将执行者报告当作独立科学真值。

- 共有 21 个诊断 case：9 个采集组分别选两种来源共 18 次，以及 3 个 PNG 转换副本。
- 当前策略 3/21 自动采纳，3 个 PNG 转换副本均未自动采纳。该结果仅是诊断放行数，不能写作 3/21 个独立项目成功、准确率或目标蛋白识别率。
- 诊断泳道数 N 在运行前依据视觉暂定：9 组依次为 `4,4,2,2,5,5,5,4,4`，3 个 PNG 暂定为 3。它们**不是实验者已确认的 metadata**，不能反过来作为证明 N 检测错误的绝对真值，也不能调整 N 只为让新算法通过。
- 拒绝标记包含 N/证据冲突、间距/目标行/方向歧义、额外信号和独立几何验证失败。标记描述程序分支，不足以单独证明原图没有可裁主行，也不足以证明具体阴影成因。
- 同一采集组的两种来源高度相关；当前两批素材尚未形成可推广的独立完整项目集。

PNG 转 TIFF 的要求是无损保存已解码数组、形状、dtype 和通道，同时保留 PNG。它不恢复导出前已经丢失的采集位深、曝光或动态范围；不能用 TIFF 扩展名把显示来源变成已验证的定量采集来源。当前数组相等证据与转换说明保存于本地输入清单，采集来源未知状态需继续保留。

## 4. 备选方法及本轮选择

| 备选 | 判断 |
|---|---|
| 只降低旧阈值、直接采用最强投影行 | 不采用作为完整方案。会同时放大规整阴影、膜边和过曝光结构；无法解释为何是目标主行。 |
| 所有弱组件都必须被排除或解释后才继续 | 不作为新默认。现有保守机制会使一张不确定图中断完整项目，与用户明确取舍冲突。旧结果和策略读取仍保留。 |
| 对原图做增强、抹背景或旋转后直接定量 | 不采用。改变测量依据且破坏来源追溯。 |
| 为少见复杂条带训练模型或扩充大型依赖 | 本轮不优先。当前没有可独立验证的标注项目库，也没有证据证明重型模型能解决该失败机制。 |
| 明显主行的多尺度证据、统一方向与固定样本结构，积极自动采纳 | 选作小实验与实现候选。具体参数必须由本地有界对照确定并版本化；本研究不声称其已优于旧算法。 |

候选管线：

1. **保留输入身份和实验配置。** 来源身份、可读性、像素范围、文件写入及用户已确认 N 属于可验证契约；不通过猜来源、漏槽或伪成功换取自动通过。
2. **在定位副本上比较不同背景尺度。** 用局部峰相对邻域的突出程度、条带宽高、跨泳道行一致性、膜边/广域阴影位置共同评分；不得把“形状规整”本身当阴影证据。背景模型只参与定位，不替换原值数组。
3. **用明显支撑估计整行和倾角。** 允许弱/空泳道沿固定样本结构保留。一个强条带也可能有效，不能把固定数量的阳性条带设为科学规则。倾角须由实际目标支撑核对；不机械沿用旧 ±10° 限制，也不让白光边缘方向替代主条带方向。
4. **主候选足够明确时自动继续。** 对次要细弱组件给非阻断记录。多候选时可按已声明的“常见主行”策略选择高评分候选，并保留排名与歧义证据；接受少数错误，不能把每个软歧义重新变成确认弹窗。明显不存在合法裁剪区域、源损坏、坐标越界和保存失败仍准确报错，其他可处理项继续。
5. **几何裁剪与定量质量分别提交。** 可以裁剪完成且测量保留低信号/饱和/边界风险状态。低信号不等于裁剪失败；工作流自动采纳不等于有效定量。前端不把这些状态合并成同一个红色阻断。

## 5. 科学影响与可少管的场景

| 变化 | 可接受的收益/取舍 | 必须保留的边界 |
|---|---|---|
| 更积极选择明显主行 | 减少弱杂点导致的暂停，少数项目可能选错行 | 记录所选候选和算法版本；原图、来源、候选和后续修正可追溯；不宣称蛋白身份已验证。 |
| 不要求 N 个强组件 | 支持真实弱/阴性泳道以及连接条带 | N、槽位顺序和空位保留；不能自动删除弱样本以获得“整齐”结果。 |
| 扩展倾角与统一显示拉正 | 解决明显倾斜主行，旋转反馈可见 | 主框/预览/导出同变换，原值采样映射回原图；边缘缺失不以填零补成测量值。 |
| 质量提示不阻断全部裁剪 | 项目更可能全自动产生裁图及文件夹 | 饱和、无效、未检出、失败仍区别表达；没有有效数据时不造数。 |
| 原值裁剪与展示裁图并存 | 简洁拼图与完整复核材料都能交付 | 预览不能替代原始图，所有来源都按原身份留存；同坐标关系未确认的辅助图不套用错误裁剪。 |

本轮可不追求自动解决：微弱信号挽救、密集多目标/异构体的生物解释、复杂弯曲膜的非线性拉直、未知 marker 的自动分子量校准、多曝光融合、跨膜定量、任意重排泳道。保留原材料和常规手动修正即可，不为这些场景增加整批强制确认。

不能作为“少见规则”删除的是：原始输入保护、同一目标行的弱/阴性样本、来源对应、非相邻拼接标识、显示/定量分离，以及缺失/失败不转零。这些属于结果含义和可追溯性，不是追求零错裁的特殊几何规则。

## 6. 完整项目 KPI 与有限验收

先冻结实际项目边界、计划裁剪清单及来源选择。项目是实验人员原本组织和交付的一次完整工作，不能事后按检测表现拆分，也不能把同图的不同曝光/来源副本当新项目。

设纳入的完整项目数为 P，同时记录三个项目级指标：

- **A：整项目自动通过率** = 无裁剪人工确认且全部计划裁剪均产出结果的项目数 / P；用户目标 A ≥ 80%。某项目即使只有一张要求确认，也不算 A 成功。
- **B：整项目无需修正率** = 独立查看后所有裁剪均无需修改的项目数 / P。B 用来衡量正确程度，不能把 A 冒充 B。
- **C：错裁项目率** = 至少一处错行、阴影误选、明显截断或错误槽位的项目数 / P。用户接受少部分项目错裁；本轮不能擅自将 C = 0 设成目标，也不能不给 C 或把漏检隐藏在自动通过里。

冻结自动化统计后再做独立核查；核查只是测量 B/C，不重新计成算法运行中的强制人工步骤。保留首次结果，修正后的正确图不能反写为首次自动成功。另列 I/O 错误或源缺损数量，不悄悄移除这些项目来提高分母表现。

测试分阶段、有新假设才补测：

1. 使用已有一次当前版本基线，按逐例失败原因选择有界候选实验，不无目的重复全量重放。
2. 候选确定后，对同一开发全集做一次新旧对照，核对明显主行与大倾角、弱槽保留、阴影误选和处理时延。该结果只证明开发样本表现。
3. 用少量完整且未用于调参的真实项目作首次项目级观察，覆盖真实项目大小；已有多少完整项目就如实报告多少。可先观察 5–10 个可用项目，不把这个数量误称统计上足以证明普遍 80%。来源不足时明确未外推验证，不反复生成旋转/加噪副本凑项目数。
4. 定向自动测试集中于原像素不变、大倾角坐标映射、阴影与主行竞争、弱/阴性槽位保留、恢复与取消/失败身份保护。最终按仓库要求跑必要完整检查，不因软歧义策略变化削弱 I/O 或数据一致性门禁。

逐图通过率和失败原因可用于诊断，但不能代替 A。项目越大，任何一张被软规则阻断越容易导致整项目不达标；因此新方案需改善流程的连续性及候选采纳，而不仅提高局部检测分数。

## 7. 当前决定、限制与重新核验条件

决定：采用“常见明显主行优先、软风险非阻断、保留完整来源及修正能力”的方向开展小实验，结合旋转和完整项目交付落地。参数、角度范围、裁剪几何与新算法版本由实验及独立影响审查确定；本文未运行候选算法、未完成科学独审，也未证明 A ≥ 80%。

重新核验触发：目标蛋白/来源类型或实验任务改变；新增弱信号/多目标模式；改变默认背景、阈值、框比例、角度或采样方法；改变归一化；出现系统性阴影误选或整项目错误集中；期刊投稿目标变化。变更须给出版本和旧项目兼容，不静默重算历史结果。
