# Qt 宿主线程归属

选择 QObject worker 移到专用 QThread，QueuedConnection 按发送顺序处理明确命令。
Workspace/SQLite 从创建到关闭均在该线程；GUI 只收不可变值、字节与请求 ID。
来源：[Qt for Python QThread](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QThread.html)，访问 2026-10-14。
线程 finished 清理 worker，主线程不 wait/terminate；调用方保留端口直到 closed。
