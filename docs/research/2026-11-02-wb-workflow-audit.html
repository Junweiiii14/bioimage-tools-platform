WB实际分析流程与现有模块对照

2026-11-02 · B-014 · 规划资料，未同步开发窗口

1. 先说结论§

我们已有WB分析的基础，不需要全部重做。接下来主要做三件事：核对实际实验室的测量方法，把已有功能接入编排，补上目前缺少的实验数据汇总与统计。

本次查阅了ImageJ、Bio-Rad、LI-COR、GraphPad和Adobe的官方资料，并只读核对实际开发树的代码、契约及测试。下面是有来源的典型流程，不是假定所有实验室都使用同一套方法。

本次没有操作原软件重跑实验，也没有实验人员访谈。ImageJ菜单依据其公开文档及1.46r指南；Bio-Rad操作依据2017年Bulletin 6434；Prism在线指南本次显示为11版。真实接入前还要确认实验室安装的版本和设置。开发树HEAD为5d5dd226a7dc6bf16879c16257a0d3754b814ff3，P-008仍在开发；本轮未写该树、未发送开发消息、未运行其测试。

2. WB完整的数据处理链是什么§

从成像结果开始，可以分为：

登记样本和原图 → 检查采集质量 → 定位泳道/条带 → 扣除背景并测量 → 内参归一化 → 对照组换算 → 汇总独立实验 → 统计和作图 → 排版与归档。

其中测量有几条不同路线。ImageJ的泳道峰面积、矩形区域像素总和、Image Lab的条带体积，不应当混为一个叫“灰度值”的指标。用户可以选用经过验证的一条路线，不需要把下面所有方法串在一起。

路线A：ImageJ/Fiji测量，再到表格和Prism§

步骤 软件和功能 实际怎样操作 要保存什么
1 登记实验 仪器软件＋实验记录/Excel 对上原图、曝光/通道、膜、蛋白、泳道、样本和分组；保留原文件 原图和采集信息；样本对应表。仅凭文件名不能确认配对
2 检查图像 ImageJ打开图像、查看信息和直方图；仪器采集记录 核对位深、通道和信号范围；用采集端信息及稀释系列判断是否适于定量 曝光选择与质量记录。没有满量程像素不等于一定处于线性范围
3 选择第一泳道 ImageJ矩形选区、Analyze > Gels > Select First Lane 框完整的第一条待分析泳道 原图坐标和宽高
4 选择其余泳道 Select Next Lane 移动同尺寸矩形逐条登记 泳道顺序和对应样本

9 汇总和统计 Prism Column/Grouped表、Analyze 按实验设计组织数据，再选配对/非配对及比较方法；输出单点图和统计表 独立重复身份、检验方法、比较集合、效应及不确定性

步骤3—7依据ImageJ Gel Analyzer操作说明。步骤2中的位深与显示区别见ImageJ图像菜单；采集线性范围需单独验证，见LI-COR定量归一化说明。步骤8是本平台已有公式的使用方式，不声称所有软件采用相同归一化标尺。

复现ImageJ时还要保存Gel Analyzer Options中的曲线缩放、Invert Peaks、Uncalibrated OD等设置，不能只留下峰面积。ImageJ Gel选项

统计时，单一分组变量可用Prism的Column表，两个分组变量可考虑Grouped表；再从Analyze选择分析。显示每个独立数据点能帮助看清分布。Prism数据表、分析入口、单点图。具体检验不能只凭“有几组”自动决定。

例如，实验设计和数据确实适用非配对t检验时，在数据表点Analyze进入相应t检验，再设置配对关系、分布假设、方差处理和单双侧，并保存结果。这个例子用来记录操作，不作为所有WB实验的默认统计方案。Prism非配对t检验操作

路线B：ImageJ矩形区域测量§

在Analyze > Set Measurements选择Area、Mean、Integrated Density，分别框条带和背景，再Analyze > Measure。RawIntDen表示原像素值之和；它不是泳道曲线面积。ImageJ测量定义

如果选定“局部背景校正的像素总和”方法，先声明信号极性，再用同一强度定义计算“条带像素总和－条带像素数×背景平均强度”。背景选区的位置、大小和避让邻带的规则必须记录。LI-COR也提供局部均值、中位数及用户指定背景，但这些选项不能仅因名称相似就与ImageJ或本平台互换。LI-COR背景方法

若实验室用Process > Subtract Background，还需记录半径、亮背景等选项，并核对扣背景后的中间图；这是另外一种图像预处理，不默认叠加到前两种方法上。ImageJ背景扣除

路线C：Image Lab内完成检测和归一化§

Bio-Rad公开的总蛋白归一化操作示例是：打开化学发光图与stain-free图 → Lane and Bands → 在Normalization Channel中Add channel → 把stain-free图放到Normalization Data → 检测泳道与条带 → 必要时用Adjust Frame / Resize Frame修正 → 选择Normalization Lane → 在Analysis Table查看并导出Excel。修改泳道后，要重新检测该泳道的条带。Bio-Rad快速指南，1—3页

这条路线需要额外的总蛋白图像及对应关系。“磷酸化蛋白/对应总蛋白”与“目标蛋白/全泳道总蛋白染色”是两件事。 我们现有代码具备前一种比值语义，没有据此证明后一种分析已完成。

排版操作应放在分析之后§

Illustrator可通过File > Place置入多幅图，再完成文字与版面编排；Photoshop的File > Automate > Batch可以批量执行已记录动作。它们适合承接重复出图操作，不能替代实验定量方法。Illustrator置入、Photoshop批处理

输出时保留足够条带上下文，明确标记泳道拼接，说明误差线和重复类型。这些信息应进入我们的出图模板。ASBMB图像与数据呈现要求

4. 为什么必须核对具体测量方法§

当前核心先对泳道每行取平均，再对线性基线以上的正差做梯形积分，不乘泳道宽度。代码在domain/lanes.py:44和domain/quantify.py:57。

举一个独立算术例子：宽度4像素，每行强度依次是10、20、30、20、10，背景为10。本平台定义的曲线积分为40；同一区域按“总像素和减背景”则为160。它们描述不同量，不能看到数值不同就判算法错误，也不能修改旧结果强行对齐。这个例子只是公式说明，不是原软件对照实验。

再如现有归一化先算q=目标信号/参照信号，可再算f=q/对照q的均值。这部分已有实现；缺的是完整实验身份和编排接线。每张膜各自归一化为1的对照值，也不能不加说明地当作一组有独立变异的原始观测进行检验。

所以模块必须在名称和输出中说清“测量的是什么”。建议用户看到“泳道曲线积分”“矩形背景校正总信号”“目标/内参比值”，而不是所有节点都输出含义不明的“灰度值”。

以下为调研后的建议工作顺序，不是本轮派发的任务，也不改变P-008/P-009。

顺序 要交付的东西 怎样做 完成证据
WB-R1 真实方法对照 一份本实验室WB操作记录和对照数据 从现有材料选一条流程；补软件版本、原图、ROI/基线、测量表及配对；按原操作复现 能解释每个结果来自哪一步；原软件重跑结果可查

自动找泳道、自动校正等可以在各自任务中提高自动化程度，但不必作为上述已知几何数据链的统一前置。标准样本默认自动跑，异常样本才需要可选纠正。

6. 原软件能力怎样变成我们的模块§

优先复用已有Python能力；需要忠实复现ImageJ操作时，先用Plugins > Macros > Record记录操作，提取参数，再按官方批处理方式对另一批文件运行。宏只是实现来源之一，仍需把输入、参数、输出和失败情况接到现有执行器。ImageJ宏批处理

第一版可以把一段完整的已验证宏封装成一个模块，不必每个按钮一个节点。ROI和背景如果原来靠人工选择，就必须变成明确输入或经过验证的定位步骤；录下鼠标坐标并不能解决新图位置不同的问题。

Image Lab、Prism和Adobe软件的安装、许可、脚本能力应在接入时逐项核验。本次确认了其功能与公开操作，没有确认商业软件存在适合我们使用的无界面API。能够导入导出结果，也是一条可先实现的连接方式。

7. 已有材料能支持什么，还缺什么§

只读文件清单发现，本机WB资料已有TIFF原图、Excel表、Illustrator文件，以及既往平台生成的裁图和验证记录。这说明有材料可以开展下一轮流程复现；本次没有读取表格具体结果或解析AI文件，不能由扩展名推断软件版本、测量公式和真实操作顺序。

下一轮只需围绕一份代表性实验补齐：原图和采集信息；样本/膜/蛋白/重复关系；原软件版本；操作录像或逐步记录；ROI与背景；软件导出的数值；最后统计图。优先包括普通条带、多峰/拖尾、较强背景或过曝问题样例。没有对照结果时先做工程验证，不能宣称与实验室流程等价。

本次未进行外联、上传私有原图、安装或启动第三方分析软件。Bio-Rad完整用户手册网页读取超时，因此本文具体操作使用可读取的官方快速指南；没有依据第三方转载补齐缺失操作。

后续实验建议顺序及每项要调研的内容见实验调研与开发路线。当前主方案仍保持简明，这份文档作为WB实例附录。
