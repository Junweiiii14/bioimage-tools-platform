# 第二实验：需求比较与 CPU 方法探针

P013 · 2026-11-05 · **最小实验完成，集成验收待完成**。问题是选出值得下一轮验证的完整学生任务，不是证明已有第二工具。当前三个候选均缺本校学生频率、现行处理耗时、独立试用及付款证据；文献中的问题不等于本项目的市场需求。

## 暂定取舍与完整任务

研究主选为 **2D 单通道荧光核计数**，备选为 **一种明确实验的孔板终点读数整理**。前者有明确许可的独立人工核标注，便于先检验方法；后者计算量小，但必须先确定实验类型及空白/对照公式。IF 蛋白强度不是核计数的同义词，暂不把它放入首个可交付范围。划痕保留，原因是时序身份、漂移、组织纹理和闭合定义叠加，现有来源尚不能提供足够明确的批量独立参考。

下列是待验证的产品流程设计，不声称已实现或经过学生访谈。

| 候选 | 输入及必要身份 | 自动步骤与质量失败 | 学生最终成果及重开 |
|---|---|---|---|
| 荧光核计数/区域强度 | 原始灰度通道；样本/视野/通道身份、尺度、对象定义；若汇总则明确独立样本与技术视野 | 读取位深→分割→实例计数→原像素区域测量；检查空图、饱和、密集粘连/碎片、边缘对象，未知尺度只报 px；不能把视野数当生物 N | 原图边界叠加、逐核面积/原始均值和积分、逐视野数值、按明确身份汇总；导出 CSV/图与方法版本，保存输入摘要及草稿，重开读已提交结果 |

## 最小实验与判定边界

预声明见 [experiment-plan](../../work/evidence/P-013/experiment-plan.md)，执行代码及固定依赖位于同目录。采用官方 validation 前 3 / test 前 12（各自按名字排序），不使用训练集，不在测试集调参。对照为连通域，候选为固定参数 watershed；人工标注来自独立数据作者。以实例 IoU >0.5 匹配统计 F1 和计数误差；原始 ADU 只演示测量，不声称独立强度验证。

实际 Windows/Python 3.12.14 CPU 运行，12 张 test 共人工标注 1395 核：连通域 micro F1=0.8161、平均绝对计数误差23.17、逐图平均相对误差20.93%；watershed F1=0.8722、绝对误差9.50、相对误差10.45%，TP/FP/FN=1167/114/228。3张 validation F1 分别0.7967/0.8654，不与留出混合。两个方法使用同一前景处理，只能说明该固定分水岭在这个子集改善，不是跨实验优势证明。

**平均值掩盖了重大失败：A12_s7 人工69核，预测20核，计数误差71.01%。** [失败面板](../../work/evidence/P-013/failure-example.png)可见小核/成簇对象未被正确分开；这是视觉观察而非已证明的唯一根因，不能删掉该图再报告。下一项优先针对小对象/密集和亮度异质性的失败分层、用 development 数据比较现成方法，并另保留未见测试数据；不应立即声称全自动核计数已经足够可靠。

最终重复运行的逐图指标和逐核强度 CSV 与前次逐字节一致。15张各图的两种分割合计耗时约0.043–0.055秒（不含读取、评价、导入、下载；未测峰值内存或目标机），不是桌面响应预算。完整逐图指标、环境、原始归档/选图 SHA256 和复现步骤见 [探针收据](../../work/evidence/P-013/README.md)。原始强度无独立参考，不能因 CSV 一致宣称科学准确。

下一实现任务只在结论形成后拆卡：建议首先限于单通道二维核计数的完整练习闭环，明确标注研究/未准入，不自动扩为 IF 相对表达；输入不猜组别，逐图错误不能填零，原始像素不进显示变换，导出重开一致。方法若不能满足预先认可的参考要求，则下一项应是失败分层与方法比较，而非立即上学生产品。

最小缺项是一个明确使用者的代表输入/目标输出和核对象判定、独立参考及可接受误差；由已有渠道后续取得，不为本研究擅自外联。若孔板先取得真实目标 assay、布局和独立参考，且重复任务价值明确，则可取代核计数主选。取得新实验/新位深、升级算法依赖、改变阈值或引入强度校正时必须重新验证。

研究步骤采用 scientific-critical-thinking 技能区分方法、科学和市场证据；其程序化指引不是方法准确性证据。技能要求的出处：[Kassis 等，Scientific Agent Skills，arXiv:2609.00065](https://doi.org/10.48550/arXiv.2609.00065)，核验 v2（2026-09-02）。
