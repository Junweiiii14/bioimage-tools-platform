## 性能测量协议

基线标识T053/65ff278，记录Windows版本、Python/Qt、锁文件SHA、CPU和内存；合成输入可公开、私有输入只留本地摘要清单。E0测量冷进程导入wb_tool.api耗时20次，含解释器启动，不能称完整GUI冷启动；E6复用同命令同硬件比较。

E3–E6固定每源尺寸/位深/数量/总字节与修订，计解码/渲染调用次数、阶段时长、峰值RSS、取消至所属进程退出延迟、输出字节数。正式比较至少20次有效观测报p50/p95和波动；样本不足明确标明。首次观测为预热/冷缓存标签，不与后续混淆。

E6开始改性能代码前，在任务中冻结样本与阈值：默认同一指标p95与峰值RSS不回退超过10%，瓶颈耗时改善至少10%且超过基线噪声；若噪声超10%先稳定测量再优化，不事后抬阈值。原值像素、来源SHA、既有科学预期与状态必须保持，数值变化另立算法任务。E0导入指标仅作成本锚点，不承诺GUI/仪器批次速度。
