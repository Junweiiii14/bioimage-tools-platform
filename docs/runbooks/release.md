# 发布、兼容与恢复规则

当前没有产品包，此文为未来发布入口，不执行发布。

## 发布输入

明确 tag/head、干净源码、锁定 Python/依赖/编译器、通过的检查、绑定 head 的独立审查、已声明兼容范围。按任务提交版本/发布说明，不从未提交工作目录构建。

采用 standalone 目录包候选；P0 验证 pyside6-deploy/Nuitka、Qt 插件和 worker 两入口。编译器/SDK 的确切版本、签名证书和安装器在 P0/发布阶段确定；安装 Python 包不等于 C++ 工具链可用。

## 必需验证

- 无开发 Python 的 Windows 干净机：启动、加载合成样本、ROI、计算、取消、重开、导出。
- 中文用户名/路径、只读安装目录、125%/150%/200% DPI、断开的外部输入。
- 数值冻结集、历史 schema、失败/中断恢复、资源准入和真实备份恢复。
- 构建与原生库许可/通知检查；按实际分发方式确认所需义务。

manifest 记录：app/build/git/lock 摘要、Python/Qt/编译器、工具及算法版本、schema/协议/工作区支持范围、所有产物 SHA256、验证报告和已知限制。构建时间可变时不宣称字节级可复现，至少验证输入与行为可复现。

## 回滚

先保存不可变旧产物和迁移前副本。代码 revert 不能还原数据；新格式不被旧程序支持时使用迁移前副本或只读导出。恢复演练记录迁移后新操作是否丢失，不能隐藏这一代价。

无明确发布请求时只生成候选产物和证据。当前没有自动发布、生产账号、代码签名证书或后台自动更新器。
