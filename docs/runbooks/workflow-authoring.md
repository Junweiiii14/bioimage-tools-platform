# 工作流编排：5–10分钟操作单

适用工作台顶部的“工作流编排”。这是原始整数灰度WB流程的工程预览；合成样例验证软件链路，不证明真实实验准确率。原工作台项目与工作流项目分别保存。

## 第一次运行（约2分钟）

1. 打开“工作流编排”，选择“用合成样例新建”，保留triangle_u16，选择保存父目录。软件会建立新的“工作流-日期-标识”目录。
2. 目录中有原图预检、WB分析和成果发布模块；画布显示真实流程。点步骤查看版本、输入输出和参数。“参数”页的“当前步骤”也可切换步骤，适合窄窗口。
3. 点击“保存并运行”。等待真实执行回执；完成后打开“成果”，查看定量表和报告。该合成样例的参考积分值为4000.0。
4. “打开已核验文件”打开实际提交资产。大文件可能只提供文件链接；预览图仅用于显示，不进入定量。有效零、未标注和失败分别保留。

## 编辑并复用（约3–5分钟）

1. 修改流程标题；选择分析步骤，在表单中编辑泳道ROI和条带区间。ROI使用原图像素半开区间；条带左右端点是ROI内行坐标，包含左右端点。不要把显示预览坐标直接当原图坐标。
2. 表单可复制、删除泳道/条带；复制后需要核对标识和坐标。删除全部条目会形成不完整草稿，可从目录参数添加一项再修改。缺失的手动基线等可在“高级：完整参数JSON”中明确填写，用“将JSON应用到表单”刷新表单。
3. 点“保存”做预检。未完成的图可以保存，预检问题会阻止执行。输入法组词未完成时先完成输入，再保存；保存失败保留当前草稿。
4. 在模块目录“添加”，先点输出端口，再点目标输入端口连线。错误类型/单位/坐标系或循环在保存预检后解释。选择节点可替换目录模块或删除。节点标题上方向键移动，Delete删除；移动只改变布局。
5. 在发布步骤修改报告布局，只重新发布；修改分析参数只使分析及其依赖失效。运行冻结当时的修订，运行中后续编辑仍是独立草稿。
6. 保存后，在“项目与模板”选择“保存为实验室模板”，选择新的JSON文件。模板含计算定义和节点布局。
7. 选择“从实验室模板新建”，选刚导出的模板、一张新TIFF和保存父目录，点击“保存并运行”。也可在原项目选择“绑定下一批原图”（最多16个），再一次运行。批次中的坏输入单独报告，不伪装成功。

练习第二批可选择“绑定另一个合成样例”，其triangle_u8参考积分为40.0。模板绑定保留明确的泳道/条带参数；更换原图不表示参数自动适合新的生物学样本，需核对ROI与样本标识。

## 实际原图与运行控制

- “从原图新建”需先填写已知泳道数和极性，再选TIFF。初始参数来自既有WB方法的全图自动建议；需要核对，不能当作已验证的新几何校正或科学结论。
- 暂停先显示请求，再在安全节点边界暂停；已启动节点会完成或按取消流程结束。“继续”恢复同一冻结批次。关闭已暂停项目后重开，需显式继续。
- 取消等待真实进程退出和存储排空。关闭整个软件沿原有退出提示处理；仅“收起”编排窗口会保留工作和后台任务。
- “打开工作流项目”选择此前的工作流目录，恢复已保存修订。切换/导出前先保存草稿，或用“撤销未保存修改”。原图及历史成果不覆盖。

## 当前限制

首版最多64节点、16输入，执行预算仍由既有编译/运行契约限制，并非性能承诺。只提供当前受信目录中的WB原始整数图模块；不支持任意模块加载、新实验或Agent。科学留出/负责人认可、干净目标Windows、物理DPI/GPU和用户体验验收仍单独待办；本机工程检查不能代签这些结论。
