# 单图核分割研究工具

在当前源码桌面工作台首页选择“单图核分割”。本工具只接受单页、单通道、unsigned uint8、BlackIsZero、TopLeft TIFF。16位、RGB、多页或带其他方向标签的图像会被拒绝；不要先转8位再把显示图当原始输入。方法仍为固定 StarDist 研究候选，科学适用性未获准入。

首次使用由环境维护者按 [准备指南](../../tools/nuclei/README.md) 准备隔离运行环境及固定模型。进入“运行设置”，选择环境内的运行程序与包含 config.json、thresholds.json、weights_best.h5 的模型文件夹。设置按当前发行通道保存；没有自动安装或模型下载。此准备只需在环境配置或位置变化后进行。

1. 点击“选择原图”，选择一张支持的 TIFF，确认原图预览。
2. 点击“开始分析”。处理和保存均在后台，等待“结果已保存”。需要停止时点击“取消运行”，等取消完成后再选图。
3. 查看已保存核数，在“原图”和“实例轮廓”之间切换；缩放可选适应窗口、50%、100%和200%。实例轮廓使用原像素坐标，缩放不改变标签或核数。
4. 点击“导出表、图与标签”，选择项目以外的目录。软件另建唯一结果文件夹，包含 count.csv、原图显示PNG、轮廓显示PNG、uint32 labels.npy和完整provenance.json；PNG只用于显示，不能替代分析资产。
5. 在“保存位置与来源”展开查看项目目录、原图SHA和运行ID。关闭应用后，重新进入工具并点击“打开已保存项目”，选择该目录；读取同一已提交结果，不重新推理。

项目自动保存在文档目录的 BioImage/Projects 下，分析重试总是创建新项目。打开错误目录、导出失败或选择不支持的图像不会覆盖上次成功的资产；屏幕保留的“已保存核数”属于仍显示的旧图，并非失败操作的新结果。失败不补0，合法无核图像才保存核数0。原图改变后需要重新选择；运行中不能切换输入。

最小练习：从[三工具练习材料](../../examples/first-use/README.md)选择已提供的 nuclei/Ganglioneuroblastoma_10.tif，执行上述五步，核对已保存核数46和重开前后相同运行ID。这张图已经用于研究，只是工程练习，不是新的独立科学验证或学生试用。没有该资料时用自己的受支持原图练习，不套用46这一预期。
