# 统一工作台源码 MVP

P020 源码入口：在 `bioimage-plan-sync` 检出本轮候选提交后运行 `uv run --locked --no-sync python -m bioimage_app`（首次环境准备见 development.md）。当前包身份仍为 bioimage-app 0.14.0；准确源码提交见 P020 候选收据。此操作不会替换用户旧安装或更新其快捷方式。

首页三张卡分别进入 WB、单图核分割和 BCA。研究标记与环境准备分开；核分割首次在“运行设置→打开准备指南”查看实际说明，环境维护者准备后选择运行程序及模型。返回工作台保留当前项目和表单；退出软件才走宿主取消/保存保护。

可直接选择的练习输入与简短反馈入口见[三工具首次练习](../../examples/first-use/README.md)。

## BCA 最小流程

1. 进入 BCA，选择符合固定列顺序的单板 CSV。逐孔原始 A562、样本身份、技术重复和预稀释倍数必须明确。
2. 填写板记录，或加载与 CSV SHA256 对应的已有 JSON。固定 SOP 展示在表单上方，三个实验事实确认默认不选。加载记录会保留原摘要及其明确确认；更换文件不擅自改写这份摘要。需要另一板的新记录时点“新建空白板记录”。
3. 点击开始分析，等待“结果已保存并核验”。运行/取消/结果核验均由既有 WorkflowSession 和 Workspace 完成，失败不填零。原始 CSV 和历史成果不覆盖。
4. 查看技术样本表，展开逐孔与原因。µg/mL 浓度、partial、低/高范围与空值明确区分。显示最多七位有效数字，不回写计算；悬停可见原值，导出保留完整精度。
5. “导出表与来源”在所选位置另建唯一结果目录；包括逐孔 CSV、样本 CSV、出处 JSON 与运行身份。展开来源可找到项目目录，关闭软件后再次进入 BCA，点击“打开已保存项目”选择该目录。重开校验同一正式结果，不重算。

工程练习可选择 `tools/bca/examples/synthetic.csv` 与 `record.json`，它们是明确合成数据；不能把示例确认当成真实实验事实。S1 原样均值为 5008.680555555556 µg/mL，另外四组 partial 的汇总为空。固定方法的真实化学准确性、LoQ 和真人使用尚未验证。
