# 核分割与 BCA 工作流编排

源码入口：`uv run --locked --no-sync python -m bioimage_app` → 首页“工作流编排” → “项目与模板”。用户在用安装不会自动更新。

| 模块 | 画布节点 | 公开入口与方法 |
|---|---|---|
| 核分割 | 固定 StarDist 核分割 · 研究 | `nuclei_tool.api`；`nuclei_module_spec`、`read_nuclei_input`、`present_nuclei_result`；`stardist-fluo-p014@1` |
| BCA | Pierce25 BCA 浓度 · 研究 | `bca_tool.api`；`bca_module_spec`、`read_plate`、`analyze_plate`；API 0.1.1，`pierce25-point-v0-research` |
| WB | 原图预检 → WB 粗分析 → 发布表与曲线 | 原有 `wb_tool.api` 与 P009 流程保持 |

1. 核分割选择“核分割研究新建”，选单帧 uint8 灰度 TIFF 和新项目保存位置。环境/模型沿用首页核分割工具的设置；设置后重开工作流项目。缺配置时运行明确拒绝，不自动下载。
2. BCA 选择“BCA 研究新建”，依次选原始长 CSV、与该 CSV 摘要对应的板记录 JSON、新项目位置。字段与示例见 [BCA README](../../tools/bca/README.md)。不得把未知实验事实填成默认确认。
3. 左侧目录添加本实验方法；选择节点查看固定方法及端口，使用“将当前输入绑定到本步骤”。BCA 绑定 CSV 和板记录两端口，核分割绑定原始图。固定方法参数只读。方法本体作为完整节点，不拆出伪算法步骤。
4. “保存并预检”检查图；兼容端口才能连接，结果/来源不能冒充原图或 A562 输入。每种研究项目只列出其受支持方法；本轮不提供跨实验链或插件装卸。
5. “运行当前流程”沿同一后台 worker/Workspace 提交。打开“已提交成果”或选节点后“查看本步骤已提交成果”。核分割显示原坐标轮廓与核数，BCA 显示逐孔及技术样本表；完整方法/来源 JSON 在“运行与来源”展开。PNG 仅显示，不能进入定量。
6. “保存为实验室模板”只创建新 JSON，不覆盖旧模板。退出重开项目可读取原成果；“从实验室模板新建”选择模板及另一份合规输入（BCA 同时提供新板记录），生成独立项目。也可“绑定新输入”产生新修订；旧运行保留，不重写为新结果。

BCA `completed_with_issues` 表示已提交且存在质量限制，不表示执行失败，也不把 partial 的空浓度变为零。打开/查看成果核验请求、输入、所有输出资产和提交来源。核分割历史结果可在无模型环境时读取，运行新图才需要受信配置。

本轮是两种固定研究方法的图编排 MVP，沿用 P009 画布与执行器；不是完整跨实验编排、科学准入、真人验收或安装器交付。未升级依赖、改第三方算法/模型，未替换用户安装。
