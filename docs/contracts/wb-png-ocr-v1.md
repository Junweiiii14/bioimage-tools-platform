# PNG与生成拼图OCR v1

PNG仅作为OCR/显示输入，不扩展load_tiff或原图定量输入。实际PNG格式与CRC、SHA、单帧、左上方向均须核验；源文件上限64MiB，3200万像素/32768边长，沿用OCR最多64块。支持1/2/4/8位灰度/调色板、8位RGB/RGBA/LA和16位灰度；16位彩色PNG明确拒绝，避免解码器静默降位。损坏、动画、多帧、方向变换和预算超限明确失败，不改全局Pillow解码容错或保护设置。

PNG预处理ocr_png_white_bt601_u16_div257_tiles2048_overlap256@1：解码样本值，不应用ICC/gamma显示变换；8位透明像素合成到白底，然后整数BT.601灰度；16位灰度按原值除257，透明灰度键映射白色。读取前后同一文件流摘要相同，显示和OCR使用同一映射与原始坐标。保留未修改原PNG。旧TIFF沿用原预处理ID/语义，结果协议接受两种已知ID，拒绝其他ID；项目v4/v5字段不变，旧应用不承诺能识别新增PNG预处理。

“识别当前拼图”先保存精确项目修订，后台按正式导出布局/审核要求生成完整PNG，嵌入wb_provenance，含原图SHA/ROI/行身份/模板/生成修订。不得使用缩略预览代替生成源。通过通用异步import_bytes端口导入新不可变资产（64MiB预算，草稿仍16MiB），再走已有OCR保存/worker/退出/提交/复核通路。平台无新增实验字段。

生成或导入失败/取消/过期时不替换已有OCR；已生成未关联的资产可留历史。新源成功导入后，旧草稿/运行仍保留；新识别成功只给未确认、未绑定建议，不凭同名标签自动关联。保存或生成期间的后到回调不能覆盖新编辑，关闭必须等真实任务退出。PNG元数据仅作来源证据，不能控制程序或覆盖当前项目。原图测量/归一化配置保持。
