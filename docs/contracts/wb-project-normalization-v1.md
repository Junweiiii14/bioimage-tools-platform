# 项目归一化 v1

WBNormalizedProject使用项目schema v5，保存定量、可选OCR及归一化配置；v1–v4继续读。v4的OCR仍必填；只有v5允许无拼图进行归一化。派生值不嵌入项目，也不改原始run，重开由经验证的测量与保存的配置重新产生。纯公式版本lane_reference_ratio@1。

用户显式选择目标/内参或磷酸化/总蛋白模式，指定目标和参照两行。每行来源快照为row_id/SHA/整行ROI/N；变化后关系过期，须重建。不得按标签或同泳道序号自动确认，初始逐泳道的样本名与参照泳道均空、无对照、无确认。用户填写一对一映射，可保留缺失槽，明确包含与对照标记，再确认。名称仅用于展示，重复/空样本名不作为身份推断。

对当前有效测量T、R，先计算q=T/R。仅有限T>=0且有限R>0可计算；0目标合法，0/负/缺失/过期/质量复核分母无效。除法溢出或正数下溢为0返回数值错误，不加epsilon。两模式采用同一比值公式，模式记录生物参照含义；不输出磷酸化化学计量比例。

可选相对对照：单对照模式要求恰好一个显式对照；均值模式对选中对照的有效q取算术均值m，然后各样本f=q/m。所有选中的对照都必须有效，不能悄悄跳过坏对照。m必须有限且>0。没有对照或无效对照时保留合法q，但f为空并说明原因。只按用户选择的行内样本计算，不跨膜自动汇总，不计算显著性，不推断技术/生物重复。

目标、参照及对照的来源/run/修订、配置/算法版本与状态随表和导出保留。任一来源改变或标注重算时使用最新核验结果，绝不复用缓存旧值。确认撤回立即隐藏派生值。OCR标签视图仅在OCR证据校验、绑定当前且人工确认时展示对应派生值，底层原图行身份不变。

后台计算与XLSX导出，界面每页200结果，最大512行关系/96泳道；延用16MiB文档、每表200000单元格预算及新文件无覆盖发布。原始积分、比值、对照均值与相对值分列，失败/排除为空，不伪装为0。
