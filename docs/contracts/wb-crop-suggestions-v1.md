# WB 自动裁剪建议 v1 / 拼图项目 schema v2

算法标识 `membrane_periodic_profile_candidates@1`。这是工程候选算法，输出几何与复核提示；不确定蛋白身份、分子量或曝光用途，不产生定量值。默认阈值不根据实验任务单预期趋势优化。

输入为明确选定且 SHA-256 校验的原 TIFF 经既有 BT.601 转换得到的原精度二维 uint8/16；不使用屏幕预览。调用者提供 N（1..96）、固定裁剪高（2..4096）、暗/亮极性；左 Marker 默认勾选，SNR 阈值默认 4（2..12），默认不检测膜的上下边缘。所有计算在私有 float64 副本中进行，原数组不变。拒绝超过 1600 万像素。结果每张最多 8 行候选。

膜定位：最长边最多约 256 的步进采样，以四边灰度中位数作参考，绝对差做 256 桶 Otsu 与 6 倍稳健噪声阈值；取面积至少 1%、矩形填充率至少 55% 的最大四连通块，原尺寸行列覆盖率 50% 精修边界。整图占比 >95%、宽不足 N×4 或高不足两倍裁剪高时不猜边界。支持用户手框膜范围，输入范围必须在原图内。多个膜、触边、边界不明均保留状态。

候选信号：沿 y 的边缘复制滑动均值（半径=裁剪高）估计局部背景，按显式极性求差，再用半径 1 均值平滑。噪声为相邻差 MAD / 0.9538725524，下限 1。该背景仅服务检测，**不替代现有定量基线**。默认上下各忽略 min(高度/2, 膜高/8) 像素的边缘信号，可显式包含并重新检测。

泳道：取正信号沿 y 的 97% 分位列强度，阈值 max(噪声×SNR, 最大列强度×0.1)，筛宽度至少 max(2, 膜宽/总槽数×0.12) 的峰。总槽数为 N+左 Marker。峰与槽数均 2..24 时按等间距候选拟合，至少 max(2, ceil(槽数/2)) 支持，误差 <0.22 周期；否则明确标记等分回退。Marker 只是假设的左侧排除槽，不识别分子量。最终严格保留 N 槽，空/弱信号不导致移位。

行：逐泳道求均值 profile，噪声取 profile MAD 与原图噪声/√宽的较大值，任一槽 SNR 达阈值的连续 y 合并小于等于 max(1, 高/6) 的间隙，至少连续 2 像素。用截断到 20 的 SNR 权重确定中心；裁剪保持固定高度并限于膜内。排序为检测到的槽数降序、截断评分之和降序、y 升序。SNR≥阈值为检测到，2≤SNR<阈值为弱，<2 为可能空；这些是启发式状态，不是统计置信度或真实空泳道声明。记录越过裁剪高、数据类型上下限、多行、无候选、容量截断等提示。

`CropSuggestion` 保存 row_id、源 SHA、源项目修订、完整参数、结果或明确错误、所选候选下标。`WBReviewProject` 在 `wb_figure_project` schema v2 增加每行当前建议；无建议的 v1 仍按原契约读取，第一次记录建议显式成为 v2；旧 v1 读取器拒绝 v2。旧单图文档 v1/v2 不受影响。重复 JSON 字段、非法尺寸、泳道分类/参数/源身份不一致均拒绝。草稿历史继续由平台 CAS 保存。

建议本身不写 ROI。用户应用或恢复某候选时保留显式空泳道元信息，写入原图坐标并撤回已审核标记；更改 N 或统一高度后旧建议只能查看，须重新检测才可应用。手工坐标修改不删除建议。失败不能伪装空成功。后台逐图运行，取消停止后续工作；关闭等实际线程结束；过期结果不能覆盖新编辑。

依据：[GelAnalyzer 概念](https://gelanalyzer.com/docs/concepts/)与 [ImageJ Gels](https://imagej.net/ij/docs/menus/analyze.html)支持显式极性、profile、背景与人工复核这些原则。本算法及阈值为本项目工程实现，不是上述软件算法的复现。验证使用冻结的合成几何/反例和只读真实样本探针；尚无独立标注数据集准确率结论。
