# 工作台快捷键 v1

固定动作目录为桌面包内 `web_ui/shortcut_actions.json`，schema_version=1，定义21个稳定动作ID、作用域、默认组合和保留键。宿主验证和网页呈现读取同一目录，不从用户工作区加载模块。科学schema、算法、N、ROI和结果格式不变。

`WorkbenchShortcuts`使用当前发行通道的QSettings保存 `workbench_shortcuts_v1`。有界版本JSON只接受已登记动作、规范的Ctrl/Alt/Shift组合及字母/数字/功能/方向键；空串表示禁用。不允许重复有效组合（即使作用域不同）、系统/文本保留键或未知动作。恢复默认先生成草稿，点击保存才持久化。无效旧偏好保留原设置，显示错误并临时使用默认；失败不声称新绑定保存成功。

网页统一注册动作并调用现有按钮或相同操作入口；文件菜单的保存/打开和快捷键共享该动作。保存优先应用当前可保存的采集组、清单或裁剪草稿；其他未应用调整要求先应用/放弃，不能仅保存项目就冒充草稿已保存。批次继续要求当前无草稿和相同可执行按钮。模式切换只允许现有页面，采集组流程不借快捷键进入独立灰度模式。

组合键只在网页拥有焦点、无网页dialog/抽屉、非忙态、非自动重复、非输入框/select/contenteditable、非IME组合（含isComposing/229）时触发。只在快捷键配置输入框内明确捕获新组合；文字输入编辑键仍归原控件。浏览器事件使用capture并终止匹配事件，撤销/重做不再保留第二个全局处理器。图上局部方向键也拒绝IME事件。Qt兼容高级窗口的原有键保持独立，真实Web聚焦按键验证不双触发。

当前采集组按最后点击/聚焦的稳定组ID保留，DOM重绘不退回第一组；会话/项目变化清除此选择。下一组/上一组、选组、归Fig、第1/2/3张来源选择/取消及放大都调用现有控件。序号只代表当前显示位置，不推断文件后缀的实验角色。

偏好保存带requestId，只有对应实际回执才确认保存；保存期间的新按键草稿保留，错误留在配置面板。关闭配置不改变尚未保存的偏好。按钮提示与aria-keyshortcuts随已保存绑定更新，清空绑定不禁用按钮本身。

默认入口：文件菜单→快捷键设置，或Ctrl+Shift+K。Ctrl+S保存、Ctrl+1–5切换可用阶段、Alt+上下切换组/原图、Ctrl+Shift+Space选组、Ctrl+Shift+G归入当前所选Fig、Alt+1/2/3选裁剪源、Alt+0取消、Ctrl+Shift+P放大、Ctrl+Enter继续批次、Ctrl+Z/Shift+Ctrl+Z撤销/重做。快捷键偏好是UI设置，不是实验数据或科学确认。
