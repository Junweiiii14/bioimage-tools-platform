# 仪器整批自动裁图及显示纠偏 v2

T072：裁图证据子策略 `intake_crop@2`。外层 schema12–14 不变，旧 `intake_crop@1` 数据与人工审核语义保持。旧程序因未知子策略拒绝 v2，不会把机器采纳读成人工确认。

无膜轮廓的信号原图可使用 `instrument_guided_geometry@1`：只接受当前明确三图采集组内两张同行尺寸、SHA/字节数/位深验证的伙伴图；沿用既有纹理差至少0.03的角色识别，白光只提供膜范围。不得把白光角度直接当成信号角度。原信号目标内至少三个独立条带强度中心拟合方向；同泳道双组件、拟合最大残差超过 max(1.5px, 中位组件高度×0.2)、多膜或多目标均暂停。绝对角度小于0.2°归零；绝对角度超过10°暂停。重新对齐的检测副本只生成原坐标槽位，最终槽位与其他信号组件交叉也暂停。记录 `signal_orientation_fit@1`、残差与两张伙伴SHA。这些均是可审计工程策略，不能代替实验身份或科学准确率证明；只有两个可见条带时人工处理。

专用合成回归包括guide/signal方向冲突、水平回零、近邻双排、多膜、选上排但标准高度吞下排，以及同组资产身份。最小实验发现旧候选峰距会压掉近邻目标；本路径不以大峰距证明唯一目标，同时独立检查原信号组件，避免将双排平均质心当单排。现有19组已见参照辅助只读检查，源图单独0/19可采纳；导向路径初稿13/19，但独审发现上述四类缺陷，修复后保守4/19，其余明确暂停。不得把13作为有效自动能力或把4解释为科学准确率。

仅已明确 Fig、蛋白、N、原图来源且用户启动的 `intake_workflow@3` 整批可自动采纳。源图身份、原坐标与 N 必须符合既有 source_geometry@2；仅一个完整候选、槽位数和逐槽原图矩形精确匹配、存在方向框且绝对角度不超过10°。无候选、多候选、N冲突、选中区域的等分回退或大角度仍暂停。10°是本轮“小角度”工程范围，合成 ±9°原有几何样例及本轮端到端验证不构成真实科学准确率阈值或留出结论。

机器采纳使用 policy@2，`reviewed=false`；`geometry_ready` 只表示几何可供本次处理，不代表人工审核、上样身份、有效信号或生物学对应。人工指定范围仍使用policy@1、reviewed=true。两条路径共用当前来源/固定N/逐槽校验；未取得依据不能发布原值资产或进行完整Fig测量。原值TIFF仍逐样本保留，旋转显示数组不入定量。

检测票据先按原冻结输入结束，安装机器几何后重新批准并持久化，再领取新的裁剪导出票据；不在活动票据内改输入摘要。取消、过期、保存失败不能继续后续阶段。已有完成结果不静默重裁，重开不自动运行。原始@1提议记录/旧分阶段策略保持，新的自动行为只在明确运行的整批中启用。

方向框接入既有 `DisplayFrame` / `standard_lane_ratio@1` 与 affine-bilinear 显示采样、来源变换矩阵。原值裁图和所有定量目标仍为原始像素坐标矩形。手动显示角度限制[-10,10]，恢复0清除旋转框；角度用于原ROI内的内接显示框，预览明确展示实际内容。修改范围会清除旧方向，只有同范围无新角度时可保留既有方向。显示设置随composition保存/归档，修改后按现有局部修订重建本Fig，历史文件和其他Fig保持。

灰度图像来自已提交且SHA/尺寸/来源核验的Fig PNG；独立有界只读预览按项目、Fig、输入摘要、资产SHA绑定，不因普通阶段保存修订失效，也不改批次运行身份。最多缓存4项、编码图像合计16MB（单张沿既有2048预览预算），界面只传当前项；原坐标测量框通过记录的仿射矩阵映射。切Fig/加载失败/过期不能显示别Fig旧图，失败提供重新加载。测量本身仍经原始TIFF和真实RunSession。

统一结果直接展示固定槽位表，显示与状态分列；所有Fig/同名蛋白仍按稳定身份保留，可导出已有CSV/XLSX或新完整结果快照。缺失/失败/待复核与有效零值保持区别。普通说明收拢，真实质量状态和当前阻断原因保留。
