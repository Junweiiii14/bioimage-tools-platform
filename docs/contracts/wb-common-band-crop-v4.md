# 常见明显条带与旋转显示 v4

T080 经用户授权，将常见项目的明显主行优先处理，目标是80%的完整项目内全部裁剪自动通过；允许少部分项目错裁。此目标不是本开发集已证明的准确率。分别报告完整项目自动完成率、全部裁剪无需修正率和至少一处错裁项目率。来源变体不是独立项目。

## 算法与兼容

既有 `source_signal_geometry@2` / `instrument_guided_geometry@2` 及 `intake_crop@3` 几何已可靠时继续采用。旧证据、历史原值及既有人审边界不重算。旧算法不能满足新常见场景时，独立生成 `source_common_band_geometry@1` / `guided_common_band_geometry@1` 候选；只有它自己的完整N槽位、有限合法坐标、5N:4显示框及原图采样范围通过校验才可采纳为 `intake_crop@4`，保持 `reviewed=false`。不能仅给旧失败候选添加成功标志。旧程序拒绝未知policy，旧文档读写保留原形状。

主行由显著条带核心的共同方向、位置和节距决定；连接核心的方向仍从信号逐列估计，不以膜倾角替代。核心用于定位，不等同于泳道数：先合并同泳道碎核，连接核心经横向剖面谷分区，槽位始终按明确N保留。弱/阴性内槽不移除，不推断未上样。远离主行的低显著结构不再单独阻断整批。缺少完整尺度/相位或真实读取/身份/范围错误仍明确报告，不伪造坐标。

检测预处理只作用于私有浮点副本，量化与原值裁剪继续使用原图像素。5N:4是实验室展示比例，不是通用期刊裁图规范或抗体特异性证明；完整原图与上下文必须保留。新策略的数值为工程选择，不宣称通用最优。

轴向原像素采样框Q使用共同主行包络，完整保留N及内部共享X分界，不将旋转展示框的外接角落直接当作定量范围。Q必须逐像素位于有效膜内；若仅首槽左侧或末槽右侧的空白延伸触边，可将该外侧边界收回到连续有效膜范围，Y范围、内部边界、槽位身份和展示框不变。收回后须保留所选核心原坐标包围范围之外至少3个完整原像素列的背景；末端没有核心相位依据、核心或最小背景触边、内部槽或保留范围有膜外像素时仍明确拒绝，不用容忍比例代替 `all(valid)`。`sampling_limits` 逐槽包含全部Q，不能被解释为旋转多边形与轴向矩形等价。

同组辅助文件先核验SHA、大小、尺寸和位深。白光只帮助定位膜。所选信号的裁剪不因伙伴坐标未证实而自动失败；只有两个信号来源各自检测后逐槽坐标满足现有注册容差，才写入 `registered_signal_pair@1` 和全组SHA，供对应辅助裁图复用。相同尺寸、文件编号或Fig名不是坐标证明，白光也不能变成定量来源。

## 旋转与原像素

新常见模式及手动显示角支持±30°；旧自动模式仍保持±10°。固定网格构造新增显式角度上限参数，缺省10°，不能改变旧调用的约束。

手动旋转的 `DisplayFrame.sampling_policy=within_source@2` 表示角度只改变原图中的展示采样。同一ROI已有显示框时保留中心和宽高；新ROI使用该ROI中心及宽高，不随角度静默缩框。四角必须位于原图，越界拒绝保存并反馈。原轴向ROI和定量数据不因角度改变。旧 `within_roi@1` 缺省字段不写入旧JSON，其边界约束仍是原ROI。

对已自动采纳或已人工确认的同一原图ROI明确改角，裁剪证据使用 `intake_crop_display_review@1`，记录人工复核，并原样保留 `slots`、`fixed_grid`（包括背景采样限域和局部复核位置）、`geometry_policy`、检测来源及已有 `raw_crop`。不能把自动定位的逐槽原坐标改成整行等宽矩形。保存、连续改角和重开仍保留这些定量输入；辅助定位的完整来源身份校验继续生效。改变原图ROI仍按既有人工裁剪流程重建固定N槽位，并清除旧原值裁图引用。旧策略文档不改写；旧程序拒绝未知复核策略。

角度修改使当前Fig显示及派生导出失效并按原账本重新执行；保留已有原值资产不是宣告新阶段已完成。相同原图ROI重新裁图仍取相同原像素。四角源边界的浮点舍入容差统一为 `1e-7` 像素，不允许真实越界。

主画布显示旋转轮廓与独立拖柄，输入即时联动预览；撤销、复位、保存、重开和导出使用同一显示框。轴向量化框仍单独可见。显示输出记录实际frame与矩阵；原值TIFF按原ROI整数切片，不从旋转后的显示图反算灰度。

## 有限验证

已知开发素材做一次旧版基线和最终新版对照；原型只有发现新机制时才补小实验。重点覆盖阴影/核心、碎核末槽、连接核心的大倾角、弱/阴性槽、原值不变、手动旋转实际画框/导出、旧记录读写和完整项目恢复。最终独立审查与仓库必需检查照常执行；不以开发案例声称80%跨实验室项目目标已统计验证。
