# WB 自动建议与自动输出 v1

T-024/T-027，`automatic_wb_proposals@1`；项目 schema8。现有 `profile_integral@1` 公式和 schema1–7 的读取不变。公开入口仍为 `wb_tool.api`；平台 runtime 不承载实验语义。

## 原图与建议

目录导入最多512张TIFF、4096个目录，不跟随符号链接或junction。原图以不可变资产保存；显示缩放/对比度不进入计算。自动算法在数值副本定位条带行与泳道，随后从原始像素生成积分边界和测量请求。没有可靠候选会明确失败，保留原图，不生成零值结果。

schema8 `automatic_rows` 保存源SHA、源修订、设置、几何、泳道数、请求与警告。机器建议不设置人工 `reviewed`。当前源/几何/N/请求必须与证据匹配，才可用于自动处理；用户图上修改使旧证据和结果过期。重新分析已有ROI时保留用户裁剪，重新建立泳道和积分边界。该版本仍采用固定等宽泳道；无人工真值准确率承诺。

## 后台与输出

宿主顺序执行导入、自动定位、真实测量进程、事务提交、精确修订保存、证据核验与新目录发布；取消/关闭/新编辑阻断后续阶段。已提交结果和已发布目录保留。自动导出目录不覆盖既有目标。

输出包括拼图PNG/TIFF、测量XLSX/CSV、项目JSON、状态报告、校验摘要及可恢复ZIP（原图、原值裁剪、运行证据）。部分无ROI来源只从展示投影中排除，仍保留在项目与归档；投影压紧空列但不改原始版式记录。全批无ROI时仅输出表与状态，不产生虚假拼图或ZIP；原输入仍在工作区。

有效信号列继续遵守现有质量规则；`raw_integral` 单列保留已核验的待复核积分，不参与归一化。schema8审计表新增此列，旧schema表结构保持。界面摘要显示4位有效数字，完整表和导出保留现有完整精度。达到位深上下限会触发质量复核，绝不因为自动化而绕过。

自动标签为 `Source 001` 等来源编号，各源默认独立Fig，避免猜测蛋白、样本或内参关系。OCR与归一化仍需明确的身份/配对信息；本流程不凭文件名或图像推断实验含义。


## T-042 可选/默认策略扩展

现网页工作台选择source_geometry@2、background_support@1。旧schema8记录不改写；旧策略Literal仍接受。几何新增candidate.lane_rois和display_frame均有空默认，旧检测证据可读。自动证据algorithm_id随source_geometry使用automatic_wb_proposals@2。源图尺寸、像素/位深保留，检测副本插值仅供方向与中心识别；定量只用独立原图矩形。未确定膜/方向/间距不返回成功候选。显式Marker排除仍需Marker证据，不能无条件删首样本。ROI/N编辑清除旧显示框，撤销恢复原几何时可恢复；分段不安装完整行旋转框。

background_support@1用边缘窗口中位值建立线性背景，在检测副本上寻找连续3–10点低于max(3噪声,2.5%幅度)的支持端点。支持不足保留可检视面积，并以background_support_review@1质量策略标记quality_review；独立第二信号同样待复核。原始profile_integral@1梯形正残差公式、单位和均值剖面语义不变。手工调整边界/背景可解除自动边界提示，位深极值提示仍由原像素检查，包含/排除开关不能解除背景提示。重规划和灰度导出接受新旧独立泳道策略。


## T-044 目录与字面标签扩展

folder_sources@1目录后台头信息筛选排除已知本软件显示/裁剪派生TIFF，不解码参考像素；同目录明确采集键的无编号/(1)主文件优先，其他编号保留排除记录，缺主文件不排除。直接选择文件沿用旧导入。损坏候选不静默隐藏；最多4096候选头检查/512原图和4096目录，不跟随链接。旧discover_tiffs默认列表编码保留，后台请求带policy/paths/skipped报告。

literal_source_labels@1替代旧“每源独立Fig”的默认：有明确Fig文件夹/文件名前缀才自动同组；采集文件名前缀可作字面条带标签，不确认内参/样本或OCR关系。标签需要额外字形时后台选已安装字体，按正常摘要/资产导入后随项目保存；不改原图、数值公式或schema8。旧项目不自动改组/改名，显式原有字体保留。

T-044筛选记录可从工作台项目工具查看；编号变体可能是不同内容，用户可明确补入。补入由当前记录摘要/索引授权，派生图拒绝，原选文件入口仍可用。记录保存requested_additions意图，新结果status.json附source_discovery；实际成功/失败仍看原图行和运行证据，记录不伪装计算成功。
