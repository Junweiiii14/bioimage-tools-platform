## 原坐标与目标

`LaneAnnotation.target_roi` 是原目标半开矩形；`roi` 是实际采样矩形。
两者原图、泳道身份和横向范围相同，采样矩形包含目标，仅允许纵向有界扩展。
每泳道仅一个稳定 `target`；多条带人工规划继续使用原独立泳道策略。
条带闭区间 `bounds` 相对采样矩形，换回原图时仅加一次 `roi.y0`。
裁图与显示拉正不因背景上下文变化而改变，也不进入定量。

先按 `background_support@1` 评估原目标。只有原目标存在边界、且唯一问题是背景
支持不足时，才依次尝试原高度的5、10、15、20、25%纵向扩展。
像素padding为 `max(1, (height * percent + 50) // 100)`，整数最近舍入、半数向上，
到原图边缘截断；重复采样矩形不重复尝试。`context_expansion_percent` 保存所选
尝试的比例，0表示保留原目标；实际各边扩展量从两个原坐标矩形读取。

选择第一个双侧连续背景完整、无竞争信号、背景扣除后最高峰仍在原目标内的尝试，
不按更大面积选结果。平坦/弱目标不借用邻近条带；原目标多峰不自动扩大。
全部尝试失败时，原目标边界、基线、原始面积和原具体质量原因保留。
原像素始终不变；平滑仅用于找边界，积分仍用原始逐行均值。

## 保存、编辑与兼容

三个机器schema快照显式增加上述策略及可选目标字段，保持既有外层文档/协议版本。
新能力由上述策略版本识别，不能伪装成旧策略；旧读取器会拒绝新策略/字段。
旧请求缺少字段时读取为 `target_roi=None` / 比例0；序列化省略这两个默认字段，
不把空字段补入旧请求/结果。固定旧worker NDJSON字节有回归对照，已有历史资产
不重写、不迁移，也不自动切换策略。新请求必须包含目标与配套策略，不能混配。

工作台区分目标框与采样上下文，曲线显示采样范围，图上编辑操作目标框。
只改基线/边界保留原目标和上下文；改目标几何清除旧边界、上下文与当前运行，
再从新目标生成，不能把已扩大的上下文当作下一次目标继续扩张。
裁剪/N改变仍使旧计划过期；新结果须正常worker退出、存储提交后才展示。
