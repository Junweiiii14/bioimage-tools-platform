# WB 明显主行固定N裁剪 v5

T081由用户明确授权。填写N始终是必须满足的槽位数量，不按检出块数改N。
新workflow@5使用source_prominent_band_geometry@1或guided_prominent_band_geometry@1，
机器采纳为intake_crop@5，reviewed=false。旧@1–@4历史、人工ROI与原值资产保持，旧读取器拒绝未知policy。

新批次统一对源信号的行评分，不允许旧检测器先成功就跳过主行判断；同一源已有明确人工确认的ROI仍保留。
膜或同组白光只帮助定位工作区域，所选信号自身负责条带评分；同尺寸不表示配准。伙伴坐标只在独立核验后用于对应裁图，否则保存原图并记录。

在原值私有浮点检测副本上作多尺度局部背景分离。低局部噪声阈值与较高核心阈值提出候选，共用局部对比、横向形态和横向峰支持排名。连通块不等同泳道，粘连主行不能仅得一票而被分离弱行超越；平滑阴影/孤立污点不因面积大无限加分。
先固定最明显主行身份，允许该主行不同阈值的完整几何尝试；不得最高主行N冲突后换较弱次行凑N。双行接近不再直接拒绝，最高评分自动采用，不固定上下。N多/少于真实空间证据时仍明确失败，不伪造完整性。

首末锚点与N槽位保留完整原图横向范围，中间弱/空原像素和间距不拼接、不移除；不能推断样本身份或把未检出改成有效零。
显示框高度按真实主行包络及背景确定，N对应横向几何；原算法默认5N:4保持，新策略不以35%固定比例放大阈值否决完整明显主行。新网格为fixed_n_frame@2（独立高度），须带prominent_envelope_frame@1；旧fixed_n_frame@1继续5N:4。完整固定N/source_axis_partition@2/合法坐标与采样范围仍必需。

有源膜时使用其合法区域；无清晰膜边界的信号采集图可用显著结构支持的有界源窗口，明确标记uniform_signal_field@1，这不是宣称整个窗口已证明膜内。原图边界、完整保留信号、有限坐标和取消均硬检查，量化仍从原像素/原坐标读取，检测插值和显示拉正不进入定量。

80%完整项目目标不是本开发集已证明科学准确率；实际用户已确认Fig1N4/Fig2N2，基线错误N2/N4应明确冲突，不能通过算法掩盖。实际180源1/四Fig/九组的GUI与输出另记证据。
