# 独立灰度工作流 v1

T045在同一入口增加默认WBQuant独立泳道（复制同尺寸/完整泳道多峰/整段拖尾）与
按Fig自动处理，见`wb-fig-quant-v1.md`。本文的区域/N目标仍作为显式规则网格分支保留。

当前绿色工作台首页提供“独立灰度分析”。选择 TIFF 原图后直接导入不可变原图资产，
不调用自动裁膜或拼图。新项目保存位置失败后重选位置仍保留手动测量模式。
用户在原图画自由矩形，或使用精确坐标输入；明确指定 N、暗/亮极性及排除泳道。
点击“计算当前原图”确认的是测量几何，不是实验质量或生物学结论。

## 计算与保存

`ManualQuantTarget` 携带来源 SHA、项目修订、原图半开矩形、整数 N、极性和排除槽位。
网页另绑定 projectId、row_id、sourceId 与当前界面 generation，拒绝旧项目或旧草稿操作。
N 为1–96整数，区域须容纳 N 槽，高度2–4096原图像素；bool、小数、越界与重复排除项拒绝。
文件解码及规划运行在现有后台，取消/关闭/代际变化阻止旧目标覆盖新草稿或启动测量。

公开纯用例 `configure_manual_quantification` 校验来源、尺寸、位深和修订，使用已有
`anchored_context@1 / anchored_background@1` 提议边界。计算仍走正常 worker、进程退出、
存储提交、结果资产核验与保存恢复，不在浏览器算积分或注入结果。

复用 schema7 的逐行自由高度与已有 `ProjectRowAnalysis`，不改变全项目模板高度，
不增加文档/worker格式，不创建自动检测 provenance。普通项目升级为已有 schema7；
schema8项目保留该类型，只撤销目标行的旧自动建议和当前运行引用，其他行不变。
没有拼图也可测量；空 composition 保持空值，已有分段则沿用校验，不能静默丢弃。
几何/N改变清目标行旧旋转显示框，多分段与新N不兼容明确失败且不部分修改项目。
原图、旧运行和完成结果不删除；旧OCR/归一化关联按既有来源/ROI/N规则显示过期。

相同目标、N、空位和极性再次计算会保留人工边界/基线。只有明确选择“恢复当前区域
自动边界”才重置参数，且保留目标区域/N，不再自动寻找另一块膜。算法、积分公式及
位深上下限质量提示沿用已有版本，失败和质量待复核不变成有效零值。

## 曲线交互

“全部泳道曲线”在现工作台内打开弹框，纵向排列每个泳道的原图逐行均值、各条带
封底和积分填充；区域内最高残差点仅作为显示峰点，不是新蛋白识别或新检测证据。
选一个泳道后可以切换条带，拖动或用Tab/方向键调整端点，也可直接输入边界/封底。
修改走现有后端标注及重新测量流程。网页曲线和单泳道编辑共用同一SVG呈现函数。
质量原因在一处按原因合并泳道编号，展开查看；显示“有效”不等于独立科学真值证明。
