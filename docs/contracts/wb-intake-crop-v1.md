# 仪器清单固定槽位裁剪 v1

E3/T056，项目schema12，`intake_crop@1`。schema1–11读取保持；11读取器拒绝12。
从未尝试执行的schema11可复制升级12；有尝试而缺少产物依据的旧账本不能静默升级。
复用source_geometry@2与original_sample_crop@1，不修改现有检测/积分阈值。

`prepare_intake_crops`建立版本化裁剪容器；`propose_intake_crop`仅读取已明确分配的
原图，核对SHA、尺寸和位深，显式传入N；不调用目录编号过滤、OCR或测量。
`IntakeCropEvidence`保存膜/Marker/检测参数/原坐标候选、版本及完整N槽位。
槽位ID与E1同一公式，位置仅代表本行从左到右，不代表跨蛋白样本对应。

检测不能定位固定N时，所有槽位仍存在，坐标为空、状态unlocated；不凭N均分后
当检测成功。不确定首尾空位、不等距或多候选保留待复核。detected/weak/not_detected
仅是检测信号证据；不等于上样状态、用户排除或有效测量值。数值始终不在此模型内。

自动候选未经人工审核，`record_intake_crop_proposal`只结束为needs_review。
`review_intake_crop`要求当前摘要和明确原图矩形，重置相关阶段/撤销运行批准，
保存人工指定范围与固定N分割；此时信号为undetermined，不猜测无信号槽位含义。
之后重新批准的所属crop尝试才可导出。人工整行范围是显式确认等宽N槽的输入，
不把它冒充原自动独立泳道证据；自动检测原证据仍保留供核查。

`export_intake_crop`使用既有export_crop：原始TIFF样本、位深/色彩/分辨率保留，
入口必须传入当前活动crop票据，先核对冻结输入/目标行/运行身份与账本取消意图；
未批准、无claim、错票据或持久取消均在创建文件前拒绝。
不读取显示图或旋转数组；目标已存在则失败，写后核验并无覆盖发布。
`complete_intake_crop`只在冻结票据校验后接收宿主已导入的原值资产，取消不安装产物。
AssetRef是宿主可信I/O端口的摘要引用，不是应用层自行验证磁盘内容的收据。
后续完整Fig compose/measure的活动或完成状态必须具备所有行已审核原值裁剪依据，
不能只用账本done代替真实产物。归档资产枚举/恢复包含原值裁剪资产并重映射。

宿主可用claim的stage_filter只领取当前已接通阶段；不影响既有默认完整依赖顺序。

本阶段不产生分析请求、RunRecord、积分或总输出成功。已批准工程实现不等于
自动裁剪科学准确率或真实独立留出通过。当前宿主接入与完整阶段验证仍在实施。
