# 工作台明确修订 @1

T075 的网页高级工具通过 `wb_tool.api` 调用既有用例，写入仍由桌面宿主编码、CAS 保存。
不引入项目 schema、数值算法、来源匹配或分母默认值变化。

- `workbench_project_digest(project)` 绑定全部配置与当前修订。
- `prepare_workbench_revision(..., expected_digest, impact)` 只返回不可变候选；宿主只安装并保存最终严格验证后的项目。
- `impact="outputs"` 使当前输出待处理；`impact="figures"` 同时使成图、测量待处理。保留仍可复用的原像素计划、运行引用、原值裁图和历史输出索引；不自动恢复执行批准。
- `apply_workbench_metadata` 复用原元信息解析、字段选择、空值保持和全有或全无规则。Fig / N 必须在同 Fig 全部行一致；不从文字推断新的采集组或原图来源。结构变化进入既有分组修订流程，等待准备页重新确认。
- 空泳道改变撤回该行裁剪审核，并失效该行裁剪及所属 Fig 后续阶段。备注、项目名称进入成图摘要，须重新生成成图；OCR 和归一化配置只使输出过期。
- `revise_workbench_figure_order` 保留稳定 Fig / 组 / 来源身份；顺序配置 v2 的蛋白序列同步移动。旧行式清单不能自动推导采集组，保留显式兼容入口。
- 正在运行的阶段不能接受高级修改。准备态 schema10 仍禁止 ROI、空泳道、OCR、归一化或结果；不会为了打开高级面板而隐式升级。

网页命令 `advanced_ui` schema_version=1 必须携带 requestId、projectId、sessionEpoch、revision（当前视图 generation）。命令预算 262144 字符；字段、数量、枚举由应用层验证。
失败回执绑定请求；弹出系统文件选择器后重新核对上下文。`pending` 不表示保存成功。
所有保存和导入后保存均等待完整提交回调；取消或仅写入历史不能清除当前网页草稿。
派生表格缓存绑定项目、视图 generation 与已核验结果对象身份；任何失配即清除。
工作簿保留服务端，网页仅获得工作表摘要与所选表头，不反复传输整本 XLSX。

验证范围见 T075 任务。纯用例测试不能替代真实网页入口、后台保存和安装版验收。

元信息预览以服务器 previewId 绑定，每页20条，最多既有1024条导入记录；`metadata_page` 仅切换页，客户端保留按原始索引的跨页编辑，`metadata_apply` 必须携带匹配 previewId。客户端超过提交预算时要求分批，不截断单元格或静默丢弃字段。并发字段按初始值/草稿/当前值比较；无冲突字段合并，冲突须在网页逐项选择后才能保存。

只读 `open` 仍校验项目/session 身份，读取宿主当前修订，允许它先于主页面快照到达；所有写入仍严格匹配视图 generation。读取失败必须在面板加载位置显示错误与重试，不能留在无反馈的加载状态。

只读 `open` 可在后台处理中查看当前草稿快照；关闭期间仍拒绝。除 open 外的命令继续受 busy 与 generation 校验保护，不因为浏览需求允许修改执行中的配置。
