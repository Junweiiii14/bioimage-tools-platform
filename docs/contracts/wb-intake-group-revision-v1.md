# 执行后分组修订 v1

T067在schema11–14中显式引入 `intake_workflow@2`，新增 `editing` 状态。原@1仍不序列化该字段、原摘要保持；旧项目不会静默进入新策略。新策略只扩展编辑/失效用例，不改变定量公式、预处理、检测阈值或数据资产。旧客户端不能安全编辑@2，应保留原快照并由新版本读取。

公开 `begin_intake_group_revision`、`revise_intake_grouping`、`confirm_intake_group_revision`。只用于已有采集组的项目；旧行式项目沿用原入口，不按蛋白名推导采集关系。进入编辑须匹配当前清单摘要、没有running阶段；撤销清单确认和执行批准。采集组和原始成员身份不可删除、重组或替换，允许明确改Fig、标签、排序、选源/取消、区域和Fig级N。图像资产不修改。

当前清单/采集组草稿仍是唯一权威，完整行按原规则投影。未选源、未定N的执行后草稿可保存重开；缺失行不成为有效零值。`editing=true`期间不能批准执行、声明阶段运行、修正裁剪或发布当前输出。全部必需信息重新核对完整后，明确确认退出编辑；执行批准另由既有继续处理通路完成。所有保存经宿主原Storage/CAS，失败或过期回复不覆盖草稿。

编辑期间界面仅开放“导入与分配”，统一键盘动作识别该网格；原图裁剪、拼图、结果入口在确认后恢复。有未应用裁剪草稿时，须先保存或明确放弃，才能进入分组修改。

| 修改 | 当前证据失效 |
|---|---|
| 选择/取消原图、改变目标区域 | 本行ROI审核、原值裁剪、测量；所属Fig显示/测量阶段和项目输出 |
| Fig级N变化或待定 | 本Fig所有行ROI审核、完整槽位几何和下游；不截断/补零 |
| 采集组移Fig | 移动行重新核对裁剪（同N也不静默复用）；两边Fig显示/测量和输出 |
| 蛋白/Fig标签、行顺序 | Fig显示、表头和输出；保留数值输入未变的裁剪及真实已提交RunRecord |
| 其他Fig | 保留其当前裁剪、布局、成图与真实运行 |

改变的Fig重建完整布局占位，未改变Fig保留自定义分段。新的成图准备仍不得夹带运行。成图提交时，仅在原图SHA、原ROI、N、空槽、完整测量请求（除CAS修订号）及算法/参数全部一致，且旧RunRecord真实成功且有结果资产时复用该计划；保留原运行与尝试身份，不创建伪运行。不能复用时仍通过原worker重新测量。

当前引用可以被撤回，但过去工作区修订、RunRecord、资产、发布目录不可变；`intake_outputs`历史索引保留，摘要不匹配即历史输出。仍存在的阶段保留attempt，下一次真实claim递增；因不完整清单而暂不投影的阶段留在旧修订历史，重新出现时为pending，不恢复旧成功。槽位稳定身份公式保持，只代表位置，不能推出生物配对。

辅助图和建议仍是证据，不直接定量；本次编辑禁止追加来源/重新识别，防止未更新的建议混入执行。要读取其他批次使用新的导入项目。原像素、坐标/位深、既有独立灰度/OCR、旧schema读取和无覆盖输出规则保持。工程验证不证明来源选择/N或科学准确率，相关歧义须实验人员核对。
