# ZIP恢复与历史证据 v1（T-019实施契约）

恢复必须产生可继续编辑/计算的项目，并保留原ZIP及历史结果。新增项目schema v6/WBRestoredProject，继承v5，v1–v5继续读取；旧读取器拒绝v6。科学算法、标注/ROI/空位/OCR确认与归一化语义不变。

`archive_sources`保存原ZIP资产、原项目ID/修订/格式；`imported_runs`保存声明的历史RunRecord、来源ZIP SHA及复制到新工作区的请求/结果AssetRef或明确缺项原因。它们仅是外来历史证据，不登记为Workspace本机run，不产生PID/退出收据。当前分析/OCR仍可引用这些历史记录，重开由本地不可变请求/结果核验后显示，并标明归档来源；当前参数改变按原规则失效。本机复算产生真实新run，旧证据保留。

原项目ID/row/lane/band/run身份保持，新工作区独立ID；修订从原修订继续。所有当前原图/字体/OCR源及历史资产映射为新工作区AssetRef，原run内部声明的引用不改写。历史来源/记录上限分别8/4096，重复身份须内容相同；重复迁移不丢历史，嵌套原ZIP只作为不可变文件保存，不递归解包。实际文件/成员/总容量预算仍限制导出和恢复。

导入只接受本软件标准ZIP成员集，先核对EOCD中央目录预算，再用ZipFile检查所有成员。拒绝绝对/越界/重复/非法路径、链接/设备、加密、未知压缩/格式；不使用extractall。按固定内部文件名写入独占临时目录，原ZIP复制后再验证，检查CRC、SHA、长度、完整成员集合、项目/run/request/result身份，重新生成表并核对CSV/OOXML有效内容。图像/裁剪/显示来源按既有工具规则核对。索引和摘要不能认证实验真实性；一致伪造的无签名ZIP不等于可信实验或本机观察记录。

T-018 archive v2缺项必须原样显示不可用，不能把缺项恢复为成功。T-012无archive.json的旧ZIP仅恢复有证据的项目/原图/模板/裁剪；不存在的结果明确标为旧归档未携带，旧run声明和原ZIP保留。未知版本拒绝，不猜字段。

宿主专用后台线程在独占临时位置创建新Workspace，流式导入资产，最后保存v6草稿并关闭存储，再发布到不存在的目标路径。Windows使用无覆盖目录rename；其他平台以独占目标和未完成标记保护逐项发布，未完成标记阻止桌面打开。所有移动前校验绝对源在本次暂存目录、绝对目标在指定父目录。失败/取消不覆盖旧目录；未完成发布留下明确标记，重新恢复需选新目标，已完成项目可重开。关闭等待后台线程真实退出，不伪造成功。

首轮支持图形窗口无工作区时“从ZIP恢复”，恢复完成打开该新工作区；历史来源在界面及导出中可见。当前不是跨项目合并器，不自动选择实验配对，也不执行归档文件/脚本。边界依据Python 3.12 [zipfile官方文档](https://docs.python.org/3.12/library/zipfile.html)，2026-10-14核对；实际运行3.12.14，使用open流式读取，不依赖extract的路径修正。

实现版本：wb-tool0.17.0 / bioimage-app0.12.0 / platform-runtime0.2.0。后者提供显式import_draft_snapshot，仅允许无文档且无run的新工作区；普通save_draft首修订0和后续+1 CAS不变。保存归档修订并不补造以前的草稿。当前schema6的CSV/XLSX来源表增加定量/参照/OCR运行来源与归档SHA列；schema1–5布局保持，表格数值算法不变。界面结果表显示“归档历史证据”或“本机运行”，归档SHA可在提示/导出中核对。

准入：容器2GiB+8MiB、解压总计2GiB、4096成员、中央目录4MiB；普通成员512MiB，历史原ZIP可以超过512MiB但仍受总计约束。JSON16MiB、PNG/单表64MiB；TIFF解码512MiB/3200万像素，单页、位深/通道/极性沿原适配器。只读普通/标准ZIP64单卷目录，不支持自解压前缀、扩展ZIP64目录、分卷或未知成员。归档历史原ZIP不递归解包。最大8代归档及实际总预算会限制反复迁移，超限明确拒绝，不丢历史。检查/临时文件与新工作区可能同时占用数倍归档大小；本轮不宣称大项目性能或断电持久性验收。

图像检查重新渲染并比对显示像素/记录，重新按原坐标裁剪并比对原通道/位深/数值/描述；定量仍使用原图。结果核验沿冻结算法与原始请求/结果资产，不以显示表或PNG作为定量输入。恢复历史后重新计算保留旧历史证据并创建真实本机run。单条历史结果在本机损坏时，其值为空，其他有效结果可读；包含损坏历史资产的完整再次归档会拒绝缺失文件，不能伪装完整保存。

公开stage_project_archive为后台适配接口，只写调用方提供的新暂存目录；调用方负责清理失败暂存。inspect_project_archive使用自有临时目录只读检查。宿主恢复在专用线程完成，Workspace关闭且线程真正退出后才通知GUI；关闭期间不自动打开晚到项目。发布先于取消时保留完整目标。Windows目录无覆盖发布已在本机测试；非Windows逐项标记发布与真实断电/物理FAT仍需对应环境验证。
