# 审核后原位置回存 v1

当前绿色工作台的“审核裁图并回存原文件夹”先保存当前项目修订，再由既有后台执行。
不需要先生成拼图。回存路径来自本机导入选择记录，绑定工作区、项目、原图行与源 SHA；
路径不进入项目 schema 或 ZIP。旧项目、迁移后的工作区或明确重新定位时使用文件选择器，
后台核对实际文件 SHA、字节数、尺寸与位深后才向该文件所在目录写入。
网页请求只能提交当前项目/行/源/界面代际和明确的重新定位标志，不能指定写入目录。

每次使用时间与随机标识生成新名称，直接放在原图所在目录，不覆盖原图或已有文件：

- `*_显示.png`：显示用途，复用拼图的同一原图采样/旋转映射；标准比例和拉正只作用于显示。
- `*_原值.tiff`：原坐标矩形内的原始样本，不拉正、不缩放；保留通道、位深、photometric、
  额外通道与分辨率标签。复用已有 `original_sample_crop@1` 来源格式，不修改定量公式。
- `*_记录.json`：`reviewed_crop_return@1` 完成记录，最后发布，包含修订、源 SHA、各输出名称
  与 SHA、泳道段和显示映射。分段逐段输出，保留全部泳道及次序。

显示图使用 `reviewed_crop_display@1` 来源记录和 `display_only_not_quantitative` 用途标志。
显示图与原值 TIFF 均暂存、刷盘、重新读取核验后，以不替换已有目标的操作发布。
原值 TIFF 的原有生成图标记使其不被目录自动发现当作设备原图。

多文件发布不是整个目录的原子事务。取消、磁盘满或源变化时不发布完成记录；已经发布的
文件保留，并在错误中列出。成功状态只能在完成记录发布后出现。关闭时等待后台退出，
迟到回调不替换新项目；并发外部程序改写目录的任意时刻竞态不是本契约的互斥保证。
本机路径记录只是定位提示，每次仍重核原图。项目的审核状态表示用户确认裁剪，不表示
积分、饱和风险或实验对应关系自动通过。
