# 工作台性能基线 v1

P006测量现有工作台，不代表M1/M2、科学验证或目标机验收。原R09四个负载、seed8209、128×128显示缩略图、5预热+30正式样本和旧预算保持；新增rows-normal/intake-normal为32行/8 Fig/12泳道，原上界仍512行/128 Fig/96泳道。所有数据均合成元信息/显示纹理，不存在对应真实原图或科学测量；不用于科学准确性。

既有命令继续测快照构造、JSON、桥接到真实生产render后的两次绘制机会、空闲发布与进程内存。冷只指PNG缓存被清空，项目/栅格及OS缓存保持；PSAPI数据属于host/renderer，不能冒充整个worker树峰值。旧50ms快照/200ms刷新触发线不替换4.0常规点击100ms等初始预算。

新增显式模式：

```
uv run --locked --no-sync python -m tooling.benchmark_workbench_snapshot --run --case rows-normal --interaction-baseline --output .local/p006-run/rows-normal.json
```

必须Windows原生Qt平台、已冻结干净源码、全新输出路径。Native QTest可信事件点击实际settings/theme/close/cancel控件，不把JS click当原生输入。外观在独立临时QSettings中真实保存，四主题各5+30次，检查项目/修订/选择稳定、焦点进入与关闭后恢复。生产边界错误、旧回执、非可信事件、缺控件或未完成动画不能贡献有效样本。纯Node测试只验证观察器拒绝假通过，不是性能证据。

feedback_ms是浏览器click时间戳至实际DOM状态变化后的两次绘制机会；settled_ms另等抽屉动画结束及两次绘制机会。前者不等于物理屏幕延迟，后者不拿来代替100ms视觉反馈预算。取消另外记录Python在QTest派发前的单调时间至真实cancelling状态信号（host_command_ack_ms），以及至ComparisonBridge.idle确认所有服务已关闭（request_to_service_closed_ms）；不以观察器返回时刻充当服务关闭时刻。各段p95不能相加。

取消使用P002真实合成输入/共享会话，每次新临时工作区；记录请求阶段及最终RunRecord/PID。该指标覆盖实际preparing/starting阶段控制链，不能宣传为大型算法中途取消性能；临时合成取消工程在终态及服务关闭后清理，报告中的路径只为诊断，不是重开成果链接。自然完成、失败或旧关闭回执不得被计为成功取消。

默认每段保留30个正式原始样本、预热另记，p50/nearest-rank p95/max及完整分母。未实现的工作流节点切换/暂停、未对齐时间戳的host-ready预览、物理OS输入/扫描显示明确未测；后续P005/P009接真实引擎再验。失败保留原命令/退出码/日志，超线保留，不删坏样本、不缩上界或修改预算来过线。工具正常exit0只表示测量完成，预算判断另列。

源码/工具/fixture摘要、硬件/OS/Qt/QPA/DPI/viewport、环境、电源/负载观察和测量范围在任务及证据记录；冻结后的测量不并行跑本地pytest/打包。旧T082数据仅在输入/环境可比时对照，不从历史摘要臆造当前成绩。目标设备、独立科学材料与用户实际体验仍独立待验。

## 原生目标与失败证据

点击前先等实际目标处于静止、完整viewport内、可见/启用/非inert且中心命中正确控件；此定位/动画等待属于未计时准备，计时仍紧邻QTest派发前开始，不缩短被测动作的反馈/settled定义。取消仅在最后neutral主题另作5+30，不冒充四主题取消矩阵。每个主题阶段的完整原始值另写日志，以保留后继阶段失败前的诊断；失败不生成成功性能报告，也不自动重试。原始日志/环境/退出码及后续报告放冻结目录时按生产字节保存，默认空白错误检查保留，仅识别CR行尾。
