# WB 完整峰边界与全组审核 v1（T046）

## 数值策略与兼容

冻结 `domain/wbquant143/` 不变。旧 WBQuant 外侧边界选择最近的严格局部极小，
随后背景搜索被限制在该区间；实际开发图 ACSL4 的左端点41接近峰顶44，漏掉左半峰。
这是本次修复的直接代码与实测依据，不以旧软件一致性替代科学准确性。

新普通独立泳道使用 `peak_envelope@1`：仍由冻结参考检测峰与排除确认框线，
但外侧端点在有效ROI边缘到首/末峰的完整半区间搜最低值；内部相邻峰共享一个最低谷点。
外侧平坦最小值取靠峰端，内部平坦最小值取靠两峰中点的一端；两个区间只共享端点，
不重复累计面积。端点灰度取原始定量剖面值；不以平滑或显示曲线积分。

`peak_envelope_review@1`保留位深上下限警告，并识别：

- `boundary_review:background_at_roi_edge`：最低值抵达ROI边缘，背景支持不充分。
- `boundary_review:unequal_or_overlapping_peak_support`：任一侧峰到端点的下降量不足较大下降量的80%，保留端点不对称/重叠疑虑。

这些是可追溯的保守审核提示，80%不是经独立实验标定的科学阈值。质量提示保留原始积分，
但不晋升为归一化可用的有效信号。worker只接受该策略的上述明确提示，仍拒绝未知标志。
原梯形正残差积分 `profile_integral@1`、位深、极性、逐行均值、坐标及单位保持。
UB/整段拖尾继续全高度[0,H−1]，保留手动范围/封底，不切成一个局部峰。

旧计划与手动边界保持。新建或明确点击“重新自动封底（本组）”时才使用新提案；
这个操作重置本组积分范围和封底并正常重算，历史原图/运行不覆盖。其几何沿用用户当前泳道。
同一原图只解码一次用于本组规划；冻结参考只在覆盖输入ROI的原像素子阵列上建立浮点副本，
结果坐标加回原偏移。截取不进行缩放、插值或亮度变换。

## 审核记录

按Fig显示所有蛋白泳道框、按蛋白纵向排列全部曲线。数值编辑绑定当前行、来源与generation，
本地草稿在“应用并重算”后才送入原像素worker；显示缩放和平移不改变参数。
所有当前计划成功提交后，允许人工“本组已审核，下一组”。

`quant_group_review@1:<sha256>`作为现有行notes中的独立版本化行保存到组内全部成员。
摘要覆盖按项目行序排列的行ID、Fig、蛋白名、除存储revision外的完整请求、run ID、结果SHA。
只保存新revision不会失效；成员、标签、参数或运行改变均会失效。它不修改crop reviewed，
不消除质量警告，也不把失败/缺失变为零。旧软件可继续读取notes但不识别组审核语义。
确认后先完成正常保存和结果核验，再转下一未审核组；保存期间主动查看别组不被旧回调跳转。

## 响应与进度

Qt桥接以模型身份/generation/选择、结果、来源预览、拼图及运行状态构成轻量失效标记。
无变化时不重建整个项目、不序列化所有曲线。状态和进度走独立小消息，不重绘页面。
选择相同SHA来源复用已解码预览；跨源仍核验当前来源。后台忙时可查看别组，修改仍受保护。
全组页保持DOM；选择只更新选中态/编辑区，拖动只更新一张曲线SVG，提交后才刷新真实结果。

识别/规划与最终保存阶段不提供虚构百分比；测量显示实际终结行数/总行数、失败数与当前蛋白。
终结计数包含失败，不代表成功率；只有正常worker退出、存储提交并解码成功才展示测量。
取消保留已提交结果，未完成项留空。减少动效关闭循环动画，但保留文字与进度条可见性。
表格按原WBQuant的组序/组名合并、蛋白逐行、泳道逐列；两位小数，缺失留空，点击回曲线。
