# WB 手工分析用例 v1

`analyze_annotations` 是 GUI 与 worker 共享的应用入口，只接受原始图像窄端口、不可变
`AnalysisRequest` 与可选取消回调，不加载文件、不导入 Qt、不提交数据库或历史结果。
请求保存来源 SHA256、草稿 revision、显式极性、稳定 lane_id/band_id、半开 ROI、
闭区间条带边界、人工基线与包含状态。一个泳道内条带 ID 唯一，泳道 ID 全局唯一。

来源摘要不符、非法请求或取消中止整次执行，不返回成功结果。
计算之前/泳道之间/条带之间/返回之前检查取消；这不是强制终止进程的证明。
合法请求中的局部 ROI 越界或积分错误保留该泳道/条带的失败原因，其他泳道可继续。
结果返回请求快照、revision、位深、颜色转换、算法和质量策略版本；
宿主后续负责检查旧 revision、验证结果完整性和提交终态，结果对象本身不宣告任务提交成功。

| 条带状态 | 有效 signal | 说明 |
|---|---|---|
| valid | 有限值，可为 0 | 解析积分通过且没有待处理质量提示 |
| not_detected | None | 没有条带边界，不能伪装为 0 |
| excluded | None | 人工排除，不参加定量或比值 |
| invalid | None | ROI/边界/人工基线无效，有原因 |
| quality_review | None | 区域有位深上下限像素，原始积分可供复核 |

`dtype_limits_review@1` 仅检查指定条带闭区间转换后的原始像素区域。
零/上限像素分别记录 dtype_min_present / dtype_max_present，提示核对曝光及饱和；
仅凭端点像素不能证明条带已经饱和或处于线性曝光范围。不自动把提示转成有效信号，
不以 epsilon、0 或 Inf 掩盖失败。更完善的曝光验证/复核策略须另行版本化。
未标注条带的空白泳道仍保留稳定身份及剖面，bands 为空；不自动制造一个零值条带。

v1 不做检测、匹配、归一化、存储、IPC 或 GUI。解析样例源于参考积分契约；
这些部分将在后续任务调用此用例，不复制公式。
