# WB 项目批量元信息 v1

wb-tool0.15.0 / bioimage-app0.10.0。新增应用用例和显示能力，不改项目schema v1–v5、积分算法或已有测量/OCR/归一化记录。实验项目对应整个项目的 name，单项目不混合多个实验名。

## 读取和映射

read_metadata_file只读普通.xlsx（UTF-8 Transitional SpreadsheetML）或UTF-8/带BOM的逗号CSV，返回不可变MetadataBook/Sheet/Cell及输入文件SHA。选择工作表、1起始表头行、匹配列和字段列。表头别名只建议列映射，不勾选字段、不应用值。支持共享/内联富文本和原数值文本；不执行公式、宏、链接，不调用Excel/附件程序。隐藏行列仍在预览中。格式化数值按存储文字显示，不解释日期格式或补前导零；身份标识应存成文本。

XLSX公式（包括声明ref区域的数组公式）及合并单元格标记不可导入，不使用公式缓存。普通字面等号文本仍为文字，CSV以等号起始的值保守标记需手动校正。显式日期/布尔/错误类型标为错误。所选表头含错误则拒绝；所选数据字段有错误则整批不应用，用户可重新输入明确值。未选择字段的错误不影响其他明确字段。

输入最多16MiB、2048 ZIP成员、16工作表、每表1025行（含表头）/64列、总65536单元格、每格2000字符。单个解析XML最多16MiB、累计32MiB；合并/公式区域累计展开最多65536格。仅支持STORE/DEFLATE，拒绝加密、重复成员/坐标/关系、宏/ActiveX/外部链接、DTD/ENTITY、非UTF-8、非法路径与越界区域。仅读取工作簿、关系、共享字符串和工作表；内嵌图像、OLE、超链接、样式/图表不读取或执行，也不解压到文件系统。XML解析预算是工程准入，不是操作系统硬内存上限。

匹配键为完整row_id、完整SHA256或完整文件名，均严格区分大小写，不截取路径/去后缀/猜曝光。不按同名蛋白配对。重复原图名、同源多行、重复输入键不自动选择目标，未匹配保留原因；预览中可明确选择任意项目行（含缺图占位），可查看完整ID/SHA。所选记录不能指向同一目标。公式键不产生匹配候选，但可手动明确选择目标。

## 预览与应用

预览只保存当前草稿摘要、来源SHA/工作表/原行号、匹配候选和提议值，不写项目或运行。用户可修改目标和值，须勾选行与字段再应用；列映射/分隔/共同值改变后预览清空，项目改变后旧摘要拒绝应用。每批最多512行，所有选中记录先验证，任何失败整批保持原项目。

字段为项目名、Fig、蛋白、N、空泳道、顺序、备注。空白保持原值；N接受数学上为整数的数字文本（1..96），0不是空白。空泳道填逗号分隔的唯一1..N编号，`无`、`-`或`[]`明确清空；备注`[]`清空。文字长度和Fig/蛋白单行要求沿用项目模型。排序值须每个所选行都提供唯一1..512整数，只在所选行占用的位置内排序；未选中行位置保持。已有Fig组顺序保留，新增Fig附后，组内顺序使用行顺序。

共同参数只作用于上方明确选中的可见行；文件名规则对完整stem按字面分隔符切分，字段位置显式给出，可用`-`忽略某段。必须分段数完全匹配，失败行提示并给空建议，不能把_0/_1或日期自动认作蛋白/N。规则不是正则表达式，不加载或执行文件名代码。自动建议全部可改。

应用保留row_id、AssetRef/SHA、尺寸位深、ROI、候选、定量请求/已提交run、OCR原文/关联和归一化配置。名称/备注/排序不撤回几何审核；N或空位变化撤回reviewed，既有analysis_is_current/关联/派生有效性隐藏过期值，历史run不删除。严格模型重验证保留LaneROI等实际类型，不能递归dump后当原始字典处理。保存/重开仍通过项目原有不可变修订；导入表/规则本身只保留在当前预览会话，没有新增持久化元信息来源审计。

## 界面和后台

项目“批量元信息”页支持导入、字段映射、共同值、文件名规则、可改预览、批量勾选与显式应用。最多1024预览记录，目标下拉共享一个至多513项的模型，避免每个记录复制全部目标。大项目性能仍需实际验收。

读取元信息在WB后台线程，支持读取部件/行/区域边界的协作取消。取消、关闭或generation变化后结果不替换原预览/草稿；关闭仍等线程真实退出。解析错误保留旧项目和旧表。

原图导入后台直接生成最长边128的灰度显示缩略图，Qt只组装小QImage/QIcon。按原SHA缓存，最多项目512源，行上显示96×64范围，tooltip保留原尺寸/位深/SHA；不写入项目、不进入定量。新导入立即显示；重开可在批量页点击“加载原图缩略图”，逐图后台读取、可取消、失败继续、后到结果校验SHA/尺寸/代际。已有原图大画布选择仍使用2048边预览。坏TIFF导入继续后续文件，SHA去重；达512行明确停止。批量原图取消/关闭沿用既有契约：当前已接受的一张完成导入并保存，停止后续文件；代际变化仍拒绝附着旧原图。

真实用户表只验证解析与原文件不变；表内190公式标为需校正，未据订单/条数猜原图身份。作者自验和截图不等于独立审查、真实实验配对或完整用户验收。
