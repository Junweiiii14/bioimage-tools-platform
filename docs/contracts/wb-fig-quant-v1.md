# WBQuant手动泳道与Fig拼图定量 v1

## 输入与两条流程

独立灰度导入接受既有TIFF规则，适用于用户过去手动测量的整张标注拼图。
默认手动流程：框第一条完整泳道→复制同尺寸→移动/坐标微调→原像素多峰定量。
泳道允许间隔，按原图从左到右编号；间隔不积分。删除/清空/重选只改本轮界面草稿，
当前已完成结果仍在存储，重新计算成功才安装新的运行引用。添加组共享不可变原图资产，
不复制显示像素作为定量来源。规则网格N作为显式替代入口继续兼容T044。

自动流程：当前原图→本地OCR与矩形条带区域→Fig轨道/垂直区间→条带行/横向分段→泳道
建议→正常测量worker→实际退出与存储提交→结果展示。没有逐组确认前置门槛；自动结果
不标为人工复核。分组失败保留原项目，单行规划失败保留该行且允许手动修正。

## 手动与数值

`ManualQuantTarget.lane_rois`为空继续原来的目标锚定网格规则；非空使用明确独立泳道，
T045使用`wbquant_1_4_3@1`；T046新建普通峰采用`peak_envelope@1`，旧计划不静默重算。
保留WBQuant自动去边框、跨泳道候选与多个峰；完整边界和组级审核见
`wb-group-review-v1.md`。UB整段模式仍保留原公式和范围语义。
位置/数目/整数/范围/高度/左右顺序/不重叠须在应用层校验，不信任网页草稿。
每组最多96泳道；目标高度2–4096原像素。界面宽高调整同步本轮泳道。
移动或调整整段泳道后保留整段模式，重规划不转回局部找峰；保存重开保持该语义。
独立泳道与规则网格切换须比较实际几何/定量策略，相同包围框不表示相同计划。

`measurement_mode=smear`产生每泳道唯一全高度`target`，闭边界[0,H-1]；不选最强峰。
只复用冻结WBQuant的保守细边框判据排除确认的框线，记录原ROI与有效ROI；
不把整段区域收窄至某个峰。无法确认的边框保留给人工核对。
标注记录`whole_lane_smear@1`、`endpoint_baseline@1`，复用`profile_integral@1`：
先以原像素逐行均值构成显式极性剖面，再减端点直线、取正残差并作梯形积分。
单位仍是既有WBQuant的灰度×原图纵向像素，不偷偷乘泳道宽度；统一宽度便于比较。
封底端点落在持续拖尾上会扣除部分信号，用户可调整积分范围和两端封底；不能声称
自动背景或UB丰度已经科学验收。自动明确UB标签选整段；未识别标签的高纵向区域
可给整段信号候选，保留缺标签提示，不代填蛋白身份。

补峰使用明确闭区间，拒绝与当前包含条带重叠；排除保留身份，缺失不填0。
32步会话撤销/重做只恢复当前组请求，核对project/row及准确的参数快照；正常保存产生
新request revision时重绑定修订，不恢复旧run或改其他组。重新打开不伪造会话历史。
未添加人工峰的旧多峰顺序（含中间缺失槽）保持；人工补峰按纵向位置展示/导出。
旧OCR/实验配对/归一化仍复用现有能力，不按蛋白名称猜内参。

## 自动检测与限制

`fig_partition@1`先在最长边2048的检测副本寻找浅色页上的填充矩形，再回到原坐标。
Fig标题按水平轨道分组，按同轨垂直位置归属；无上方标题的宽顶图分段可归前轨标题。
同框多条标签用于分开连接的行，同一行横向分段分别给泳道、间隔不作为泳道。
普通信号按二维连接区域合并同一条带的双瓣/上下峰。至少三种不同矩形宽度共同支持时，
可以从图内重复宽度估计泳道单元；分段信号一致时优先分段证据。不读取文件名、冻结
人工坐标或历史答案。它仍是排版几何建议：混合缩放、无框/白背景、缺字、密集相连、
非均匀泳道可能错误，界面允许删除/复制/重选；没有独立留出准确率结论。

OCR原词/坐标/置信度/引擎模型摘要随项目保存；I/L标签歧义和缺蛋白标签显式提示。
不能将大写转换当作纠正OCR真值。自动框选和计算不证明生物学对应或积分准确。

## 持久化与兼容

新Fig项目为`WBPartitionProject/schema9`，继承现有schema8能力并增加最多32张
`partition_sources`原图OCR证据。旧schema1–8读取继续；不静默升级旧项目或重算旧结果。
旧软件拒绝schema9。普通独立手动仍可沿用schema7/8，UB模式通过版本化标注记录。
Qt表格重建项目、版式、分析/自动计划更新必须保留schema9及证据，不能下转schema8。
原图资产保持原通道/位深/SHA，图组视口直接聚焦该资产，不重新缩放生成定量小图。

网页绑定projectId、row_id、source SHA和generation；旧草稿拒绝。单次泳道请求最多
32KiB/96项，其余网页操作仍4KiB。识别/解码/规划在已有后台线程，测量在已有独立进程；
取消、关闭、修订改变都不能让迟到识别安装或启动测量。历史原图/已完成run不覆盖。

## 画布操作

手形按钮、空格临时平移和中键拖动维护显示位移；取消恢复位移，不改变泳道。
适应窗口/聚焦重置位移。原坐标由实际变换后图像边界映射；显示缩放不进入定量。
SVG描边按实际缩放反算至1.5px；手动工具可折叠且最多占侧栏40%，Fig列表至少160px。
